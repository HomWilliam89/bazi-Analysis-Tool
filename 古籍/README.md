# 古籍\ — 规范正文层（接收规格据 D-010 裁定）

## 总则
- 每部书一个 md，UTF-8 无 BOM，文件名 `书名.md` 或 `类别-书名.md`。
- **原件（PDF/docx/底本）始终留底**；本目录的 md 是"规范正文层"，用于检索与引用，不是原件替代品。
- md 以原文逐字与书中原有注释为准，整理者考证一律使用 `【整理者按】` 或 `〔注〕` 与正文严格区隔。

## 结构与体例
- 头部标明底本与参校本来源（若有）。
- 卷／篇／章名以 `##` 或 `###` 标记，附出处篇名与行号区间。
- 引文逐字提取，使用 `>` 引用块，不删句、不合并、不改写；原书图表／命式以代码块原样保留。
- 遇字词疑讹、原缺字，以 `〔疑讹〕` 或 `【】` 校记标出，不主观臆改。

## 质量与交验
- 逐字照录，无乱码、无替换符。
- 放进本目录后跑收口检查与编码校验（UTF-8 无 BOM）。
- 期 3 起另做抽样比对（md 与原件逐段核验）。

## 禁止
- 禁止在正文引用块内直接夹带主观推断。
- 禁止私自“纠正”原文错漏——错亦照抄，以校记或按语说明。
