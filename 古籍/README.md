# 古籍\ — 使用者自制古籍 md 的接收规格（草案，待 D-010 确认）

## 总则
- 每部书一个 md，UTF-8 无 BOM，文件名 `书名.md`。
- **原件（PDF/docx）始终留底**；本目录的 md 是"规范正文层"，用于检索与引用，不是原件替代品。
- md 只准收原文与书中原有注释，**不掺任何解读**；解读另立条目，标 `[解读]`，不进原文。

## 结构
```md
# 书名

## 卷／篇／章名

正文逐段原文……

〔注〕书中原有注释／按语照抄，以此标记开头（无注则不用）
```

## 质量要求
- 逐字照抄，不删句、不合并、不改写；保留原书空行。
- 无乱码、无替换符；章节与原件目录对照，不得缺失。
- 一章一个 `##`；章内原文按自然段分行。

## 交验
放进本目录后跑 `node 工具\shoukou-check.mjs` 查编码；
期 3 起另做抽样比对（md 与原件逐段对）。

## 禁止
- 禁止在原文里夹带解释。
- 禁止"纠正"原文错漏——错了也照抄，可加〔注〕说明。
