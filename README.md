# 八字分析工具 (bazi-Analysis-Tool)

> 一款基于 antigravity + dsh 开发的八字分析工具，仅供个人分析学习使用，不得参与任何商业行为。

给定生辰或四柱，固定输出三层内容：
1. **排盘事实（底层）**：四柱、藏干、十神、神煞、大运、流年等客观事实，只算事实，不下主观判断。
2. **各派主张并陈（丙层）**：平铺格局、调候、盲派、神煞等各家学说的主张、古籍出处与成立条件，只并陈、不选边。
3. **本工具看法（乙体系）**：按本工具自己的宪法与判据推导判断；宪法尚未覆盖的局面，明写「本体系未覆盖，暂不判断」，严禁硬答或拿某一门派冒充。
