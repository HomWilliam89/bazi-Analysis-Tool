# 八字分析工具

给定生辰或四柱，输出三样：**排盘事实**（无争议）＋**各派主张并陈**（不选边）＋
**本工具看法**（按本工具宪法判断；宪法尚未建成时明写「本体系未覆盖，暂不判断」）。

## 当前状态
期 0（立项）与期 1（骨架）已交付：四件文档、开发纪律、目录、两个自检工具、git 均已就位。
**下一步：讨论 D-008——乙体系宪法种子**（使用者口述"看盘先看什么"，逐条整理成宪法）。

## 怎么读（人）
- 项目要做什么、分几期：`文档\01 企划.md`
- 体系长什么样：`文档\02 设计.md`
- 代码、案例、测试怎么落地：`文档\03 技术.md`
- 已裁／待裁：`文档\04 决策台账.md`

## 怎么开发（AI）
1. `AGENTS.md`（硬纪律，每轮自动进上下文）
2. `文档\04 决策台账.md` → 当日 `日志\*.md`
3. 动手前先定级（轻／中／重），中重级先写可行性结论等使用者确认

## 自检
```powershell
node 工具\shoukou-check.mjs   # 收口与编码检查
node 工具\case-runner.mjs     # 案例格式校验（判据建成后升级为真跑）
```

## 文件地图
```
八字分析工具\
├─ AGENTS.md              ← 硬纪律＋指路（英文名固定）
├─ README.md              ← 本文件
├─ 文档\                  01 企划 · 02 设计 · 03 技术 · 04 决策台账
├─ 核心\                  排盘底座（期 2 接入，只算事实不下判断）
├─ 规矩\                  乙体系：宪法＋判据＋术语（判据唯一处）
├─ 流派\                  丙层：各派主张库（只并陈不选边）
├─ 古籍\                  使用者自制的古籍 md（接收规格见其 README）
├─ 案例\                  命盘案例（*.jsonl）
├─ 工具\                  case-runner.mjs · shoukou-check.mjs
└─ 日志\                  YYYY-MM-DD.md
```
