# 规矩\ — 乙体系（判据唯一处）

本工具自己的宪法、判据、术语都只在这里。

- **宪法**（`宪法.md`，据 D-008 裁定）：分析总纲、四条关键、两道闸门等根本原则。
- **术语**（`术语.md`，据 D-008 裁定）：一词一义，全仓唯一术语定义处。
- **判据**（`判据.md`，据 D-009 裁定）：`条件 → 结论`（结论只许枚举值，已落库 P-001～P-004）。
- **母本规格**（`体用路线法.md`，据 D-016 归位）：乙体系原始口述完整规格母本，供出处检索与查验。
- 每条新判据四步齐备（讨论 → 裁定 → 钉住 → 入库）才准进本目录，见 `AGENTS.md` §8。
- 判据尚未完全覆盖前，凡未覆盖之局面一律输出「本体系未覆盖，暂不判断」，只并陈各派（丙层）。
