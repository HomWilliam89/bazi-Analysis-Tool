# 测试区\ — 用户盲测与功能准确度检验专区

> 本目录为**使用者专属盲测沙盒区**。专门用于接收使用者提供的测试八字，对本工具的核心功能、排盘精度与体用推演准确度进行客观检验。

---

## ⚖️ 三大核心铁律（硬纪律）

### 1. 零经验调用与零特判作弊（Zero Hardcoding / Blind Evaluation）
- **绝不被“经验的方式”调用**：测试区内的所有八字命盘，**严禁被本工具以任何经验硬编码、特判分支、或记忆答题的方式调用**。
- **正向公理化推演**：引擎在处理测试八字时，必须完全走通用的底层公理化物理算法（天文求根历法底座 → 藏干神煞事实排定 → 六派规则客观碰撞 → 体用路线生克推演 → 完整报告生成）。
- **纯盲测检验**：严禁在代码中针对测试区八字加入任何 `if (chart === ...)` 式的特殊规避或人工拟合，确保每一次测试都能真实、客观地检验工具的泛化推理能力与真实边界。

### 2. 交付规格 100% 对齐正式完整报告
- **拒绝阉割与缩水**：测试八字生成的报告，**与正式生产环境下解盘交付的最终完整报告完全一致**。
- **全景四段结构**（约 1.8～2.0 万字符深度决策咨询报告）：
  1. **第一段 · 客观排盘事实**：竖排四柱卡片、藏干副星、自坐星运、神煞、五行能量条形图、得令得地得势三维旺衰、真太阳时经度校正披露；
  2. **第二段 · 丙层六派主张并陈**：格局派、旺衰平衡派、调候穷通派、盲派象法、古法三命、神煞象义六派各陈其理，附原典出处、干支详析与学派分歧，不偏袒选边；
  3. **第三段 · 乙体系体用路线法深度推演**：子平八格成破救应全解、去留清格路线图、主要矛盾与全景双通路护卫模型、高阶财富事业专题报告、未来大运逐运深度详批、未来十年流年真实推演、心性画像与修行规划；若触及未立宪外格坚决触发宪法认怂横幅；
  4. **第四段 · 免责声明与科学认知导引**：科学唯物认知导引、法律商业决策边界、自强不息人本哲学。

### 3. 全量沉淀与可追溯归档
- **实时落盘**：每次使用者下达测试指令后，生成的完整 Markdown 报告统一保存在本目录下（形如 `测试报告_<干支标识>.md`）。
- **台账登记**：测试时间、输入干支/生辰、参数、核心定性与报告文件名实时登记于 [`测试台账.md`](./测试台账.md)，确保随时可查验、可复测、可回溯。

## 🚀 使用方法与触发指令

### 方式一：在对话中直接唤起（自然语言指令）
使用者直接发送指令：
- `测试这个八字 庚午 辛巳 乙酉 癸未`
- `测试这个八字 庚午 辛巳 乙酉 癸未 男 1990`
- `测试这个八字 1990-05-20 14:30 男`

AI 将自动调用测试跑器，将生成的万字全景报告写入 `测试区/`，并在对话中呈现精要概览与报告文件链接。

### 方式二：命令行运行
在仓库根目录直接运行测试专用跑器：
```bash
# 1. 四柱模式测试（默认男命，支持 -y 指定基准年）
node 工具/run-test.mjs 庚午 辛巳 乙酉 癸未
node 工具/run-test.mjs 庚午 辛巳 乙酉 癸未 -y 1990 --gender 女

# 2. 公历生辰模式测试（支持指定真太阳时经度校正）
node 工具/run-test.mjs --solar "1990-05-20 14:30" --gender 男 -L 113.3
```
