# 核心\ — 排盘底座与推演大脑（据 D-011、D-017 裁定）

排盘＝把生辰／四柱推演为客观事实（四柱、藏干、十神、神煞、大运、流年、干支作用等）。
**只算事实，不下主观吉凶判断。**

## 模块与文件
- `engine.mjs`：排盘推演核心内核（纯原生 Node ESM，零外部依赖，专注排盘事实底座）。
- `tiyong.mjs`：乙体系 · 体用路线法推演模块（解耦自排盘底座，承载体用四项、主要矛盾、从格改判、护卫网络、承载重估与八格成破救应推演，依据《规矩/体用路线法.md》）。
- `school-matcher.mjs`：丙层 · 六大流派单源特征匹配器（据 D-026 裁定，依据 180 条标准规则动态匹配并陈各派主张）。
- `selftest.mjs`：底座全量自动化回归测试跑器（39 节 1383 项测试全绿）。
- `matcher-test.mjs`：丙层匹配器独立自动化回归测试（4 大测试组 12 项测试全绿）。

## 运行与测试
```powershell
# 运行排盘 CLI（事实层）
node 核心\engine.mjs --birth "1990-05-20 14:30" --gender 男

# 运行体用路线法 CLI（乙体系）
node 核心\tiyong.mjs --birth "1990-05-20 14:30"

# 运行流派匹配器 CLI（丙层各派并陈）
node 核心\school-matcher.mjs 庚午 辛巳 丙寅 己丑

# 运行全量底座自检（1383 项）
node 核心\selftest.mjs

# 运行匹配器自检（12 项）
node 核心\matcher-test.mjs
```

## 架构与演进验证
- **环境实测**：Node v26.10.0（Windows x64），原生 ESM，零第三方依赖。
- **架构解耦实测**：
  - `engine.mjs`（事实底座）：专职排盘事实、神煞、纳音、节气、干支互涉基础；
  - `tiyong.mjs`（体用推演）：独立承载体用路线、从格改判、四维受力仲裁、护卫链求值、夺根降级与八格成破救应；
  - `school-matcher.mjs`（丙层流派）：动态解析 180 条单源主张，客观输出各派原典与互链。
- **验证结果**：通过全量 1383 项底座自检 + 12 项匹配器测试 + 89 项 CLI 测试，命盘案例真跑回归 222 盘 432 项断言 100% 吻合全绿。
