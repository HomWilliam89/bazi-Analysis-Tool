# 核心\ — 排盘底座与推演大脑（据 D-011、D-017 裁定）

排盘＝把生辰／四柱推演为客观事实（四柱、藏干、十神、神煞、大运、流年、干支作用等）。
**只算事实，不下主观吉凶判断。**

## 模块与文件
- `engine.mjs`：排盘推演核心内核（纯原生 Node ESM，零外部依赖，专注排盘事实底座）。
- `tiyong.mjs`：乙体系 · 体用路线法推演模块（解耦自排盘底座，承载体用四项、主要矛盾、从格改判、护卫网络、承载重估与八格成破救应推演，依据《规矩/体用路线法.md》）。
- `school-matcher.mjs`：丙层 · 六大流派单源特征匹配主分发入口（据 D-026、D-070、D-072、D-073、D-074、D-075、D-076、D-077 裁定，解耦拆分为 `核心/matcher/` 子模块，依据 540 条标准规则动态匹配并陈各派主张）。
- `matcher/`：丙层六大学派独立特征谓词子模块（`geju.mjs`, `geju_chengbai.mjs`, `geju_jiuying.mjs`, `tiaohou.mjs`, `wangshuai.mjs`, `mangpai.mjs`, `sanming.mjs`, `shensha.mjs`, `shensha_yuzhao.mjs`, `helpers.mjs`, `index.mjs`），单文件代码量严格控制在 400 行以内。
- `report-generator.mjs`：三段式全景报告装配生成引擎（前 3 项核心详析 + 其余命中全量附录全陈，彻底废除截断隐瞒）。
- `selftest.mjs`：底座全量自动化回归测试跑器（39 节 1383 项测试全绿）。
- `matcher-test.mjs`：丙层匹配器独立自动化回归测试（17 大测试组 45 项测试全绿，含高阶特征、外格专测、调候专测、古法三命专测、神煞铁断专测、盲派做功专测、旺衰变局专测、玉照定真经专测、穷通宝鉴专测、子平真诠成败救应专测、子平真诠成败救应大圆满专测、玉照刑冲定位大圆满专测与 540 条谓词覆盖率 100% 门禁）。
- `cli-test.mjs`：命令行与整车总装自动化回归测试（92 项测试全绿，看门狗 1~41 全绿，含输出完整性 100% 锁死门禁）。

## 运行与测试
```powershell
# 运行排盘 CLI（事实层）
node 核心\engine.mjs --birth "1990-05-20 14:30" --gender 男

# 运行体用路线法 CLI（乙体系）
node 核心\tiyong.mjs --birth "1990-05-20 14:30"

# 运行流派匹配器 CLI（丙层各派并陈）
node 核心\school-matcher.mjs 庚午 辛巳 丙寅 己丑

# 运行全量底座自检（1383 项）
node 核心\selftest.mjs

# 运行匹配器自检（45 项）
node 核心\matcher-test.mjs

# 运行总装与完整性看门狗测试（92 项）
node 核心\cli-test.mjs
```

## 架构与演进验证
- **环境实测**：Node v26.10.0（Windows x64），原生 ESM，零第三方依赖。
- **架构解耦实测**：
  - `engine.mjs`（事实底座）：专职排盘事实、神煞、纳音、节气、干支互涉基础；
  - `tiyong.mjs`（体用推演）：独立承载体用路线、从格改判、四维受力仲裁、护卫链求值、夺根降级与八格成破救应；
  - `school-matcher.mjs` / `matcher/`（丙层流派）：动态解析 540 条单源主张，学理谓词解耦子模块化，客观输出各派原典与互链。
- **验证结果**：通过全量 1383 项底座自检 + 45 项匹配器测试 + 92 项 CLI 测试，命盘案例真跑回归 234 盘 468 项断言 100% 吻合全绿。
