# 渊海子平 · 技法知识模块

## 1. 传承与体例

《渊海子平》，宋徐升（徐大升，号东斋）编。本书由南宋"渊海"与"渊源"两系子平文献汇辑而成，末篇《会要命书说》自述："自唐李虚中一行禅师、宋徐升东斋、明王诠醉醒子诸公，登觉【渊海】【渊源】……今将【渊海】【渊源】二书，合成一集。"故传世本经后人增补，非一时一人之作。

书前《论日为主》点出本书的历史地位：唐李虚中"取人所生年月日时干支生克"论命，至"宋时方有子平之说"，其法"取日干为主，以年为根，以月为苗，以日为花，以时为果"。**全书最核心的方法论主张：专以日干为主，先看月令提纲取格，再以年月时支配合、以财官向背与身主强弱定贵贱，一切归于"中和"二字。**

体例上，本书是子平法的奠基性汇编：先列基础（干支体象、地支藏遁、五行生克制化），次列十神分论（正官、偏官七杀、正财、偏财、印绶、食神、伤官、倒食、劫财），再次列神煞（阳刃、日刃、日贵、日德、魁罡、金神），继以六亲、女命专篇，最后汇集大量早期赋文口诀（《继善篇》《碧渊赋》《造微论》《人鉴论》《爱憎赋》《万金赋》《挈要捷驰玄妙诀》《渊海集说》《群兴论》《五行元理消息赋》《身弱论》《弃命从杀论》《女命总断歌》《论命细法》《心镜歌》《妖祥赋》《络绎赋》《金玉赋》《寸金搜髓论》《珞琭子消息赋》等）。全书以口诀、诗诀、赋文为骨架，理论密度高而体例松散，同一命题常在不同赋篇中反复出现，且**同句异文颇多**（详见第 5 节）。

## 2. 核心技法体系

### 2.1 五行生克制化总则

**相制而成器（各有所喜）**
- 金旺得火 → 方成器皿；火旺得水 → 方成相济；水旺得土 → 方成池沼；土旺得木 → 方能疏通；木旺得金 → 方成栋梁。
- 强金得水 → 方挫其锋；强水得木 → 方泄其势；强木得火 → 方化其顽；强火得土 → 方止其焰；强土得金 → 方制其害。

**相生反为累（母多灭子，各有所害）**
- 金赖土生，土多金埋；土赖火生，火多土焦；火赖木生，木多火炽；木赖水生，水多木漂；水赖金生，金多水浊。
- 金能生水，水多金沉；水能生木，木盛水缩；木能生火，火多木焚；火能生土，土多火埋；土能生金，金多土变。

**相克反受伤（克者力不任）**
- 金能克木，木坚金缺；木能克土，土重木折；土能克水，水多土流；水能克火，火多水热；火能克金，金多火熄。
- 金衰遇火，必见销熔；火弱逢水，必为熄灭；水弱逢土，必为淤塞；土衰遇木，必遭倾陷；木弱逢金，必为砍折。

**判断准则（总纲）**
- 太过无克制者 → 贫贱；不及无生扶者 → 夭折。
- 五行偏枯（太过不及）→ 主夭折、灾病；五行中和、八字相停 → 主遐龄、福寿。
- 用火愁水，用木愁金；太过宜脱剥（泄耗），不及喜生扶。
- 寒暖通则：南方火炎，利入北方水运；北方水寒，利入南方火运；东方木多，宜入西方金运；西方金旺，宜入东方木运。
- 水火有既济之功，金木有成名之论 → 五行相济者，威名荣振。
- "木从水养，水盛而木则漂流；金赖土生，土厚而金遭埋没。"
- "金木交差刑战，仁义俱无；水火递互相伤，是非日有。"

### 2.2 干支体象与月令分日用事

**天干体象（用于取象、定性情与行运宜忌）**

| 乙 | 根荄深种之木 | 阳地；南行需水济 | 多水漂浮、苦用金刻断、南去火炎、西行土重 |

| 辛 | 珠玉之金，性通灵 | 阳和沙水清、湿泥资扶 | 水多火旺不宜西北、不劳炎火煅 |
| 壬 | 汪洋之水 | 养性结胎须未午 | 干支多聚成漂荡、火土重逢涸本源、西北行程厄 |
| 癸 | 雨露/江河之水 | 申子辰全成上格 | 柱无坤坎身弱、寅午戌备要中和 |

**地支体象（摘判断性内容）**
- 子：逢午破应无定，遇卯刑还有情；柱内申辰来合局 → 即成江海发涛声。
- 丑：刑冲戌未非无用；日在日时多水木 → 宜行巽离（东南）乡。
- 寅：破禄伤提独虑申；四柱火多 → 嫌火地，"从来燥木不南奔"。
- 卯：庚辛叠见愁申酉，亥子重来忌癸壬；祸见六冲应落叶，喜逢三合便成林。
- 辰：直须一钥能开库，若遇三冲即破门；水木重逢西北运 → 原土不能存。
- 巳：得时戊土禄随娘；三形传送翻无害，一撞登明（亥）便有伤。
- 午：申子齐来能战克；戌寅同见越光明；东南身强，西北丧形。
- 未：藏官藏印不藏财；无火怕行金水，多寒偏爱丙丁；远带刑冲库亦开。
- 申：巳午炉中成剑戟，子辰局里得光锋；木多无火终能胜，土重埋金却有凶。
- 酉：柱见水泥应有用，运临西北岂无情；三合能坚锐。
- 戌：洪炉巨火能成就，钝铁顽金赖主张；海窟（辰）冲龙生雨露，山头（寅）合虎动文章。
- 亥：五湖归聚原成象，三合羁留正有心。

**月令分日用事（司权日数，用于定月令真假）**
- 立春念三（廿三）丙火用，余日甲木旺提纲；惊蛰乙木未用事，春分乙未正相当。
- 清明乙木十日管，后八日癸水洋；谷雨前三戊土盛。
- 立夏伏戊土取；小满过午丙火光；芒种己土相当好，中停七日土高张；夏至阴生阳极利，丙丁火旺有土张。
- 小暑十日丁火旺，后三日乙木芳，己土三日威风盛；大暑己土十日黄。
- 立秋十日壬水涨；处暑十五庚金良；白露七日庚金旺，八日辛金独行。
- 寒露七日辛金管，八日丁火又水降；霜降己土十五日，其中杂气取无妨。
- 立冬七日癸水旺，壬水八日更流忙；小雪七日壬水急，八日甲木又芬芳。
- 大雪七日壬水管；冬至癸水更潺汪；小寒七日癸水养，八日辛金丑库藏；大寒十日己土胜。

**地支藏遁歌（取格与论人元之基）**
- 子宫癸水在其中，丑癸辛金己土同；寅宫甲木兼丙戊，卯宫乙木独相逢。
- 辰藏乙戊三分癸，巳中庚金丙戊丛；午宫丁火并己土，未宫乙己丁共宗。
- 申位庚金壬水戊，酉宫辛金独丰隆；戌宫辛金及丁戊，亥藏壬甲是真踪。

### 2.3 十神定位与看命顺序

**十神定位（以日干为我）**
- 克我者：分阴阳 → 正官（阳见阴／阴见阳）、七杀偏官（阳见阳／阴见阴）。
- 我克者：分阴阳 → 正财、偏财。
- 生我者：分阴阳 → 正印（印绶）、偏印（倒食、枭神）。
- 我生者：分阴阳 → 伤官（阳见阴／阴见阳）、食神（阳见阳／阴见阴）。
- 同类者：分阴阳 → 比肩（兄弟）、劫财（阳见阴为败财，阴见阳为劫财；阳刃亦属此类）。

**看命顺序（《论日为主》《看命入式》《宝法》）**
1. 先看日干为主，定身旺身弱。
2. 次看月令提纲——"凡格用月令提纲，勿于傍求年日时为格"；月令所藏何者为用，即知其格。
3. 再看四柱（年月时）何字损月令之神、损日主秀气；有坏月神者，要别制之。
4. 后看岁运何旺，再就日下消详。
5. 年为本（祖上、父母）、月为苗（父母、兄弟门户）、日为花（己身、妻妾）、时为果（子息）。
6. 取格后以"逢官看财、逢财看杀、逢杀看印、逢印看官"推其取舍救应。

**四柱宫位断法**
- 年有用神 → 得祖宗力；月令有用神 → 得父母力；时有用神 → 得子孙力；反此则不得力。
- 年带官星印绶 → 早年有官出自祖宗；月带官星印绶 → 慷慨聪明、见识高人；时为辅佐 → 平生操履。
- 年月日有吉神 → 时归生旺之处；有凶神 → 要归时制伏之乡。
- 年伤日干 → 名"主本不和"；年克日为上能陵下，日克年为下去犯上（有物制日干则可化恶为祥）。
- 日通月令 → 得祖安身；年冲月令 → 离祖成家；日破提冲 → 弦断再续；时日对冲 → 伤妻克子。

### 2.4 十神分论（性情、成败与行运）

#### 正官
- 取法：甲见辛之类，阴见阳为官。**"大抵要行官旺乡，月令是也。"** 生于八月中气之后、金旺在酉 → 正官；天干不透辛而地支有巳酉丑 → 亦可言官，但**大要身旺，时辰归于甲木旺处**。岁时透出正官、地支又有官格 → 不拘中气之后。
- 成格：喜身旺、印绶；官星得印绶、身旺则发；若无伤官破印、身不弱 → 便为贵命。
- 破格：大忌刑冲破害；最怕阳刃七杀；官星一位若两官不妨，年月时干皆有官星隐露 → 福渺。
- 官杀混杂：月令正官而年时支干有偏官 → 便杂，不可纯以正官论。
- "正官或多，反不为福"——太过与不及同，宜得中和之气。
- 行运：命中有官而运行伤官 → 不吉；须待印绶、官旺之运可发。
- 杂论补：官怕伤；合官非为贵取；贪合忘官荣不足；柱中官星太旺、天元羸弱 → 贫。

#### 偏官 / 七杀
- 取法：甲见庚之类，阳见阳、阴见阴，不成配偶。
- **核心判语："有制伏则为偏官，无制伏则为七杀。""身旺化之，得为偏官；身弱无制伏，则为七杀。"**
- 成格：喜身旺、合杀、制伏、阳刃；元有制伏可行杀旺之方，元无制伏可行制伏之运。
- 破格：忌身弱、忌见财（财能生杀）、忌无制。四柱杀旺运纯而身旺 → 为官清贵；身弱杀旺无制 → 带病贫薄、凶夭。
- **制伏不可太过**："如有一杀，而制伏有二三，复行制伏之运，反不作福……尽法无法……不可太甚，亦不可不及。"偏官时遇、制伏太过 → 乃是贫儒。
- 阳刃配杀："如行身旺乡，更有阳刃，贵不可言。"
- 冲与刃：月令中气之杀怕冲与阳刃；**"时上七杀，却不怕阳刃，而亦不畏冲"**；"如曰七杀不怕刑冲，宜详之"（存疑语）。
- 位置轻重：月见杀者重，时见杀者轻；日七杀只宜一位，年时再见则杀多为祸。时七杀一位 → 要本身旺，年月时三处有制伏为福；却要行杀旺运，运三合得地亦发。
- 六日主杀性：甲申、乙酉、丁丑、戊寅、己卯、辛未、癸未日生 → 性急伶俐、心巧聪明。
- 去留：去官留杀有威权，去杀留官方论福；官杀混杂，有财者吉、无财无印者凶。

#### 正财
- 取法：甲见己之类，阴见阳、阳见阴；"吾妻之财也"。
- 喜：身旺、印绶（印能生身）；忌：官星（盗财之气）、倒食、身弱、比肩劫财。
- 关键门槛：**"财要得时，不要财多。"** 财多则须日主有力方可胜任；天元一气羸弱贫薄难治。**"财多身弱，正为富屋贫人"**；"财多身弱，身旺以为荣"（行身旺运反发）。
- 成格：财旺生官而身健 → 贵；四柱相生、别带贵格、不值空亡、又行旺运、三合财生 → 皆贵命。
- 破格：财多盗气、身柔、年运又伤财 → 必生奇祸；带刑并七杀 → 凶不可言；力不任财 → 祸患百出。
- 行运：命中有官星得地 → 运行喜财星多生官；财星得地 → 运行忌见官星，恐克其身。

#### 偏财
- 取法：阳见阳财、阴见阴财；"众人之财也"，偏财为父、为妾。
- 喜：身旺、财丰；财盛自生官。忌：兄弟（比劫）分夺；空亡（"有一于此，官将不成、财将不住"）。
- 判语：偏财好出、亦不惧藏，惟怕分夺；主人慷慨、不甚吝财、为人有情而多诈。
- 财弱 → 待历旺乡而荣；财盛 → 无所往而不妙，但恐身势无力。
- **"财多，须看财与我之日干强弱相等，行官乡便可发禄。若财盛而身弱，运至官乡，是既被财之盗气，复被官之克身"** → 非惟不发禄，亦防祸患。
- 四柱元带官星 → 便作好命看；四柱兄弟辈出 → 纵入官乡，发禄必渺。

#### 印绶（正印 / 偏印）
- 取法：生我者；阳见阴、阴见阳为正印，阳见阳、阴见阴为偏印，亦名"生气"。
- 成格："有官无印，即非真官；有印无官，反成其福。"带印绶须带官星 → 官印两全，必为贵命。官星虽见成，得父母力，为福亦厚；行官星运便发，或行印绶运亦发。
- 破格：**"印绶畏财"**、"喜官星生印，忌财旺破印"；最怕行印绶死绝之运；若运临死绝、又有物窃之 → "即入黄泉，无疑也"。
- 伤印之应：主破家离祖、出赘；又临死绝之地，非降官失职，必夭其寿。
- 轻重：月与时上见者为妙，**月上最为紧要**；两三命相并，当以印绶多者取之。月印得父母力，年下有生气得祖宗力，时上见之得子孙力、寿元耐久、晚景优游。
- 交杂判：官鬼多或入别格 → 不可专以印绶论。
- 杂论补：印绶比肩、不忌财乡；印绶多根、身旺必贫；身旺何劳印绶；印多者行财而发；印綬被伤、倘若荣华不久；印旺身强多嗜酒。

#### 食神
- 取法：甲见丙，我生而能生我财（丙生戊土为甲之财），故称食神。
- 成格：主人财厚食丰、腹量宽洪、肌体肥大、优游自足、有子息、有寿考；喜身旺、喜财神相生；"独一位见之，则为福人，然终亦不清"。
- 破格：**"恒不喜见官星，忌倒食，恐伤其食神"**；不喜印绶（亦恐伤食神）；身弱则不成。
- 行运：如运得地，方可发福；大概与财神相似。
- 死法（必看具体）：食神居先、杀居后 → 衣禄无亏富贵厚；食神近杀 → 却为殃。食神最喜劫财乡；食神干旺、胜似财官；食衰枭旺 → 不死也灾；食神制杀逢枭 → 不贫则夭；食神逢枭者亡。

#### 伤官
- 取法：甲见丁，我生而阴阳相异；亦名"盗气"。
- **第一门檻："伤官务要伤尽；伤之不尽，官来乘旺，其祸不可胜言。伤官见官，为祸百端。"**
  - 伤官伤尽（四柱不留一点官星）→ 又行旺运及印绶运，却为贵也。
  - 伤官不尽、四柱有官星露、岁运再见官星 → 其祸不可胜言。
  - "四柱有官而被祸重，四柱无官而被祸则浅"（元有者重，元无者轻）。
- 第二门槛：**"如四柱中虽伤尽官星，身虽旺，若无一点财气，只为贫薄。"** 用伤官格局，见财方可用；伤官用财者富，伤官劫财者贫。
- 身弱可用财："如四柱虽伤尽官星，身弱逢财运发福，是为伤官见财。"
- 行运：用伤官格者，支干、岁运都要不见官星；运一逢官，祸不可言；或有吉神可解，必生恶疾以残其躯，不然运遭官事。财行得地则发，行败财之地必死；运支内无财运，干虚露亦不可。
- 性情：多才艺、傲物气高、常以天下之人不如己；贵人惮之，众人恶之。
- 宫位：年带伤官父母不全，月带伤官兄弟不完，日带伤官妻妾不完，时带伤官子息无传。
- **五行分别（口诀，务必分辨）**："火土伤官宜伤尽；金水伤官要见官；木火见官官有旺；土金官去返成官；惟有水木伤官格，财官两见始为欢。"
- 印与财的取舍："伤官用财，不宜印乡"；"伤官见官，印运不妨"；"伤官用印去财，方可驰名"；"伤官用财，伤官处须当发福"；"伤官用印宜去财，伤官用财宜去印"；用财去印、用印去财方发弥福。

#### 倒食（偏印 / 枭神 / 吞啖煞）
- 取法：甲见壬，冲财神之谓。**"用财神大忌见之，用食神亦忌见之。"**（壬克丙，丙不能生甲之土财。）
- 判断：凡命中带此二者，主福浅寿薄；作事进退悔懒、有始无终、财源屡成屡败、容貌欹斜、身品矮小、胆怯心慌、凡事无成。
- 又见庚为七杀，得丙丁火制之，怕见水（水克火则反为祸）。

#### 劫财 / 败财
- 取法：乙见甲为劫财（亦名逆刃）；五阳见五阴为败财，五阴见五阳为劫财。
- 判语：五阳见五阴为败财 → 主克妻害子；五阴见五阳为劫财 → 主破耗、防小人，不克妻。
- 兄弟之辨："兄见弟，弟能败兄之财，夺兄之妻；弟见兄，兄能劫弟之财，而不敢取弟之妻。"
- "男命见劫财多克妻，女命见伤官多克夫。此极论也。"
- 柱有劫财比刃多者 → 刑父伤妻，不聚财。

#### 十神组合的成败判语（《杂论口诀》《继善篇》《四言独步》汇录）
- 财官相生：富而且贵，定因财旺生官；财生官、官生印、印生身 → 富贵双全。
- 财生杀党：干党财、财党杀、杀攻身 → 凶穷两逼；财生杀党 → 夭折童年。
- 伤官见官：为祸百端；若非疾病伤躯，必当官讼囚系、子丧妻伤；重则迁徙，轻则刑责。
- 枭神夺食：食神制杀逢枭 → 不贫则夭；食衰枭旺 → 不死也灾。
- 杀印相生：杀不离印，印不离杀；杀印相生 → 功名显达；印赖杀生。
- 官印相生：有官有印，无破作廊庙之材；官印财食无破 → 清高。
- 比劫夺财：孤寡者只为财神被劫；用财若遇劫夺，一生贫困。
- 财坏印：印绶见财，愈多愈灾；贪财坏印 → 破家离祖。

**《群兴论》五种兴发模式（原文成节，用于断发达时机）**
- 当兴：四柱身主专旺，所用吉神（财官印食）俱各带禄权得令、不偏不杂，又无刑冲伤损克害，运上步步皆吉 → 源清流洁，终身享福。

## 4. 该书的独门之处

1. **"专以日干为主，以年为根，以月为苗，以日为花，以时为果"的体系宣言。** 本书明确记述子平法取代唐李虚中"以年为主"法的历史转变（《论日为主》），并以"日为花、时为果"建立宫位与生命阶段的对应，这是子平术区别于三命术的根本标记。
2. **以月令提纲为唯一取格依据的死规定。** "凡格用月令提纲，勿于傍求年日时为格""不可以年取格"——本书对取格来源限制之严，在诸命书中最为突出，并以此直接批评当时"取格不定，十有九差"的通行弊病。
3. **对"十八格"的自我怀疑与收敛。** 同一部书里，《论日为主》痛斥"倘有妄立格局，从列其名，而无实用，其飞天禄马、倒冲井栏叉，即伤官，析而为之"，而《喜忌篇》《妖祥赋》又大量罗列飞天禄马、子遥巳、丑遥巳、井栏叉、刑合、拱禄拱贵等外格。《宝法》则提出折中：**"十八格内取六格为重"**，以官、印、财、杀、食神、伤官六格统摄诸格。这种"立格—疑格—归六格"的自我修正过程，是本书独有的思想轨迹。
4. **"逢官看财、逢杀看印、逢印看官"的三句取用口诀。** 本书标榜此为"西山易鉴先生"所得、"斯有奥妙不传之法"，把复杂的用神取舍压缩为三条联动规则，是早期子平术最简明的用神操作法。
5. **伤官法按其五行细分为五类。** "火土伤官宜伤尽；金水伤官要见官；木火见官官有旺；土金官去返成官；惟有水木伤官格，财官两见始为欢。"——同一格局因日主五行不同而取用相反，本书把这一层讲得比后世许多书更具体。
6. **大量"神趣八法"式的取象法门。** 类象、属象、从象、化象、照象、返象、鬼象、伏象八法，以及"类象最怕引至时为死绝之乡，谓之破了秀气"一类的秀气论，是本书保留的早期象法遗产，后世格局派多已不用。
7. **"死法"与"通变"并陈的教学结构。** 论大运时先给出十神行运的固定断语（"且如甲乙得寅卯运，名曰劫财败财，主克父母及克妻、破财争斗之事"），随即自我否证："此乃死法譬喻，须随格局喜忌推之，不可执一；妙在识其通变。"这种把口诀与其适用边界一并写出的做法，在命书中较为难得。
8. **《群兴论》五阶段发达模型。** 当兴、崛起、聚兴、中兴、末兴，专论"何时发"，把命局静态结构与大运动态配合分成五种发迹机理，是本书独有的应期理论。
9. **《格局生死引用》的应期归纳。** 把各类破格统一归结为"岁运并临／重见／相并必死"的句式，并提供"柱有比肩，庶几有解"一类的救应判据，是早期子平最系统的死期推断条文化尝试。

## 5. 局限与后世争议

1. **全书体例松散、重复与矛盾并存。** 同一命题在十神分论、诸赋、诸诀中反复出现，且常互有出入。例如《碧渊赋》作"逢印看官而遇官，十有八贵"，而《挈要捷驰玄妙诀》作"逢印看官而遇官，八而七贵"；《碧渊赋》"身旺有杀行印绶，权断之官"，《挈要》作"身旺有杀逢印绶"，《详注本》又作"身旺有杀行印绶"。原文自身即存在版本异文，引用时须注明所据篇名。
2. **外格标准极不统一，且本书内部自相矛盾。** 《论日为主》明言飞天禄马、倒冲、井栏叉"即伤官，析而为之……而无实用"，而《喜忌篇》《妖祥赋》《碧渊赋》《挈要》又把这些格当作取贵正途反复使用；《相心赋》一边说"乙巳鼠贵，遇午冲，贫如颜子"（承认其格），一边在《论妇人总诀》说"飞天禄马井栏叉，女命逢之福不佳"。**这是本书最须留意的一处含混。**
3. **对"内十八格／外十八格"只提名称、不列细目。** 传世本正文中"十八格"仅作为数字出现（"十有八格，当从善恶推求""十八格内取六格为重"），逐格的取法与破法散落各篇，读者无法据本书重构完整目录。**此点须结合后世《子平真诠》《渊海子平评注》等书补足。**
4. **部分格局"原文仅列名"。** 勾陈得位、真武当权（《珞琭子消息赋》）仅一句赞语，无取法无破法；女命贵格 19 项、贱格 20 项仅列名目，无逐格条件；三奇格、建禄格、胞胎格亦仅略述。此类条目**原文仅略述，需结合他书**。
5. **神煞体系庞杂，且多不释起例。** 空亡、咸池、驿马、华盖、天月二德、孤鸾、勾绞、元亡、天罗地网、十恶大败、五鬼等，本书或只给断语、或只给名目，**起例多"原文未详"**，须依后世工具书补齐；而《继善篇》《碧渊赋》又反复强调"神煞相绊，轻重较量"、应以五行生克为主——神煞与五行的主次关系在本书中并未彻底理清。
6. **女命部分时代局限明显。** "女命只要身弱""身强欺夫，不孝公姑""财多而淫""满盘多是印，损子必须定""官星桃花，福禄堪夸"等语，把女性的社会角色固化为柔顺、旺夫、益子，"淫贱""娼妓""婢妾"一类判词大量直接用作出身与品行的推断。这是本书最明显的时代偏见，现代使用时应剥离价值判断、只保留其结构分析（如夫星数量、官杀混杂、伤官对夫星的作用）。
7. **断死期条款过于绝对。** 《格局生死引用》以"岁运并临必死""岁运重见即死"一类句式成批下断，未给身旺身弱、用神有力无力、有无救应之外的更多缓冲；同篇结尾自己也承认"作此论，一不可拘，二须敢断"，前后口径不一。
8. **六亲取象存在性别与象义交叉的混乱。** 同一偏财既为"父"又为"妾"、正印既为"母"又为"祖母"之属，且"男取克干为嗣，女取干生为子息"与《论妇人总诀》"女命取伤官是子，食神是女"两处口径互异（《论子息》篇内前后即并存"女命取伤官是子，食神是女"与"七杀者子也"两说），取子星时须择一而从并注明取舍。
9. **调候内容薄弱。** 本书论寒暖仅见《寸金搜髓论》《金玉赋》《珞琭子消息赋》数句（"南方火炎，利入北方水运""生居三冬，水冷金寒，得火相扶，莫作等闲"），未形成如后世《穷通宝鉴》那样按十二月令逐干列丙火癸水的调候用神表。**以调候为主要判据的场景，本书不足以支撑，须另取他书。**
10. **对纳音旧法的态度前后不一。** 《详解定真论》讥"俗以甲子作海中金，即娄景之前，未知金在海中之论"，主张废纳音，但同篇又引"以年为主者……便可为本命忌日之戒"，且全书多处仍用年命、将星、天乙、华盖、咸池等星命旧法，新旧杂陈。
