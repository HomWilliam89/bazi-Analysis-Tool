# 滴天髓阐微 · 技法知识模块

## 1. 传承与体例

《滴天髓》旧题京图撰、刘基（诚意伯）注，本文通行本为**清代任铁樵（任氏）增注、后学辑为《滴天髓阐微》**。全书分**通神论三十四章**（天道、地道、人道、知命、理气、配合、天干、地支、干支总论、形象、方局、八格、体用、精神、月令、生时、衰旺、中和、源流、通关、官杀、伤官、清气、浊气、真神、假神、刚柔、顺逆、寒暖、燥湿、隐显、众寡、震兑、坎离）与**六亲论二十九章**（夫妻、子女、父母、兄弟、何知章、女命、小儿、才德、奋郁、恩怨、闲神、从象、化象、假从、假化、顺局、反局、战局、合局、君象、臣象、母象、子象、性情、疾病、出身、地位、岁运、贞元）。

体例为三段：**四句歌诀原文 → 原注 → 任氏曰**。任氏注占全书篇幅十之八九，附有大量实际命例验证。

最核心方法论主张：**"命中至理，只存用神"**——尽扫奇格异局、神煞纳音之妄，一切以"日主衰旺、用神喜忌、去留舒配"四端定吉凶。

## 2. 核心技法体系

### 2.0 判断总流程（任氏全书隐含的取断顺序）

1. **审三元**：干为天元、支为地元、支中所藏为人元；先看天干地支是否"接续相生"（顺）抑或"反克为害"（悖）。
2. **看月令提纲**：月令为"提纲之府"，定格局之所属；再究**人元司令**（寅月立春后七日前戊土、八至十四日丙火、十五日后甲木之类）以定真假。
3. **看天干透出何神**：月支之神透于天干者为"格之真者"；不透则于别支寻透干者借以为用。
4. **定衰旺通根**：不专以月令论旺衰，四柱有根便能任财官食伤而当伤官七杀。
5. **取用神、喜神、忌神**：定一个着落；除用、喜、忌外皆闲神客神。
6. **看体用情协**：上下（干支）情协、左右（四柱）同志、始终（年月为始、日时为终）得所。
7. **看岁运安顿**：大运重地支、太岁重天干；盖头截脚、战冲和好。
8. **落到六亲与事象**：夫妻、子女、父母、兄弟、出身、地位、性情、疾病。

### 2.1 三元顺悖与命贵中和

- 天干气弱、地支生之；地支神衰、天干辅之 → 有情而顺 → 吉。
- 天干衰弱、地支抑之；地支气弱、天干克之 → 无情而悖 → 凶。
- 四柱流通、五行生化 → 吉；四柱缺陷、五行偏枯 → 终有损。**凡四戊午、四癸亥、四乙酉、四辛卯、四庚辰、四甲戌等"一气"之造，任氏皆作偏枯论，无不应验**（原文斥"圣帝之造""张桓侯之造"为讹传）。
- 用之为财不可劫、用之为官不可伤、用之为印不可坏、用之为食不可夺 → 其要在一"**用**"字；**不用财星尽可劫，不用官星尽可伤，不用印绶尽可坏，不用食神尽可夺**。
- **凡神煞（桃花咸池、金锁铁蛇）、奇格异局、纳音诸法、飞天禄马、杂气财官、三刑六害，皆任氏所辟**："吉凶神煞之多端，何如生克制化之一理。"
- **支神只以冲为重，刑与穿兮动不动**：刑（自刑、子卯、寅巳申、丑戌未）与穿（六害、破）皆"无所取""尤为穿凿"，总以生克论。

### 2.2 衰旺真机

**通根重于比肩**（判断旺衰的第一硬门槛）：

- 日主不论月令休囚，四柱有根便能受财官食神而当伤官七杀。
- **长生禄旺 ≡ 根之重者；墓库余气 ≡ 根之轻者**。
- 天干得一比肩 ＜ 地支得一余气墓库；得二比肩 ＜ 支中得一长生禄旺。"比肩如朋友之相扶，通根如家室之可托"——**干多不如根重**。
- 墓库：甲乙逢未（木库）、丙丁逢戌（火库）、庚辛逢丑（金库）、壬癸逢辰（水库）；余气：丙丁逢未、甲乙逢辰、庚辛逢戌、壬癸逢丑。
- **"投墓而必冲""墓库逢冲必发"皆谬**：地支全赖辰戌丑未通根者，逢冲则微根拔尽，未有不因冲而败者。

**得时不旺 / 失时不弱**：

- 春木虽强，干庚辛而支申酉，无火制则不富，逢土生则必夭 → 得时不旺。
- 秋木虽弱，干甲乙而支寅卯，遇官透而能受 → 失时不弱。

### 2.3 体用与用神取法

**体用定义**：体者形象气局之谓（无形象气局则以日主为体）；用者用神也，"除体用之外，不能别求用神"。

**任氏用神定则（照此直取）**：

| 命局情状 | 用神 |
|---|---|
| 日主旺，印绶多 | 财星 |
| 日主旺，官杀轻 | 财星 |
| 日主旺，比劫多（劫我财星） | 食伤 |
| 日主旺，比劫多而财星轻 | 食伤 |
| 日主旺，官星轻、印绶重 | 财星 |
| 日主弱，官杀旺 | 印绶 |
| 日主弱，食伤多 | 印绶 |
| 日主弱，财星旺 | 比劫 |
| 日主与官杀两停 | 食伤 |
| 日主与财星均敌 | 印、比 |
| 提纲是禄刃 | 以提纲为体，于四柱干支食神财官中寻得所者用之 |
| 日主不能为力，合别干而化（真化） | 以化神为体；化神有余泄之，化神不足生之 |
| 局方曲直五格（日主是元神） | 以格象为体；用食伤或财，**不宜用官杀** |
| 无格无局、无用神可取 | 待岁运破合神、合冲神、制劫占、通阻隔，"随岁运取用" |

**原注之辨**：原注称"二三四五处用神者，的非妙造"，任氏斥为"此说大谬"——八字除日干外只有七字可取用，"总有一个着落"。

**旺则抑之、弱则扶之有变**：旺极者抑之反激而有害 → 宜从其强而扶之；弱极者扶之徒劳无功 → 宜从其弱而抑之（此即从格、顺局之理）。

### 2.4 十干体象与性情（原文口诀＋任氏取用）

**甲乙木**

- **甲木参天，脱胎要火。春不容金，秋不容土。火炽乘龙，水宕骑虎。地润天和，植立千古。**
  - 春初木嫩气寒，得火而发荣；仲春旺极，宜泄其菁英（强木得火方化其顽）。春不容金：金休囚而克旺木，木坚金缺。秋不容土：秋土虚薄，遇下攻之木必反遭倾陷。火炽乘龙：柱中寅午戌全又透丙丁，宜坐辰（湿土生木泄火）。水宕骑虎：申子辰全又透壬癸，宜坐寅（火土生地，木之禄旺，能纳水气）。
- **乙木虽柔，刲羊解牛。怀丁抱丙，跨凤乘猴。虚湿之地，骑马亦忧。藤萝系甲，可春可秋。**  - 生丑未月或乙未乙丑日，未为木库蟠根、丑为湿土受气 → 能制柔土。生申酉月得丙丁透干、有水不相争克 → 不畏金强。生亥子月四柱无丙丁又无戌未燥土 → 即使年支有午亦难发生。天干甲透、地支寅藏 → 四季皆可。

**丙丁火**

- **丙火猛烈，欺霜侮雪。能煅庚金，逢辛反怯。土众成慈，水猖显节。虎马犬乡，甲木若来，必当焚灭。**
  - 泄其威须用己土（己土卑湿能收元阳）；遏其焰必要壬水（壬水刚中之德能制暴烈，癸水逢丙即涸）；顺其性还须辛金（辛柔软，明合亲、暗化水相济；庚金刚健，刚又逢刚势不两立）。支坐寅午戌火势过猛，再见甲木来生则转致焚灭。
- **丁火柔中，内性昭融。抱乙而孝，合壬而忠。旺而不烈，衰而不穷，如有嫡母，可秋可冬。**
  - 抱乙：使辛金不伤乙木；合壬：暗使戊土不伤壬水。干透甲乙，秋生不畏金；支藏寅卯，冬产不忌水。

**戊己土**

- **戊土固重，既中且正。静翕动辟，万物司命。水润物生，火燥物病。若在艮坤，怕冲宜静。**
  - 生春夏火旺，宜水润之，燥则物枯；生秋冬水多，宜火暖之，湿则物病。艮坤者寅申之月：春受克气虚宜静，秋多泄体薄怕冲。**生四季月最喜庚申辛酉之金，秀气流行，定为贵格**（己土亦然）；柱见木火则破。
- **己土卑湿，中正蓄藏。不愁木盛，不畏水狂。火少火晦，金多金光。若要物旺，宜助宜帮。**
  - 柔土能生木，木不克；土深能纳水，水不冲。无根之火（丁火）不能生湿土，故火少反晦；湿土能润金（辛金）故金多反光。柱中土气深固、得丙火去其阴湿 → 滋生万物。

**庚辛金**

- **庚金带煞，刚健为最。得水而清，得火而锐。土润则生，土干则脆。能赢甲兄，输于乙妹。**
  - 得水而清者壬水（引通刚杀之性）；得火而锐者丁火（阴柔不与庚为敌，销熔成剑戟）。生春夏气稍弱，遇丑辰湿土则生，逢未戌燥土则脆。甲木正敌力能伐之；与乙相合转觉有情。
- **辛金软弱，温润而清。畏土之叠，乐水之盈。能扶社稷，能救生灵。热则喜母，寒则喜丁。**
  - 畏戊土太重（涸水埋金）；乐壬水有余（润土养金）。生夏火多得己土则晦火生金；生冬水旺得丁火则温水养金。**辛金生冬月见丙火则男命不贵（虽贵亦不忠），女命克夫（不克亦不和）；见丁则男女皆贵且顺。**

**壬癸水**

- **壬水通河，能泄金气，刚中之德，周流不滞。通根透癸，冲天奔地。化则有情，从则相济。**
  - 申子辰全又透癸，其势泛滥，戊己不能止流，强制则冲激成患，**必须用木泄之，顺其气势**。生四五六月火土并旺无金水相助，火旺透干则从火，土旺透干则从土。
- **癸水至弱，达于天津。得龙而运，功化斯神。不愁火土，不论庚辛。合戊见火，化象斯真。**
  - 柱中有甲乙寅卯，皆能运水气、生木制火、润土养金，定为贵格，火土虽多不畏。弱水不能泄金气（金多反浊），故不论庚辛。合戊见火：戊土燥厚、柱中得丙火透露引出化神乃为真；秋冬金水旺地，纵支遇辰、干透丙丁亦难从化。

**十干勿作死板比喻**：任氏力斥"甲为梁栋、乙为花果、丙作太阳、丁作灯烛、戊作城墙、己作田园、庚为顽铁、辛作珠玉、壬为江河、癸为雨露"之说，谓"甲乙一木也，不过阳刚阴柔、阳健阴顺而已"。

**五阳从气不从势，五阴从势无情义**：
- 五阳性刚健，不畏财煞（"五阳得阳之气，即能成乎阳刚之势"）。
- 五阴见势忘义，木盛则从木、火盛则从火……（"妇人之情"）。
- 人品端邪辨：阳中之阴（外仁义而内奸诈）、阴中之阳（外凶险而内仁慈）、阳外阴内（包藏祸心）、阴外阳内（秉持直道）。要在气势顺正、四柱停匀。

### 2.5 精神、月令、生时

**精神（精/神/气）**

- 任氏定义：**精者生我之神（印），神者克我之物（官杀），气者本气贯足**；精足则气旺，气旺则神旺。
- 原注以金水为精气、木火为神气（"由脏而论"：肺金肾水藏于里，肝木心火发于表，脾土贯周身），任氏以为论命当以生克实际论，不拘金木水火。
- 失调之象：**水泛木浮则木无精神，木多火炽则火无精神，火炎则金无精神，金多水弱则水无精神**。
- 救法：精太足宜益其气，气太旺宜助其神，神太泄宜滋其精。

**月令（提纲）**

- 月令为"提纲之府，譬之宅也"；人元为用事之神，"譬之宅之定向，不可以不卜"。
- **取格之法**：先观月令所得何支 → 次看天干透出何神 → 再究司令以定真假 → 然后取用以分清浊。
- 立法：**人元必须司令，则能引吉制凶；司令必须出现，方能助格辅用**。天干为用必要地支司令，地支人元必得天干引助。
- "门地两旺/门地同来衰"四象：地支司令而天干不助（地衰门旺）、天干得用而地支不载（门旺地衰）皆吉凶参半；司令之神来助而为日主所喜者福力非常，司令之神与日主所忌同来（如戊土司令而木透干支藏水）则祸生不测。

**生时（归宿）**

- 生时为"归宿之地，譬之墓也"；时之人元用事为"墓之定方"。
- 子时前三刻三分壬水用事（夜子时，亥中余气）、后四刻七分癸水用事；余时亦有前后用事，从司令一例推。
- **时之人元与月令人元用事相附**：为日主所喜者加倍兴隆，为日主所忌者必增凶祸。
- 穴向喻：丙日亥时（亥中壬为丙之煞）得甲木用事 → 穴凶向吉；辛日未时（未中己为辛之印）得丁火用事 → 穴吉向凶。穴吉向凶减其吉，穴凶向吉减其凶。
- 但"人元用事，到底不比提纲司令之为重"；时有不的确者十之四五。同八字而百人各异，须究时之先后、山川之异、世德之殊、人品端邪。

### 2.6 格局取法与成破

**八格正变（任氏定则）**

- 正格（兼五行之常理）：官印、煞印、财煞、食神制杀、食神生财、伤官佩印、伤官生财。
- 变格（从五行之气势）：从财、从官杀、从食伤、从强、从弱、从势、一行得气、两气成形。
- 其余外格、奇格异局、纳音诸法，任氏"俱不从五行正理，尽属谬谈"。
- **成格条件**："格之真者，月支之神，透于天干也。"以散乱之天干寻其得所附于提纲，非格也。
- **月逢禄刃，无格可取** → 须审日主喜忌，另寻别支透出天干者借以为用。
- **格局不可执一**：不拘财官印绶等格，与日主无干；**旺则宜抑，衰则宜扶；印旺泄官宜财星，印衰逢财宜比劫**，此不易之法。

**形象（两气成象 / 五气成形）**

- **两气合而成象，象不可破**：天干属木地支属火、天干属火地支属木之类，见金水则破。相生各半五局（土金、金水、水木、木火、火土），相克各半五局（木土、土水、水火、火金、金木）亦可成象；**相克务须均敌，切忌偏重偏轻**。
- 行运："一路澄清，必位高而禄重；中途混乱，恐职弃而家倾。"木火成象最怕金水破局，水火既济尤忌土来止水。
- 两气成象，**要日主去生（食神或伤官）**："英华秀发，多致富贵"；印绶格（金水、水木）无秀可取故无富贵。
- **五气聚而成形，形不可害**：木之成形——食伤泄气以水生之，官杀交加以火行之，印绶重叠以土培之，财轻劫重以金成之。四柱无成、岁运又无成处，则终身碌碌。
- **独象（曲直、炎上、稼穑、从革、润下）**：木日或方或局全不杂金为曲直，火日不杂水为炎上，土日四库皆全不杂木为稼穑，金日不杂火为从革，水日不杂土为润下。必要得时当令、遇旺逢生。**喜行化地（食伤），而化神要昌**。行金运为破局凶多吉少。
- **全象喜行财地，而财神要旺**（"三者为全"：伤官生财固全；官印相生、财官并见亦是全）。任氏分四则：日主旺伤官轻有印绶 → 喜财不喜官；日主旺财神轻有比劫 → 喜官不喜财；财官并见日主旺相 → 喜财不喜官；官印相生日主休囚 → 喜印不喜比劫。
- **形全者宜损其有余，形缺者宜补其不足**——即"旺则宜泄宜伤，衰则喜帮喜助"，但须四字分用：
  - 日主旺相、柱中财官无气 → **伤之有利而泄之有害**（泄则损官星，伤则去比劫补官星）。
  - 日主旺相、满局比劫、财官不见 → **伤之有害而泄之有利**（伤之则激，不若泄以顺其气势）。
  - 日主衰弱、财星重叠 → **帮之则吉而助之则凶**（助则印坏）。
  - 日主衰弱、官杀交加满盘杀势 → **帮之则凶而助之则吉**（不若以印化其强暴）。
  - 原注之"木生寅卯辰为形全、戊生寅卯辰为形缺"被任氏斥为偏论：须究旺中变弱、弱中变旺之理。

**方局**

- 三字全为成方（寅卯辰东、巳午未南、申酉戌西、亥子丑北）；三支合为局（亥卯未木、寅午戌火、巳酉丑金、申子辰水），皆取生旺墓一气始终。**方之力较胜于局**；"局之用多，而方之用狭"。
- 方局相混：任氏以为无害——木见亥为生旺之神、见未为我克之财又为盘根之地；辰为余气湿土能生助木神。"**成方干透一元神，生地库地皆非福**"须看气势：若属从强则生地库地亦能发福，若财官无气再行生地库地则刑耗多端。
- 会局之破：凡会忌冲——杂一冲字而与所冲之神**紧贴**是为破局；冲字杂处其中而不紧贴，或冲字在外而紧贴，则不作破论。二支会局者**以相贴为妙，逢冲即破**，他字间之亦遥隔无力，须天干领出可用。
- **成局干透一官星，左边右边空碌碌**：如亥卯未全而干见庚辛（木之官杀）虚脱无气，余干有土亦休囚难生金，须地支有一申酉丑字为美；若无申酉丑反加寅辰，则木势愈盛金势愈衰，碌碌终身。得岁运去其官星亦可发达，但必要柱中先见食伤。
- **方局一齐来，须是干头无反复**：支全方局其气旺盛，要天干顺其气势（日主是木须天干有火泄其精英，不见金水）；若天干有火而见水，或无火而见金，谓之干头反复（例：甲寅丁卯乙亥癸未，癸水透干紧伤丁火秀气，一衿尚不能博）。
- 判语：**干乃领袖之神，阳气为强阴气为弱；支乃会格之物，方力较重局力较轻。独象虽美，只怕运途破局；合象虽难，即喜制化成功。**

### 2.7 清浊、真假、源流、通关

**清气**

- 清非"全而不缺、生而不克"：正官格身旺有财、身弱有印，并无伤官七杀杂之，纵有比肩食神财煞印绶杂之而皆循序得所、有安顿、或作闲神不来破局，乃为清奇；**又要有精神，不为枯弱者佳**。
- 浊：如正官格身弱混之以煞、混之以财，以食神杂之不能伤我之官反与官星不和，以印绶杂之不能扶我之身反与财星相戕。
- 澄浊求清之法：得一神有力，或行运得所，扫其浊气、冲其滞气。
- **情势贴身论**（任氏独法）：财与官贴、官与印贴、印与日主贴 → 财生官、官生印、印生身，印之源头更长 → 富贵。印星无气与官星不通、或印太旺日主枯弱不受生、或官星贴日而印星远隔 → 日主先受官克、印不能生化 → 不贫亦夭。伤官与财贴、财与官贴、官与比肩贴 → 伤官化劫生财、财生官旺；伤官与财远隔反与官紧贴 → 不贫亦贱。
- 通则：**喜神宜得地逢生、与日主紧贴者佳；忌神宜失势临绝、与日主远隔者美**。

**浊气**

- 浊之源：正神失势邪气乘权（气之浊）；提纲破损另求别用（格之浊）；官衰喜印而财星坏印（财之浊）；官衰喜财而比劫争财（比劫之浊）；财旺喜劫而官星制劫（官之浊）；财轻喜食伤而印绶当权（印之浊）；身强杀浅而食伤得势（食伤之浊）。
- **宁使清中浊，不可清中枯**：浊者虽成败不一，遇行运得所扫除浊气亦有起发之机；清枯者日主无根或用神无气，"日主枯者非贫即夭，用神枯者非贫即孤"。

**真神 / 假神**

- **真者得时秉令之神，假者失时退气之神**。日主所用之神在提纲司令又透出天干，谓"聚得真"，不为假神破损则生平富贵。
- 纵有假神，安顿得好（不与真神紧贴，或被闲神合住，或遥隔无力）亦无害；倘与真神紧贴、或相克相冲、或合真神暗化忌神 → 终为碌碌庸人。
- 行运得助、抑假扶真 → 亦可功名小遂。**"喜宜四生，忌神宜四绝，局内看真神，行运看解神。"**
- 真假参差：真神得令而假神得局党多，或假神得令而真神得局党多，真假不能辨其胜负 → 一生迍否少安乐。
- 取用变通：气有真假——真神失势假神得局，法当"以真为假、以假为真"；气有先后——真气未到假气先到，法当"以真作假、以假作真"。**一切取决于日主之爱憎**：日主爱假憎真，须岁运扶真抑假；若岁运助真损假，凶祸立至。
- 经验判语：安享荫庇现成之福者真神得用居多；创业兴家劳碌少安逸者假神得局居多，或真神受伤；一生起倒、世事崎岖者假神不足居多。

**源流**

- 源头即四柱中之旺神（不论财官印绶食伤比劫皆可为源头）。**看源头流到何方，流去之处是所喜之神即在此住了，乃为好归路**；未曾流到吉方而中间遇阻节，看阻住之神何神以断休咎。
- 流住之人事对应：起于年月是食印、住于日时是财官 → 上叨祖父之荫、下享儿孙之福；起于年月官、住于日时伤劫 → 破败祖业、刑妻克子；流住年是官印 → 祖上清高，是伤劫 → 祖上寒微；流住月是财官 → 父母创业，是伤劫 → 父母破败；流住日时是财官食印 → 白手成家或妻贤子贵，是伤劫枭刃 → 妻陋子劣或因妻招祸破家受辱。
- 阻节之神断六亲：阻节是印绶 → 长辈之祸（柱有财制则得妻贤之助，有比劫化则得兄弟相扶）；阻节是比劫 → 兄弟之累（有官制则得贤贵之解，有食伤化则得子侄之助）；阻节是财星 → 妻妾之祸；阻节是食伤 → 子孙之累；阻节是官煞 → 官刑之祸。
- **收局一字定贵贱**："凡富贵者，未有不从源头也。分其贵贱，全在收局一字定之。**去我浊气作我喜神，不贵亦富；去我清气作我忌神，不贫亦贱。**"

**通关**

- 定义：引通克制之神。木土而要火、火金而要土、土水而要金、金木而要水，皆"牛郎织女之有情"。
- 原局无印必须岁运逢印向而通之，或暗会明合而通之；局内有印被财星损坏（或官星化之、比劫解之、被合住则冲开之、被冲坏则合化之、隔一物则克去之）。
- 杀重喜印、杀露印亦露、煞藏印亦藏 → 显然通达，不必节外生枝；年印时杀、干杀支印前后远立上下悬隔 → 原局无可通之理，必须岁运暗冲暗会、克制间神忌物。杀印之论如此，食伤财官之论亦如此。

### 2.8 官杀（含"杀分六等"）

**混杂可不可混之判**

- 总纲：**日主旺相可混也，日主休囚不可混也**。官杀混杂者富贵甚多。
- 非混之例：天干甲丙戊庚壬为杀而地支卯午丑未酉子（杀之旺地）非混；天干乙丁己辛癸为官而地支寅巳辰戌申亥（官之旺地）非混。杀重官从之非混；官轻杀助之非混。
- 宜去之例：干甲乙支寅、干丙丁支巳、干戊己支辰戌、干庚辛支申、干壬癸支亥 → 以官混杀宜去官；干甲乙支卯、干丙丁支午、干戊己支丑未、干庚辛支酉、干壬癸支子 → 以杀混官宜去杀。
- 从势之例：年月两干透一杀、年月支中有财、时遇官星无根 → 官从杀势非混；年月两干透一官、年月支中有财、时遇杀星无根 → 杀从官势非混。
- 为混之例：势在于官官得禄而依官之杀年干助杀；势在于杀杀得禄而依杀之官年干助官。
- 其余：败财合杀、比肩敌杀 → 官可混；比肩合官、劫财挡官 → 杀可混；一官而印绶重逢官星泄气、杀助之 → 非混；一杀而食伤并见制杀太过、官助之 → 非混。官杀并透无根、四柱劫印重逢 → 不但喜混，尚宜财星助官杀。
- 去官两面：**用食用伤皆可；合杀总为美事**（合来合去宜清）。藏官露杀、干神助杀、合官留杀 → 皆成杀气，勿使官混；藏杀露官、干神助官、合杀留官 → 皆从官象，不可使杀混。
- 吉凶条目：独杀乘权无制伏 → 职居清要；众杀有制主通根 → 身掌权衡；杀生印、印生身 → 龙墀高步；身任财而财滋杀 → 雁塔题名；杀重身轻 → 非贫即夭；杀微而制过 → 虽学无成。**"格格推详，以杀为重""有杀只论杀，无杀方论用"。**

**杀分六等（任氏自定，附命例）**

1. **财滋弱杀格** → 身旺杀弱，以财生杀（例：己酉丙寅庚申庚辰；丙申庚寅庚申辛巳）。要点：财与杀两字缺一不可，"春金虽不当令，地支两逢禄旺又得印比帮身，弱中变旺"，则用财滋杀。
2. **杀重用印格** → 众杀横行，一仁可化（例：戊子甲寅戊午甲寅；戊辰庚申甲子甲子；癸亥癸亥丁卯癸卯）。
3. **食神制杀格** → 一将当关，群凶自败（例：戊辰戊午壬辰甲辰；庚申庚辰甲戌丙寅；壬子壬子丙戌戊戌；壬申丙午庚午丙戌）。
4. **合官留杀格** → 合而不化反喜其合（例：癸丑戊午丙午壬辰；癸巳戊午丙午壬辰〔铁樵自造〕；戊午癸亥丙戌壬辰）。要点：**合而化则有情变为无情**（化火仍生土），**合而不化则有情**。
5. **官杀混杂格** → 官杀当令必要坐下印绶（则官杀之气流通生化有情）或气贯生时（亦足以扶身敌杀）；若不当令又不坐印不气贯生时 → 不贫亦贱。
6. **制杀太过格** → **"与其制杀太过，不若官杀混杂之美"**：制杀太过则杀既伤残，再行制煞之运九死一生（例：辛卯戊戌丙辰己亥；壬辰丙午丙午壬辰；甲寅戊辰壬辰壬寅；庚申戊寅戊寅庚申）。

### 2.9 伤官（六格）与伤官见官

**可见不可见之判（原注）**：身弱伤官旺见印而可见官；身旺伤官旺见财而不见官；伤官旺财神轻有比劫而可见官；日主旺伤官轻无印绶而可见官。反之：伤官旺而无财、伤官旺而身弱、伤官弱而财轻、伤官弱而见印 → 一见官而有祸。**大率伤官有财皆可见官，伤官无财皆不可见官**；又须看身强身弱与何财官印比。

**任氏定则**

- 日主旺、伤官亦旺 → 宜用财；有比劫可见官，无比劫有印绶不可见官。
- 日主弱、伤官旺 → 宜用印，可见官而不可见财。
- 日主弱、伤官旺、无印绶 → 宜用比劫，喜见劫印，忌见财官。
- 日主旺、无财官 → 宜用伤官，喜见财伤，忌见官印。
- 日主旺、比劫多、财星衰、伤官轻 → 宜用官，喜见财官，忌见伤印。
- **"伤官见官，为祸百端"专指日主衰弱用比劫帮身者**：见官则比劫受克所以有祸；**若局中有印，见官不但无祸而且有福**。

**行运吉凶**

| 格 | 喜运 | 忌运 |
|---|---|---|
| 伤官用印（局内无财） | 印旺身旺之乡 → 显贵 | 财旺伤旺之乡 → 贫贱 |
| 伤官用财（财星得气） | 财旺伤旺之乡 → 富厚 | 印旺劫旺之地 → 贫乏 |
| 伤官用劫 | 运逢印旺必贵 | — |
| 伤官用官 | 运逢财旺必富 | — |
| 伤官用伤 | 运遇财乡，富而且贵 | — |

**六格与命例**：伤官用印（己丑辛未丙寅己丑；辛酉丁酉戊午辛酉；壬戌壬子庚辰己卯）、伤官用财（丙申戊戌丁卯乙巳；癸亥乙卯壬申乙巳；戊子辛酉戊午丁巳；壬申辛亥辛酉庚寅）、伤官用劫（癸亥辛酉戊申己未；己未癸酉戊戌庚申；癸亥甲寅癸亥甲寅）、伤官用伤官（庚辰己卯壬辰庚子；乙酉戊寅癸酉癸丑；己卯庚午甲寅丁卯；丙子乙未丙辰乙未）、伤官用官（壬戌己酉戊戌乙卯；庚午己卯壬申己酉；辛未辛卯壬辰己酉；癸酉己未丙午癸巳）、假伤官（戊申戊午丁巳乙巳；戊午丙辰戊辰辛酉等）。

**伤官格清浊（性情章）**：真者月令伤官或支会伤局又透天干，身弱有印不见财为清；假者满局比劫无官星以制之（虽有官而气力不敌），身旺有财不见印为贵。**凡伤官格只不宜见印，见印破伤为凶**。

### 2.10 从象、化象、假从、假化、顺局、反局

**从象（任氏定四从，自谓"诸书所未载，余之立说，试验确实"）**

- **从旺**：四柱皆比劫，无官杀之制，有印绶之生，旺之极者从其旺神。运行比劫印绶则吉（原文作"运行比劫印绶制则吉"，"制"字于文义不合，疑为"顺"或"继"之讹）；印轻行伤食亦佳；**官杀运谓之犯旺，凶祸立至；遇财星群劫相争，九死一生**。
- **从强**：印绶重重、比劫叠叠、日主又当令，绝无一毫财星官杀之气，"二人同心"强之极。行比劫运吉，印绶运亦佳；**食伤运有印绶冲克必凶，财官运为触怒强神大凶**。
- **从气**：不论财官印绶食伤，气势在木火要行木火运，气势在金水要行金水运，反此必凶。
- **从势**：日主无根，四柱财官食伤并旺不分强弱，又无劫印生扶，又不能从一神而去 → 惟和解。视财官食伤中孰独旺则从旺者之势；三者均停则**行财运以和之**（引通食伤之气助财官之势）则吉，官杀运次之，食伤运又次之，**行比劫印绶必凶无疑**。
- 从财之常：日主孤立无气、无生扶之意、满局财星 → 从财。既从，当论所从之神（如从财，财神是木而旺，看意向要火要土要金，行运得所者吉）。**从财格必要食伤吐秀**（不但功名显达，且一生无大起倒凶灾）；最忌比劫运，柱中有食伤能化比劫生财故妙。

**化象**

- 合化真源：依洛书之数（甲一乙二丙三丁四戊五己六庚七辛八壬九癸十），五居中——一得五为六故甲己合，二得五为七故乙庚合，三得五为八故丙辛合，四得五为九故丁壬合，五得五为十故戊癸合。**"合则化，化亦必得五土而后成，五土者辰也"**；十干之合至五辰之位则化气之元神发露（甲己起甲子至五位逢戊辰而化土……戊癸起壬子至五位逢丙辰而化火）。
- **真化条件**（原注）：甲日生四季月，单遇一位己土在月时上合，遇壬癸甲乙戊而有一辰字，乃为化得真；丙辛生冬月、戊癸生夏月、乙庚生秋月、丁壬生春月，独自相合又得龙（辰）以运之，此为真化。
- **化神取用**：化神旺而有余 → 宜泄化神之神为用；化神衰而不足 → 宜生助化神之神为用。如甲己化土生未戌月（土燥而旺、干透丙丁、支藏巳午）为有余，再行火土必太过不吉——柱中有水要行金运，有金要行水运，无金无水而土势太旺秘要金泄之，火土过燥要带水之金运以润之。生丑辰月（土湿为弱）为不足——柱中有金要行火运，有水要行土运，金水并见过于虚湿要带火之土运以实之。
- **争合妒合之说**："既合而化，如贞妇配义夫，从一而终，不生二心"——真化者见戊己（彼之同类）、见甲乙（我之本气）有相让之谊，不作争妒论；合而不化者勉强，见戊己多而起争妒之风，遇甲乙众而更强弱之性。

**假从**：日主根浅力薄不能自立，局中虽有劫印亦自顾不暇，只得投从于人。与真从大同小异。四柱财官得时当令、日主虚弱无气，虽有比劫印绶生扶而柱中食神生财（财仍破印）、或有官星制劫（日主无从依靠），则依财官之势——财势旺则从财，官势旺则从官。**"假行真运"可富贵**：从财有比劫分争 → 行官杀运必贵、行食伤运必富；有印绶暗生 → 要行财运；有官杀泄气 → 要行食伤运。从官杀有比劫帮身 → 逢官运而名高；有食伤破官 → 行财运而禄重；有印绶泄官 → 要财运以破印。

**假化**：其象不一——合神真而日主孤弱、化神有余而日带根苗、合神不真而日主无根、化神不足而日主无气、既合化神而日主得劫印生扶、既合化而闲神来伤化气。取运示例：甲己之合生丑戌月（合神虽真而日主孤弱、秋冬气翕而寒又有金气暗泄）→ 岁运必须逢火去其寒湿；生辰未月（化神虽有余而辰乃木之余气、未是通根身库）→ 岁运必须土金之地去其木之根苗。乙庚之合日主是木生夏令（日主泄气无根、土燥不能生金）→ 必须（带水之）土以泄火养金；生冬令（金逢泄气不足、木不纳水无气）→ 必须带火之土解冻。丁壬之合日主是丁生春令 → 岁运必须逢水。丙辛之合日主是火生冬令（重重金水既合且化，嫌柱中有土暗损化神）→ 必须逢金土。

**顺局（从儿格）**

- 定义：**顺者我生之也**；"只见儿"者食伤多也；"构门闾"者月建逢食伤也（月为门户，必要食伤在提纲）；"不论身强弱"者四柱虽有比劫仍去生助食伤也；"吾儿又得儿"者必要局中有财以成生育之意也。
- 行运：**行运不背、逢财者未有不富贵者**；透气流行人必聪明出类、学问精通。**最忌印运**（印是我之父，父能生我，子必遭殃，无生育之意其祸立至），**次忌官运**（官能泄财又能克日，食伤与官星不睦，忘生育之意起争战之风，不伤人丁则散财）。

**反局（四则）**

- **君赖臣生**：印绶太旺之意（日主是木为君，局中之土为臣，四柱重逢壬癸亥子水势泛滥木气反虚）→ 必须用土止水则木中托根，破其印而就其财（犯上之意故为反局）。
- **儿能救母**：木为母火为子，木被金伤则火克金以生木（须分时候而论：土生冬令逢金水必冻，必须火以克金解水之冻；火遭水克生于春初冬尽，必须土来止水培木；土遇木伤生于冬末春初，必须用金伐木；金逢火炼生于春末夏初，必须水来克火；水因土塞生于秋冬，必须木以疏土）。
- **母慈灭子**：太旺谓之慈母反使火炽而焚灭（与君赖臣生之意相似，均是印旺；其关异者——君赖臣生局中印绶虽旺而柱中财星有气可用财破印；母慈灭子纵有财星无气未可以财破印，只得顺母之性助其子，岁运仍行比劫之地，一见财星食伤逆母之性灾咎必不免）。
- **夫健怕妻**：木是夫土是妻，木旺土多无金不怕，一见庚申辛酉则金克木；**重在一"健"字**——若日主不健则为财多身弱终身困苦；"夫健怕妻，怕而不怕，倡随之理然也"，运遇生旺扶身之地自然出人头地。又有五行颠倒之相生：水生土者制火之烈，火生水者敌金之寒，水生金者润地之燥，火生木者解天之冻。

### 2.11 战局、合局、君象、臣象、母象、子象

**战局**

- **天战犹自可，地战急如火**：天干气专而得地支安静，易于制化；地支气杂，天干虽顺静难于制化。**天干宜动不宜静（动则有用，静则愈专）；地支宜静不宜动（静则有用，动则根拔）**。必得合神有力、会神成局息其动气，或库神收其动神，"动中助静，以凶化吉"。
- 甲寅庚申、乙卯辛酉、丙寅壬申、丁卯癸酉之类天地交战，虽有合神会神亦不息其动气，其势速凶。
- **"两不冲一"为谬言**：两寅一申冲去一寅存一寅；两申逢一寅纵使不冲，金多木少亦能克尽。
- 用神伏藏或用神被合、柱中无引用之神 → **反宜冲而动之**方能发用。故"合有宜不宜，冲亦有宜不宜"。

**合局**

- **合有宜不宜，合多不为奇**。喜神有能合而助之者（以庚为喜神得乙合而助金）；凶神有能合而去之者（以甲为凶神得己合而去之）；闲神凶神有能合而化喜者（癸为凶神戊为闲神，戊癸合而化火为喜）；闲神忌神有能合而化喜者（壬为闲神丁为忌神，丁壬合而化木为喜）。
- 不宜之合：忌神得合而助之（己为忌神甲合之则助土）；羁绊喜神（乙是喜神庚合之则羁绊）；掩蔽动局（丑为喜神子午合之则闭）；助起凶神（不喜甲木而寅亥合之则助木）。
- 逢冲得合而静之则易：子午逢冲喜神在午而丑合之；寅申逢冲喜神在寅而亥合之 → 宜。
- 通则：**忌神合而不去不足为喜，喜神合而不来不足为美，反为羁绊贪恋而无用**；"大率多合则不流通、不奋发，虽有秀气亦不为奇"。

**君象**：君不可抗也，贵乎损上以益下。
- 日主为君，用神（财）为臣。如甲乙日主满局皆木而内有一二土气（君盛臣衰）→ 其势要多方助臣：**用火行之（火行则木泄、土得生扶），用土实之，金卫之**，庶下全而上安。
- **切忌以金制之**——木盛能令金自缺，"君仍不能抗，反触其怒，而臣更泄气，不但无益而有害"。

**臣象**：臣不可过也，贵乎损下而益上。
- 日主为臣，官星为君。如甲乙日主满盘皆木而内只一二金气（臣盛君衰）→ **须带火之土运**（木见火而相生则臣心顺，金逢土而得益则君心安）；若木火并旺不见火土则宜顺臣之心一路行火。
- **若纯用土金以激之，非安上全下之意。**

**母象**：日主为母，日之所生者为子（食伤）。
- 母众子孤（如甲乙日主满柱皆木、中有一二火气）：**一不可见水（见水子必伤）；二不可见金（见金则触母性）**。惟行带火土之运则母性降慈。

**子象**：日主为子，生日者为母（印）。
- 子众母衰（如甲乙日主满局皆木、中有一二水气）：**一不可见土（见土则子恋妇不顾母）；二不可见金（见金母势强而不容子）**。惟行带水之金运，使金不克木而生水。

（任氏自注：此四章虽主木论，火土金水亦如之。）

### 2.12 刚柔、顺逆、寒暖、燥湿、隐显、众寡、震兑、坎离

**刚柔**：**柔刚不一也，善为制者，但引其性情而已矣。**
- 得时当令、原局无克制之神 → 其势雄壮其性刚健，**不泄则不清，不清则不秀，不秀则为顽物**；若以刚斩其柔（强制），寡不敌众反激其怒而更刚。
- 失时无气、原局无生助之神 → 其势柔软其性至弱，**不劫则不辟，不辟则不化，不化则为朽物**；略以柔引其刚（弱扶），虚不受补反益其弱而更柔。
- 四字诀：**泄者有生生之妙，克者有成就之功，引者有和悦之情，从者有变化之妙**（克、泄、引、从宜详审）。
- 又以"以无入有，向实寻虚"为玄妙：得时当令四柱无克制之神 → 用食神顺其气势、泄其菁英、暗处生财，为"以无入有"；失时休囚原局无劫印帮身 → 用食神制杀，杀得制则生印，为"向实寻虚"。
- 具体：**庚金生七月必要壬水，乙木生八月必要丁火**——但若原局先有木火而壬水不见，不可弃明现之木火反用暗藏之壬水。

**顺逆**：**顺逆不齐也，不可逆者，其气势而已矣。**
- 不可逆者：当令得势之神（乘权得势局中之神，又去助其强暴，谓"二人同心"），或日主得时秉令、四柱皆拱合之神（谓"权在一人"）。只可顺其气势以引通之，若勉强得制，激怒其性必罹凶咎。
- 四句权变："制杀莫如乘旺，化杀正以扶身，从杀乃依权势，留杀正尔迎官。"
- **"浊中清，贵之机；清中浊，贱之根。逆来顺去富之基，顺来逆去贫之意。"**

**寒暖**：**天道有寒暖，发育万物，人道行之，不可过也。**
- 原注：阴支为寒、阳支为暖；西北为寒、东南为暖；金水为寒、木火为暖。得气之寒遇暖而发；得气之暖逢寒而成。五阳逢子月则一阳之候，万物怀胎，阳乘阳位可东可西；五阴逢午月则一阴之候，万物收藏，阴乘阴位可南可北。
- 任氏正之："寒虽甚，要暖有气；暖虽至，要寒有根" → 能生成万物。**"寒甚而暖无气"则反以无暖为美；"暖之至而寒无根"则反以无寒为美。**（例证：甲申丙子庚辰戊寅，寒金冷水赖寅时一阳解冻，更妙寅申遥冲为"动"，"凡四柱紧冲为克，遥冲为动"。）

**燥湿**：**地道有燥湿，生成品汇，人道得之，不可偏也。**
- 木生夏令精华发泄、外有余而内实虚脱 → 必藉壬癸生之、**丑辰湿土**培之；若见未戌燥土则反助火而不能晦火，纵有水亦不能为力。
- 金生冬令虽泄气休囚 → 竟可用丙丁；若见丑辰湿土则反助水而不能制水，纵有火亦不能为力。
- 原注要诀：火土而成其燥者吉，**木火伤官要湿**；土水而成其湿者吉，**金水伤官要燥**。间有土湿而宜燥者，用土而后用火；金燥而宜湿者，用金而后用水。

**隐显**：**吉神太露，起争夺之风；凶物深藏，成养虎之患。**
- 吉神太露者因天干气专易于劫夺（如天干以甲乙为财，岁运遇庚辛则起争夺；必须天干先有丙丁官星回克，或得壬癸食伤合化）→ 吉神宜深藏地支。
- 凶物深藏者因地支气杂难于制化（如家贼难防，养成祸患）→ 凶物宜明透天干，易于制化。
- 补充门槛：**吉神显露而通根当令者，露亦无害；凶物深藏而失时休囚者，藏亦无妨。**

**众寡**：**强众而敌寡者，势在去其寡；强寡而敌众者，势在成乎众。**
- 以日主分众寡：日主是火生寅卯巳午月、官星是水而四柱无财（或财无根气不能生官）反有土之食伤 → 日主党众敌官星之寡，势在尽去其官，岁运宜扶众抑寡则吉。
- 以四柱分众寡：须与日主符合弗反背。官星是水休囚无气、土是伤官当令得时 → 其势在去其官星，岁运宜制官为美，但日主是火亦要通根得气方能生土，或有木克土则日主自能化木（转转相生）。
- 官星是水虽不及时却有财生助（或财星当令或成财局）→ 官星虽寡得财星扶则强，岁运宜**扶寡而抑众**者吉。

**震兑（金木）**：**震兑主仁义之真机，势不两立，而有相成者存。**
- 任氏立五法：**攻、成、润、从、暖**——
  - 春初之木，木嫩金坚 → 火以攻之；
  - 仲春之木，木旺金衰 → 土以成之；
  - 夏令之木，木泄金燥 → 水以润之；
  - 秋令之木，木凋金锐 → 土以从之；
  - 冬令之木，木衰金寒 → 火以暖之。
- 判语："若内外之说，不过衰旺相敌之意也。**当泄则泄，当制则制，须观其金木之竟向**，不必拘执而分内外。"（原注之"震内兑外、兑内震外、主喜在震以兑为敌国必用火攻"等说，任氏以五法易之。）

**坎离（水火）**：**坎离宰天地之中气，成不独成，而有相持者在。**
- 任氏立五法：**升、降、和、解、制**——
  - **升**：天干离衰、地支坎旺，必得地支有木，则地气上升；
  - **降**：天干坎衰、地支离旺，必得天干有金，则天气下降；
  - **和**：天干皆火、地支皆水，必须有木运以和之；
  - **解**：天干皆水、地支皆火，必须有金运以解之；
  - **制**：水火交战于干支，必须岁运视其强者而制之。
- 原注之别：天干透壬癸地支属离为既济（要天气下降）；天干透丙丁地支属坎为未济（要地气上升）；天干皆水地支皆火为交媾（交媾身强则富贵）；天干皆火地支皆水为交战（交战身弱岂能富贵）。

### 2.13 岁运与大运流年法则

**大运**

- 富贵虽定乎格局，**穷通实系乎运途**。日主如我之身，局中喜用是我所用之人，运途乃我所临之地，**故以地支为重**。要天干不背、相生相扶为美。
- **一运看十年，切勿上下截看，不可使盖头截脚**（上下截看则吉凶不验）。
- 干支优劣（喜行某运时的具体干支表）：
  - 喜木运：必要甲寅乙卯，次则甲辰、乙亥、壬寅、癸卯；
  - 喜火运：必要丙午丁未，次则丙寅、丁卯、丙戌、丁巳；
  - 喜土运：必要戊午、己未、戊戌、己巳，次则戊辰、己丑；
  - 喜金运：必要庚申辛酉，次则戊申、己酉、庚辰、辛巳；
  - 喜水运：必要壬子癸亥，次则壬申、癸酉、辛亥、庚子。
  - **宁使天干生地支，弗使地支生天干**（天干生地支则荫厚，地支生天干则气泄）。
- **盖头**：喜木运而遇庚寅辛卯，喜火运而遇壬午癸巳，喜土运而遇甲戌甲辰乙丑乙未，喜金运而遇丙申丁酉，喜水运而遇戊子己亥 → 吉凶减半。
- **截脚**：喜木运而遇甲申乙酉乙丑乙巳，喜火运而遇丙子丁丑丙申丁酉丁亥，喜土运而遇戊寅乙卯戊子己酉戊申，喜金运而遇庚午辛亥庚寅辛卯庚子，喜水运而遇壬寅癸卯壬午癸未壬辰癸巳 → **支不载干，则十年皆否**。
- 举例算法：喜行木运而遇庚寅辛卯——庚辛本为凶运，而"金绝寅卯"谓之无根，虽有十分之凶减其半；若原局天干有丙丁透露得回制之能又减其半；再遇太岁逢丙丁制庚辛则无凶。寅卯本为吉运，因盖头有庚辛之克，虽有十分之吉亦减其半；若原局地支有申酉之冲，不但无吉而反凶。

**太岁（流年）**

- **太岁管一年否泰，如所遇之人，故以天干为重**，然地支不可不究。
- 最凶者**天克地冲**；岁运冲克，日主旺相虽凶无碍，日主休囚必罹凶咎。
- **日犯岁君**（日主克太岁）：日主旺相无咎，日主休囚必凶；**岁君犯日**同此论。
- 判语："大运看地支，太岁看天干，运途与日主之冲战尤重。"

**战（克）**

- 如丙运庚年谓之"运克岁"：日主喜庚 → 要丙坐子辰、庚坐申辰，又局中得戊己泄丙、得壬癸克丙则吉；如丙坐午寅、局中又无水土制化则必凶。
- 如庚运丙午谓之"岁克运"：日主喜庚则凶，喜丙则吉；喜庚者要庚坐申辰、丙坐子辰，又局中逢水土制化者吉，反此必凶。

**冲（破）**

- 子运午年谓之"运冲岁"：日主喜子 → 要干头逢庚壬（助子），午之干头逢甲丙（助午）亦无咎；如子之干头遇丙戊、午之干头遇庚壬，亦有咎。
- 日主喜午：子之干头逢甲戊、午之干头遇甲丙则吉；如子之干头遇庚壬、午之干头逢丙戊亦凶。

**和（合）**

- 乙运庚年、庚运乙年则和：**合而能化，喜金则吉**（喜庚亦然，必要木金得地、乙木无根则合化为美）；**合而不化反为羁绊**，不顾日主之喜我则不吉。子运丑年、丑运子年，日主喜土则吉，喜水则不吉（子丑之合不化亦是克水）。

**好（同类）**

- 庚运申年、辛运酉年是为真好（支之禄旺，自我本气归垣，如家室之可住）；庚运辛年、辛运卯年乃天干之助（如朋友之帮扶，究竟不甚关切）。**必先要旺运通根，自然依附为好；如运无根气，其见势衰而无依附之情，非为好也。**

**贞元**

- 以八字看：**年为元、月为亨、日为利、时为贞**；年月吉者前半世吉，日时吉者后半世吉。
- 以大运看：**初十五年为元，次十五年为亨，中十五年为利，后十五年为贞**；元亨运吉者前半世吉，利贞运吉者后半世吉。
- **身后运**：人既终之后行运仍在，观其运之吉凶可知子孙之兴替——身后运吉则家兴旺，身后运凶则家衰败（"父为贞，子为元"，贞下起元，生生不息之机）。岁运所喜则其家必兴，所忌则其家必替。

### 2.14 六亲专论

#### 夫妻（以财论妻）

- **六亲正名（任氏重定）**：生我者为父母（偏正印绶）；我生者为子女（食神伤官）；我克者为妇妾（偏正财星）；克我者为官鬼（祖父）；同我者为兄弟（比肩劫财）。**任氏力斥"以财为父、以官为子"**（谓失伦常、翁妇同宗）。
- 判妻总法：**财星清则中馈贤能（喜神即是财星，不争不妒）；财神浊则河东狮吼（生煞坏印，争妒无情）**。旧书"阳刃劫财主克妻"之说须分日主衰旺喜忌。
- 克妻条件表：
  - 财神轻而无官、比劫多 → 主克妻。
  - 财神重而身弱、无比劫 → 主克妻。
  - 官杀旺而用印、见财星 → 主妻陋而克。
  - 官杀轻而身旺、见财星、遇比劫 → 主妻美而克。
  - 劫刃重、财星轻、有食伤、逢枭印 → 主妻遭凶死。
  - 财星微、官杀旺、无食伤、有印绶 → 主妻有弱病。
  - 劫刃旺而财轻、有食伤 → 妻贤不克，妻陋必亡。
  - 官星弱、遇财星 → 妻陋不克。
- 妻贤而美（或得妻财致富）之条件：身强煞浅而财星滋杀；官轻伤重而财星化伤；印绶重叠而财星得气。
- 妻不贤而陋（或因妻招祸伤身）之条件：杀重身轻而财星党杀；官多用印而财星坏印；伤官佩印而财星得局。
- 求财法：**日主坐财而财为喜用者必得妻财**；日主喜财而财合闲神化财者必得妻力；日主喜财而财合闲神化忌神者主妻有外情；日主忌财而财合闲神化财者主琴瑟不和。
- 财星浮泛 → 宜财库以收藏；财星深伏 → 宜冲动而引助。

#### 子女

- 任氏重定：**以食神伤官为子女**（斥"以官为子"为犯上）。"喜神看与杀相连"乃通变之至论——先将食伤认定，再看日主衰旺、四柱喜忌。
- 多子条件：日主旺无印绶有食伤 → 子必多；日主旺印绶重食伤轻有财星 → 子多而贤；日主旺印绶多无食伤有财星 → 子多而能。
- 无子/少子条件：日主旺印绶重食伤轻 → 子必少；日主弱印绶轻有财星 → 子必无；日主弱食伤重印绶无 → 亦无子；日主弱食伤轻无比劫有官星 → 子必无；日主弱官杀重印绶轻微伏财 → 必多女；日主弱七杀重食伤轻有比劫 → 女多子少；日主弱官杀重无印比 → 子必无。
- 其他：日主旺食伤轻逢印绶遇财星 → 子少孙多；日主旺印绶重官杀轻有财星 → 子虽克则有孙；日主旺食伤旺有印绶遇财星 → 虽有若无；日主弱官杀旺有印绶遇财星 → 有子必逆。
- 逆局反克相生法：日主旺无印绶食伤伏有官杀 → 子必多；日主旺比劫多无印绶食伤伏 → 子必多（"母多灭子"之意）。**木多火熄，金克木则生火；火多土焦，水克火则生土；土重金埋，木克土则生金；金多水渗，火克金则生水；水多木浮，土克水则生木。**
- 总括："大率身旺财为子，身衰印作儿。"（附注：**用神为子，忌神为女**）
- 数目之推：命中子只有五数，**水一、火二、木三、金四、土五**；当令者倍之，休囚者减半。
- 得子之年：**凡八字之用神即是子星**——用神是火，其子必在木火运或木火流年得；如不是木火运年得，必子息命中多木火，或木火日主，否则难招或不肖。

#### 父母（年月所关）

- 原注：岁气有益于月令者、岁月不伤喜神者 → 父母必昌；岁月财气斩丧于时干者先克父；岁月印气斩丧于时支者先克母。
- 任氏重定为"丧亲、刑妻、克子"之说，以年月与日主喜忌断：
  - 年月官印相生日时财伤不犯 → 上叨荫庇、下受儿荣；年月官印相生日时刑伤冲犯 → 破荡祖业、败坏门风。
  - 年官月印、月官年印 → 祖上清高。
  - 日主喜官而时日逢伤；日主喜印而时日逢财 → 必败祖辱宗。
  - 年财月印、日主喜印、时日逢官印 → 帮父兴家。
  - 年伤月印、日主喜印、时日逢官 → 父母创业之命。
  - 年印月财、日主喜印、时上遇官 → 父母破败；时日逢印 → 自创成家。
  - 年官月印、日主喜官、时日逢财 → 出身富贵，守成之造。
  - 年伤月劫、日主喜财、时日逢财或伤 → 出身寒窘，创业之命。
  - 年劫月财、日主喜财 → 遗绪丰盈；日主喜劫 → 清高贫寒。
  - 年官月伤、日主喜官 → 时日适官必跨灶，时日遇劫必破败。
- 通则：**财官印绶在于年月，为日主之喜，父母不贵亦富；为日主之忌，不贫亦贱。**

#### 兄弟

- 原注：败财比肩羊刃皆兄弟，要在提纲之神与财神喜神较其重轻。
  - 财官弱而三者显其攘夺之迹 → 兄弟必强；
  - 财官旺而三者出其助主之功 → 兄弟必美；
  - 身与财官平而三者伏而不出 → 兄弟必贵；
  - 比肩重而伤官财杀亦旺 → 兄弟必富；
  - 身弱而帮者不显、有印 → 兄弟必多；
  - 身旺而三者又显、无官 → 兄弟必衰。
- 任氏条目：杀旺无食、杀重无印而得败财合杀 → 必得弟力；杀旺食轻、印弱逢财而得比肩敌杀 → 必得兄力；财轻劫重、印绶制伤 → 不免司马之忧；财官失势、劫刃肆逞 → 周公之虑；财轻劫重而食伤化劫 → 可无斗粟尺布之谣；财轻遇劫而官得明显 → 不作煮豆燃萁之咏。
- 总断："**总之劫刃太旺、财官无气，兄弟反少，纵有不如无也。然官杀太旺亦伤残，必须身财并旺、官印通根，可敦友爱之情。**"

#### 何知章（富贵贫贱吉凶寿夭）

**富 —— 财气通门户**

| 条件 | 断 |
|---|---|
| 身旺财弱无官 | 必要有食伤 |
| 身旺财旺无食伤 | 必须有官有杀 |
| 身旺印旺食伤轻 | 财星得局 |
| 身旺官衰印绶重 | 财得当令 |
| 身旺劫旺，无财印而有食伤 | 财气通门户 |
| 身弱财重，无官印而有比劫 | 财气通门户 |

- 原注："财旺身强，官星卫财；忌印而财能坏印，喜印而财能生官；伤官重而财神流通，财神重而伤官有限；无财而暗成财局，财露而伤亦露者" → 皆富。
- 妻财之辨：身旺有印、官星泄气、四柱不见食伤而得财星生官 → 主妻美而财薄；身旺无印、官弱逢伤而得财星化伤生官 → 不特妻美而且富厚；身旺官弱、食伤重见、财星不与官通 → 家虽富而妻必陋；身旺无官、食伤有气、财星不与劫连 → 无印则妻财并美，有印则财旺妻伤。
- **"凡巨富之命，财星不多，只要生化有情，即是财气通门户。"**

**贵 —— 官星有理会**

| 条件 | 断 |
|---|---|
| 身旺官弱 | 财能生官 |
| 官旺身弱 | 官能生印 |
| 印旺官衰 | 财能坏印 |
| 印衰官旺 | 财不现 |
| 劫重财轻 | 官能去劫 |
| 财星坏印 | 官能生印 |
| 用官 | 官藏财亦藏 |
| 用印 | 印露官亦露 |

- 无子之贵：身旺官旺印亦旺而四柱食伤一点不混、财星不出现 → 官星之情依乎印、印之情依乎日主，只生得一个本身，**所以有官无子**。
- 子息分辨：身旺官旺印弱而食伤暗藏不伤官不受印克 → 自然贵而有子；身旺官衰、食伤有气、有印而财有坏印、无才而暗成财局 → 不贵而子必富；身旺官衰、食伤旺而无财 → 有子必贫；身弱官旺、食伤旺而无印 → 贫而无子，或有印逢财亦同此论。

**贫 —— 财神反不真（任氏列九不真）**

1. 财重而食伤多；2. 财轻喜食伤而印旺；3. 财轻劫重而食伤不现；4. 财多喜劫而官星制劫；5. 喜印而财星坏印；6. 忌印而财星生官；7. 喜财而财合闲神而化；8. 忌财而财合闲神化财；9. 官杀旺而喜印、财星得局。

- 贫三等：贫而贵（财轻官衰逢食伤而见印绶，或喜印而财坏印得官星解）；贫而正（官杀旺而身弱、财星生助官杀，有印则一衿易得，无印则老儒冠）；贫而贱（财多而心必欲贪、官旺而心志必欲求之，非合而合、不从而从、合之不化、从之不真）。
- 原注："伤轻财重伤气泄，财轻官重财气泄，伤重印轻身弱，财重劫轻身弱，皆为财神不真也。**中有一味清气，则不贱。**"

**贱 —— 官星还不见**

- 原注："身轻官重，官轻印重，财重无官，官重无印者，皆是官星不见也。**中有一味浊财，则不贫。**"
- 三等官星不见：
  - **上等**：官轻印重而身旺，或官重印轻而身弱，或官印两平而日主休囚者 → 学问真确、处世无苟、苦守清贫。
  - **下等**：官旺喜印而财星坏印，或官杀重无印而食伤强制，或官多忌财而财星得局，或喜官星而官星合他神化伤，或忌官星而他神合官星又化官者。
- 任氏之辨："富贵之中未当无贱，贫贱之中未当无贵"——身弱官旺不用印绶化之反以伤官强制、身弱印轻不以官星生印反以财星坏印、财重身轻不以比劫帮身反以比劫夺财 → 灾生不测殃及子孙。

**吉 —— 喜神为辅弼**

- 喜神者辅用助主之神。**凡八字先要有喜神，则用神势，一生有吉无凶。**
- 有用神而无喜神：岁运不逢忌神无害，一遇忌神必凶。例：戊土生寅月以寅中甲木为用，忌神必是庚辛申酉之金；日主元神厚者以壬癸亥子为喜神（金见水而贪生不来克木）；日主元神薄者以丙丁巳午为喜神（金见火而畏亦不来克木）。
- 用官用印之别：**用官者身旺可以财为喜神；用印身弱者而后用官为喜神。**
- 无喜神而用神得秉令、气象雄壮、大势坚固、四柱安和、用神紧贴不争不妒者 → 即遇忌神亦不为凶。

**凶 —— 忌神辗转攻**

- 以忌神为病，以喜神为药；**有病有药则吉，有病无药则凶**。
- 例：寅月生人不用甲木而用戊土，则甲木为当令之忌神，看日主意向或用火以化之、或用金以制之，安顿得好又逢岁运扶喜抑忌 → 转凶为吉；岁运不来扶喜抑忌又不与忌神结党 → 不过终身碌碌；若无火之化金之制、又遇水生、岁运又党助忌神、伤我喜神、辗转相攻 → 凶祸多端到老不吉。

**寿 —— 性定元神厚**

- 原注：静者寿（柱中无冲无合、无缺无贪则性定）；元神存者不特精气神皆全，官星不绝、财神不灭、伤官有气、身弱印旺、提纲辅主、用神有力、时上生根、运无绝地皆是元神厚处。"大率甲乙寅卯之气，不遇冲战泄伤、偏旺浮泛而安顿得所者心寿。**木属仁，仁者寿**，每每有验。"
- 任氏：**仁、静、宽、德、厚五者皆寿征**。四柱得地、五行停匀，所合者皆闲神、所化者皆用神、冲去者皆忌神、留存者皆喜神，无缺无陷不偏不枯 → 性定。
- 元神厚者：官弱逢财、财轻遇食、身旺而食伤发秀、身弱而印绶当权；所喜者皆提纲之神，所忌者皆失令之物；提纲与时支有情，行运与喜用不悖。
- 判语：**清而纯粹者必富贵而寿；浊而混杂者必贫贱而寿。**

**夭 —— 气浊神枯**

- 原注："印绶太旺日主无着落，财杀太旺日主无依倚，忌神与喜神杂而虞，四柱与用神反而绝，冲而不和，旺而无制，湿而滞，燥而郁，精流气泄，月悖时脱，此皆无寿之人也。"
- 任氏分言：**浊字作一"弱"字论**——气浊者日主失令、用神浅薄、忌神深重，提纲与时支不照、年支与日支不和，喜冲而不冲、忌合而反合，行运与喜用无情反与忌神结党 → **虽不寿而有子**。**神枯者**——身弱而印绶太重、身旺而克泄全无，或重用印而财星坏印、身弱无印而重叠食伤，或金寒水冷而土湿、或火炎土燥而木枯 → **皆夭而无子**。
- 经验判语："**凡水木并旺无土者，最忌火运**，即不伤身，刑耗异常。""两干不杂、金水双清、地支三杀、杀印相生之美，定为贵格……不知夭命皆类此格。"

#### 女命章

- **判断顺序**："先观夫星之盛衰，则知其贵同也；次察格局之清浊，则知其贤愚也。"
- **夫星取法（不可专执官星为夫）**：
  - 官星太旺 → 无比劫以印为夫；有比劫而无印绶者以伤食为夫。
  - 官星太弱 → 有伤官以财为夫；无财星而比劫旺者亦以伤食为夫。
  - 满盘比劫而无印无官者 → 又以伤食为夫。
  - 满局印绶而无官无伤者 → 以财为夫。
  - 伤官旺、日主衰 → 以印为夫；日主旺、食伤多 → 以财为夫；官星轻、印绶重 → 亦以财为夫。
- **"财乃天之恩星，女命身旺无官，财星得令得局者，上格也。"**
- **克夫条件**：官星微而地财星、日主强而伤官重；官星微无财星而比劫旺；官星微无财星、日主旺而印绶重；官星弱、印绶多、无财星；比劫旺而无官、印旺无财；官星旺而印绶轻；比劫旺无官星、有伤官、印绶重；食神多、官星微、有印绶、遇财星——皆必克夫。
- **欺夫**：官星微无财星、比劫旺 → 必欺夫；官星微无财星、日主旺、印绶重 → 必欺夫克夫。
- **女命子星（即是喜神）**：
  - 必有子：日主弱食伤重有印绶无财星；日主弱食伤轻无财星；日主弱财星轻官印旺；日主弱官星旺无财星有印绶；日主弱无官星有伤官。
  - 子多而贵/强/富/贤/能：日主旺伤官旺无印绶有财星 → 子多而贵；日主旺伤官旺无财印 → 子多而强；日主旺伤官轻无财印 → 子多而富；日主旺无食伤官得局 → 子多而贤；日主旺无食伤有财星无官杀 → 子多而能。
  - 子少/无子：日主旺有印绶无财星 → 子必少；日主旺比肩多无官星有印绶 → 子必少；日主旺印绶重无财星 → 必无子；日主弱伤官重印绶轻 → 必无子；日主弱财星重逢印绶 → 必无子；日主弱官杀旺 → 必无子；日主弱食伤旺无印绶 → 必无子。
  - 泛断：**火炎土燥无子，土金湿滞无子，水泛木浮无子，金寒水冷无子，重叠印绶无子，财官太旺无子，满局食伤无子。**（以上无子者，有子必克夫，不克夫亦夭。）
- **淫邪之判（皆就四柱之情）**：日主旺官星微无财星（日主足以敌之）；日主旺官星微伤食重无财星（日主足以欺之）；日主旺官星弱而日主之气生助他神而去之；日主旺官星弱而官星之气合日主而化；日主旺官星弱而官星之气依日主之势；日主弱无财星有食伤逢印绶（日主自专其主）；日主旺无财星、官星轻、食伤重（官星无依倚）；日主旺官无根而日主不顺官星合财星而去；日主弱伤食重印绶轻；日主弱食伤重无印绶有财星；食伤当令财官失势；官无财滋而比劫生食伤；满局伤官无财；满局官星无印；满局比劫无食伤；满局印绶无财 → 皆淫贱之命。
- **总结**："**伤官不宜重，重必轻佻美貌而多淫也；伤官身弱有印，身旺有财者，必聪明美貌而贞洁也。**"
- 任氏又警戒："凡观女命，关系非小，不可轻断淫邪"；且举"多合"之例（丁丑壬子辛巳丙申——"十干之合，以官化伤官，谓贪合忘官……其情必向丁壬一边"）。
- **贤妇（夫荣子贵受封）之条件**：官星食神坐禄、印绶当令逢生、财生官旺不伤印绶、五行停匀安详纯粹；或官星财星助金而年时两支逢生得禄、火水干透无相克之势有生化之情；或伤官虽旺合而化金（官星元神愈厚）、巳火拱金辰土引之（财之元神更固）、时透印绶助日主之光辉制辰土之伤官——"木不枯、火不烈、水不涸、土不燥、金不脆，气静和平之象"。
- 任氏亦以"二德三奇乃好事之妄造；咸池驿马是后人之谬言"，专就四柱五行之理断贞淫贤愚。

#### 小儿章

- **易养条件**：财神不党七杀；主旺精神贯足；干支安顿和平。又看气势——气势在日主而日主雄壮；气势在财官而财官不叛日主；气势在东南而五七岁之前不行西北；气势在西北而五七岁之前不行东南。行运不逢前丧 → "气势攸长，虽有关杀，亦不伤身"。
- 具体论断：必须四柱和平不偏不枯、无冲无克、**根通月令、气贯生时**；杀旺有印、印弱有官、官衰有财、财轻有食伤，生化有情流通不悖；或一神得用始终相托；或两意相通互相庇护；未交运而流年平顺、既交运而运途安祥。
- 反例（夭）：财多身弱（辛丑癸巳丙子丁酉，财官太旺，运根拔尽得疳疾而亡）；财绝官休（癸丑己未丙寅辛卯）；母多子病（壬申戊申壬申戊申，金多水浊，四柱无火克金，金反不能生水，死于三岁甲戌年；壬申甲辰壬申戊申，春土气虚，五行无火，死于痘症）；酉为丁火长生之说为谬（壬戌甲辰丁酉己酉，火到酉位死绝之地，夭于癸酉年）。
- 任氏强调："其余关杀多端，尽皆谬妄……必宜一切扫除。"

### 2.15 性情、才德、奋郁、恩怨、闲神

**性情**

- 总纲：**五气不戾，性情中和；浊乱偏枯，性情乖逆。**
- 五行配德：东方木为仁、南方火为礼、西方金为义、北方水为智、土为信（坤艮居西南东北，"仁义礼智之性，非信不能成"）。
- 专条：
  - **火烈而性燥者，遇金水之激。**火燥而烈，其炎上之性只可纯用湿土（丑辰）润之，则知礼而成慈爱之德；若遇金水激之则火势愈烈而不知礼，灾祸必生。
  - **水奔而性柔者，当火土之神。**水性本柔而其冲奔之势刚急为最，若逢火冲之、土激之则逆其性而更刚；须用金以顺其势、用木以疏其淤塞。
  - **木奔南而软怯。**木之性见火为慈，奔南则仁之性行于礼，其性软怯。得其中者为恻隐辞让，偏者为姑息为繁缛。柱中有金必得水以通之则火不烈；如无金必得辰土以收火气；如无水以济土、土以晦火，发泄太过则聪明自恃、多迁变不常而成妇人之仁。
  - **金见水以流通。**金之性最方正、有断制执毅，见水则义之性行而为智。得气之正者（金旺遇水）内方外圆、能知权变；得气之偏者（金衰水旺）作事荒唐、口是心非、有挟术待人之意。
  - **最拗者西水还南。**西方之水发源最长其势最旺，无土以制之、木以纳之，如不顺行反行南方则逆其性，强拗难制。宜顺其性用木以纳之，则智之性行于仁。
  - **至刚者东火转北。**东方之火其炎上之性不可御，只可顺其刚烈之性用湿土以收之，则刚烈化为慈爱之德；一转北方必刚暴无礼。
  - **顺生之机，遇击神而抗。**"顺则宜顺，逆则宜逆，则和平而性顺矣。"我生者为顺，生我者为逆；旺者宜顺，衰者宜逆。如遇击神，旺者勇急，衰者懦弱。
  - **逆生之序，见闲神而狂。**旺极见闲神必为狂猛，衰极见闲神必为姑息（此旺极衰极乃从旺从弱之理，非旺衰得中之意）。
  - **阳明遇金，郁而多烦。**寅午戌为阳明，有金气（多指湿土藏金）伏于内 → 火不能克金、金又不能生水，而成忧郁；一生得意者少失意者多。
  - **阳浊藏火，包而多滞。**酉丑亥为阴浊，有火气藏于内则不发辉而多滞；阴气太盛不能生陷之火而成湿滞之患。必须纯行阳明之运引通木火之气，则豁然而通达。
  - **羊刃局，战则逞威，弱则怕事；伤官格，清则谦和，浊则刚猛。用神多者，情性不常；时支枯者，虎头蛇尾。**
    - 羊刃局：旺则心高志傲，战则恃势逞威，弱则多疑怕事，合则矫情立异。以丙日午刃为例——干透丁为露刃；支会寅戌、或逢卯生、干透甲乙、或逢丙助皆谓之旺；支逢子为冲，遇亥申为制，得丑辰为泄，干透壬癸为克，逢己土为泄皆谓之弱；支得未为合、遇巳为帮则中和。
    - 伤官真假：真者月令伤官或支会伤局又透出天干；假者满局比劫无官星以制之（虽有官而气力不能敌）。真者身弱有印不见财为清，假者身旺有财不见印为贵。
    - "夏木之见水，冬金之得火，清而且秀，富贵非常"——但夏木之见水必先有金则水有源；冬金之遇火须身旺有木则火有焰；若夏水无金、冬火无木，清枯之象，名利皆虚。

**才德**

- **德胜才者，局合君子之风；才胜德者，用显多能之象。**
- 德胜才：清和平顺、主辅得宜，所合者皆正神、所用者皆正气；财官喜神皆足以了其生平，不生贪恋之心，度量宽宏施为必正。**阳在内、阴在外，不激不亢者为德胜才。**
- 才胜德：财薄而身旺足以贪之，官轻而心志必从而求之；混浊被害、主弱辅强、争合邪神、三四用神；心事奸贪、作事侥幸。**阳在外、阴在内，畏势趋利者为才胜德。**
- 任氏细目：和平纯粹、格正局清、不争不妒，合去者皆偏气、化出者皆正神，喜官而财能生官、喜财而官能制劫、忌印而财能坏印、喜印而官能生印，阳盛阴衰、所用所喜皆阳气 → 君子之风。偏气杂乱、舍弱用强、多争多合，合去者皆正气、化出者皆邪神，喜官而临劫地、喜财而居印位、忌印而官星生印、喜印而财星坏印，阴盛阳衰、所用所喜皆阴气 → 多能之象。

**奋郁**

- **局中显奋发之机者，神舒意畅；象内多沉埋之气者，心郁志灰。**
- 奋发：局中不太过不缺陷，所用者皆得气、所喜者皆得力、所忌者皆失时失势，闲神不党忌物反有益于喜用；忌其合而遇冲、忌其冲而遇合；体阴用阳。岁运又要辅格助用。
- 郁困：局中或太过或缺陷，所用者皆失令、所喜者皆无力、所忌者皆得时得势，闲神劫占、喜神反党助忌神；喜其合而遇冲、忌其合而遇合；体阳用阴。
- **配运定则（从藏神而论）**：
  - 用亥中甲木而天干有壬癸 → 运宜戊寅己卯；天干有庚辛 → 运宜丙寅丁卯；天干有丙丁 → 运宜壬寅癸卯；天干有戊己 → 运宜甲寅乙卯。
  - 用午中己土而天干有壬癸 → 运宜庚午辛未。
  - 用天干之木而地支水旺 → 运宜丙寅丁卯；天干有水 → 运宜戊寅己卯；地支金多 → 运宜甲戌乙亥；天干有土 → 运宜甲子乙丑；地支火多 → 运宜甲辰乙巳；天干有火 → 运宜壬子癸丑。
  - "如此配合，庶无争战之患，而有制化之情。"

**恩怨**

- **两意情通中有媒，虽然遥立意寻追；有情却被人离间，怨起恩中死不灰。**
- 恩怨者喜忌也。日主所喜之神远，得合神化而近之 → 两意情通如中有媒。喜神远隔得旁神引能而相和好 → 有恩而无怨。
- 只有闲神忌神而无喜神，得闲神忌神合化喜神 → "邂逅相逢"。喜神远隔与日主虽有情而被闲神忌神隔绝，得闲神忌会化作喜神 → "私情牵合"，更为有情。
- 喜神与日主紧贴可谓无情，遇合化为忌神；喜神与日主虽不紧贴却有情，中有忌神隔占，或喜神与闲神合助忌神 → 如被人离间，以恩为怨。

**闲神**

- **一二闲神用去么，不用何妨莫动它；半局闲神任闲着，要紧之场作自豪。**
- 定义：自用神、喜神、忌神之外皆闲神（"惟闲神居多，故有一二半局之称"）。
- **本句所重在末句"要紧之场，作自家"**：闲神不伤体用、不碍喜神，可不必动它；至岁运遇破格损用之时而喜神不能辅格护用之际，得闲神制化岁运之凶神忌物，或得闲神合岁支之神化为喜用而辅格助用 → "为我一家人也"。
- 任氏斥原注"只不去动它……反作贼鬼提防矣"。
- 例句：用木而木有余，以火为喜神、以金为忌神、以水为仇神、以土为闲神；木不足，以水为喜神、以土为忌神、以金为仇神、以火为闲神。

**（附）出门与策马两诀**

- **"出门要向天涯游，何事裙钗恣意留"**：乃贪合不化之意。日主有合不顾用神之辅我；用神有合不顾日主之有为；合神真本可化者反助其从合之神而不化；日主休囚本可从者反逢合神之助而不从 → 有情而反无情，绊住留连、贪彼忌此而无大志。
- **"不管白雪与明月，任君策马朝天阙"**：乃逢冲得用意也。冲则动，动则驰。局中除用喜之外日主与他神有所贪恋者，得用神喜神冲而去之 → 日主无私意牵制，乘喜神之势而驰骤。

### 2.16 出身、地位、疾病

**出身**

- **巍巍科第迈迈伦，一个玄机暗里存。**
- "玄机"者：不特格局清奇迥异、用神真假之分，须究支中藏神司命包罗用神喜神，使闲神忌神不能争战反有生拱之情。
- **判语**："**如显然杀印财官、动人心目者，必非佳造；若用神轻微、喜神暗伏、秀也深藏者，初看并无好处，越看越有精神，其中必有玄机。**"
- 世德、山川、命格之序：**"世德心田居一，山川居二，命格居三。"**（从世德而来者不论命）
- **清得尽时黄榜客，虽存浊气亦中式。**
  - 清得尽者非一行成、两气双清；虽五行尽出而清气独逢生旺，或真神得用。
  - 若清当权而闲神忌客不司令、不深藏、和岁运制化者亦发科甲；清所当权虽有浊气而安放得所不碍喜用者虽不能发甲亦发科；清虽不当而得亲神忌客不党浊气、匡扶清气，或岁运安顿者亦可中式。
- **秀才不是尘凡子，清气还嫌官不起。**
  - **官星不起之九种**：官星太旺日主不能用其官；官星太弱不能克日主；官旺用印见财；官衰用财遇劫；印多泄官星之气；官多无印；官透无根地支不载；官坐伤位伤坐官位；忌官逢财、喜官遇伤。
  - "纵有清气，不过一衿终身"；有富而秀者（身旺财旺与官星不通，或伤官顾财不顾官）；有贫而秀者（身旺官轻、财星受劫，或财官太旺印星不现，或伤官用印见财不见官）。
  - **运途之说**：有学问过人竟不能得一衿老于儒童者——格局原可发秀，只因运途不济破其清气；亦有格局本可登科发甲而屡困场屋终身一衿者；亦有格局本无出色竟能科甲连登者——此因一路运途合宜，助其清气官星、去其浊气忌客之故。
- **异路功名莫说轻，日干得气遇财星。**
  - 异路功名（刀笔成名、捐纳出身）总不外**日干有气、财官相通**：或财星得用暗成官局，或官伏财乡两意情通，或官衰逢财两神和协，或印旺官衰而财星破印，或身旺无官而食伤生财，或身衰官旺而食神制官，必有一种清纯之气方可出身。仕路之高卑须究格局之气势、运途之损益。
  - 不能出身者：日干太旺而财轻无食伤、喜官而官星不通或无官；日干太弱而财星官星并旺；有财官虽通而伤官劫占；有财星得用而暗成劫局；有喜印逢财、忌印逢官者。

**地位**

- **台阁勋劳百世传，天然清气发机权。**（台阁宰辅及封疆之任：清气发乎天然、秀气出纯粹，四柱内与喜神有情，格局之中并无可嫌之物；所用者皆真神、所喜者皆真气；度量宽宏能容物，施为纯正不贪私。）
- **兵权獬豸弁冠客，刃煞神清气势特。**（掌生杀大权、兵刑重任者必以刃旺敌杀、气势出人。局中杀旺无财、印绶用刃者，或无印而有羊刃者 → 杀刃神清；气势特者刃旺当权 → 必文官而掌生杀之任。**若刃旺敌杀而局中无食神印绶而有财官者，气势虽特而神气不清，乃武将之命。若刃不当权，虽能敌杀，不但不能掌兵权，亦不能贵显。**"其人疾恶太严，如刃旺杀弱亦然，必傲物而骄慢也。"
  - 羊刃取法：春甲用卯刃、乙用寅刃；夏丙用午刃、丁用巳刃；秋庚用酉刃、辛用申刃；冬壬用子刃、癸用亥刃。
- **分藩司牧财官和，清纯格局神气多。**（方面之任以及州县之官，虽以财官为重，必须格局清纯、日元生旺、神贯气足；又加官旺有印、官衰有财、印旺有财，左右相通上下不悖，根通年月气贯日时，身杀两停、杀重逢印、杀轻遇财者皆是。）
- **便是诸司并首领，也从清浊分形离。**（杂职佐二首领亦膺一命之荣，气象格局冲合理气之内必有一点清气。**"天干象天，地支象地。地支上升于天干者轻清之气也；天干下降于地支者重浊之气也。天干之气本清不忌浊也；地支之气本浊必要清也。天干浊、地支清者贵；地支浊、天干清者贱。"**）

**疾病**

- **五行和者，一世无灾。** 和者非"全而不缺、生而不克"，其要贵在**泄其旺神、泻其有余**——有余之旺神泻，不足之弱神受益。若强制旺神则寡不敌众、触怒其性，旺神不能损而弱神反受伤。**旺神太过者宜泄，不太过宜克；弱神有根者宜扶，无根者反宜伤之。**
- 脏腑配属：腑皆属阳为甲丙戊庚壬，脏皆属阴为乙丁己辛癸。木为肝胆、火为心与小肠、土为脾胃、金为大肠与肺、水为膀胱与肾。
- 五味之克：酸属木多食伤筋、苦属火多食伤骨、甘属土多食伤肉、辛属金多食伤气、咸属水多食伤血。
- **血气乱者，生平多疾。** 五行论水为血、人身论脉即血；丁壬相合故心能下交于肾，得既济相生则血脉流通而无疾病。若左右相战、上下相克，喜逆逢顺，则"火旺水涸火能焚木；水旺土荡水能沉金；土旺木折土能晦火；金旺火虚金能伤土；木旺金缺木能渗水" → 犯此者必多灾病。
- **忌神入五脏而病凶**（忌神＝阴浊之气埋藏于地支，阴浊深伏难制难化，为病最凶）：忌木而入土则脾病，忌火而入金则肺病，忌土而入水则肾病，忌金而入木则肝病，忌水而入火则心病。
  - 虚实：如木入土，土旺者脾自有余之病（发于四季月）；土衰者脾有不足之病（发于春冬月）。余仿此。
  - 脾本忌湿、胃本忌寒；土湿而有余其病发于春冬（反忌火以燥之），土燥而有余其病发于夏秋（反忌水以润之）。土湿而不足其病发于夏秋；土燥而不足其病发于冬春。
- **客神游六经而灾小**（客神＝阳虚之所浮于天干，阳而虚露易制易化，为灾必小，犹病之在表）：木游于土之地而胃灾，火游于金之地而大肠灾，土行水地膀胱灾，金行木地胆灾，水行火地小肠灾。
- **木不受水者血病。** 春木不受水者喜火之温暖；冬木不受水者喜火之解冻；夏木之有根而受水者去火之烈润地之燥；秋木得地而受水者泄金之锐化杀之顽。**春冬生旺之木，要其衰而受水；夏秋休囚之木，要其旺而受水。**反此则不受，不受则血不流行故致血病。
- **土不受火者气伤。** 燥实之土不受火者喜水之润；虚湿之土不受火者忌水之克；春土有根而受火者解天之冻去地之湿；秋土得地而受火者制金之有余补土之泄气。**过燥必气亏，过湿必脾虚。**
- **金水伤官，寒则冷嗽，热则痰火；火土印绶，热则风痰，燥则皮痒。论痰多木火，生毒郁火金，金水枯伤而肾经虚，水木相胜而脾胃泄。**
  - 金水伤官过于寒者其气辛凉、真气有亏必主冷嗽；过于热者水不胜火、火必克金（水不胜火者心肾不交，火能克金者肺家受伤）。冬令虚火上炎故主痰火。
  - 火土印绶过于热者木从火旺、火旺焚木、木属风故主风痰；过于燥者火炎土焦、土润则血脉流行营卫调和，皮属土土喜暖暖即润，所以过燥则皮痒、过湿则生疮。"
  - **火多主痰，水多主嗽。**
  - 木火多痰：火旺逢木、木从火势，金不能克木、水不能胜火，火必克金而伤肺，不能下生肾水，木又泄水气，肾水必燥，阴虚火炎痰则生矣。
  - 生毒郁火金：火烈水涸、火必焚木；木被火焚土必焦燥；燥土能脆金，金郁于内，脆金逢火肺气上逆；肺气逆则肝肾两亏，肝肾亏则血脉不行，加以七情忧郁而生毒矣。
- **断病与断事相通**（任氏要诀）：不可专执而论——如病不相符，可究其六亲之吉凶、事体之否泰，必有应验者。如日主是金、木是财星，局中火旺日主不能任其财，必生火而助杀，反为日主之忌神；既或有水，水仍生木则金气愈虚，金为大肠肺，肺伤大肠不畅不能下生肾水，木泄水而生火，必主肾肺两伤之病。**然亦有无此者，必财多破耗、衣食不敷，是其咎也；亦有无病而财源旺者，其妻必陋恶、子必不肖也。**反之亦有局中金水与木火停匀而得肺肾之病者，或财多破耗、或妻陋子劣者，亦因岁运一路木火而金水受伤之故。

## 3. 关键原文口诀（附适用场景）

> 标注说明：**〔原文〕**＝《滴天髓》歌诀原文；**〔原注〕**＝旧注；**〔任氏〕**＝任铁樵注中可独立引用的判断句。每条按篇章归并，同一篇章内数句口诀合为一条；引号内文字逐字照抄，仅去除折行与空格。

### 通神论

1. **〔原文〕** "欲识三元万法宗，先观帝载与神功。""坤元合德机缄通，五气偏全定吉凶。""戴天覆地人为贵，顺则吉兮凶则悖。" —— 出处：通神论·天道、地道、人道。用法：论命第一层框架——干为天元、支为地元、支中所藏为人元；吉凶之总纲在五行偏全与干支顺悖（顺＝接续相生，悖＝反克为害）。
2. **〔任氏〕** "最宜四柱流通，五行生化；大忌四柱缺陷，五行偏枯。""命贵中和，偏枯终于有损；理求平正，奇异不足为凭。" —— 出处：通神论·人道。用法：评断命局结构优劣的总尺度；四柱一气（四戊午、四癸亥之类）皆作偏枯论。
3. **〔任氏〕** "用之为财不可劫，用之为官不可伤，用之印绶不可坏，用之食神不可夺。……其要在一"用"字。" —— 出处：通神论·知命。用法：四句口诀的适用前提是"用"——不用财星尽可劫，不用官星尽可伤，不用印绶尽可坏，不用食神尽可夺。
4. **〔原文〕** "理承气行岂有常，进兮退兮宜抑扬。" —— 出处：通神论·理气。用法：论旺衰不可死守长生死绝，须审五行进退。
5. **〔任氏〕** "将来者进，是谓相；进而当令，是谓旺；功成者退，是谓休；退而无气，是谓囚。""然相妙于旺，旺则极盛之物，其退反速，相则方长之气，其进无涯也。" —— 出处：通神论·理气。用法：以旺相休囚辨进退；为日主为喜神宜旺相，为凶煞为忌神宜休囚；喜神在"相"位优于"旺"位。
6. **〔原文〕** "配合干支仔细详，定人福祸与灾祥。" —— 出处：通神论·配合。用法：专从奇格神杀取用者必致祸福无凭。
7. **〔任氏〕** "命中至理，只存用神，不拘财、官、印绶、比劫、食伤、枭杀，皆可为用，勿以名之美者为佳，恶者为憎。" —— 出处：通神论·配合。用法：全书方法论核心，先破十神名相之执，唯以日主衰旺、用神喜忌取裁。
8. **〔原文〕** "五阳皆阳丙为最，五阴皆阴癸为至。""五阳从气不从势，五阴从势无情义。" —— 出处：通神论·天干。用法：丙为纯阳、癸为纯阴（丙辛化水、戊癸化火之本）；五阳性刚健不畏财煞，五阴见势忘义，故从格易成于阴干。
9. **〔任氏〕** "即分别所用，不过阳刚阴柔，阳健阴顺而已。" —— 出处：通神论·天干。用法：破除甲为梁栋、乙为花果、丙作太阳、丁作灯烛、戊作城墙、己作田园、庚为顽铁、辛作珠玉、壬为江河、癸为雨露之死板比喻，甲乙只是一木之刚柔。
10. **〔原文〕** "甲木参天，脱胎要火。春不容金，秋不容土。火炽乘龙，水宕骑虎。""乙木虽柔，刲羊解牛。怀丁抱丙，跨凤乘猴。虚湿之地，骑马亦忧。藤萝系甲，可春可秋。" —— 出处：通神论·天干。用法：甲木春宜火、仲春宜泄、秋土虚薄不能培根、寅午戌透丙丁宜坐辰、申子辰透壬癸宜坐寅；乙木生丑未月能制柔土，生申酉月得丙丁不畏金，生亥子月无丙丁虽坐午亦难发生，甲透寅藏则四季皆可。
11. **〔原文〕** "丙火猛烈，欺霜侮雪。能煅庚金，逢辛反怯。土众成慈，水猖显节。虎马犬乡，甲木若来，必当焚灭。""丁火柔中，内性昭融。抱乙而孝，合壬而忠。旺而不烈，衰而不穷，如有嫡母，可秋可冬。" —— 出处：通神论·天干。用法：丙火泄威用己土、遏焰用壬水、顺性用辛金，支全寅午戌再见甲木则焚灭；丁火得甲乙（嫡母）则秋生不畏金、冬产不忌水。
12. **〔原文〕** "戊土固重，既中且正。静翕动辟，万物司命。水润物生，火燥物病。若在艮坤，怕冲宜静。""己土卑湿，中正蓄藏。不愁木盛，不畏水狂。火少火晦，金多金光。若要物旺，宜助宜帮。" —— 出处：通神论·天干。用法：戊土坐寅申喜静忌冲、生四季月最喜庚申辛酉之金（秀气流行定为贵格，见木火则破）；己土柔能纳木水，最需丙火与土气深固。
13. **〔原文〕** "庚金带煞，刚健为最。得水而清，得火而锐。土润则生，土干则脆。能赢甲兄，输于乙妹。""辛金软弱，温润而清。畏土之叠，乐水之盈。……热则喜母，寒则喜丁。" —— 出处：通神论·天干。用法：庚宜壬水淘洗、丁火煅炼，丑辰湿土生金、未戌燥土脆金；辛金畏戊土重叠喜壬水，夏喜己土、冬喜丁火（冬见丙则男命不贵、女命克夫）。
14. **〔原文〕** "壬水通河，能泄金气，刚中之德，周流不滞。通根透癸，冲天奔地。化则有情，从则相济。""癸水至弱，达于天津。得龙而运，功化斯神。不愁火土，不论庚辛。合戊见火，化象斯真。" —— 出处：通神论·天干。用法：申子辰全又透癸则泛滥不可强制（戊己不能止流，必用木泄顺其势）；癸水柱有甲乙寅卯则运水气、生木制火，定为贵格，合戊须丙火透出方为真化。
15. **〔原文〕** "阳支动且强，速达显灾祥；阴支静且专，否泰每经年。" —— 出处：通神论·地支。用法：子寅辰午申戌之吉凶验速；丑卯巳未酉亥之祸福应迟。一支所藏或二干或三干，**以本气为主**（寅必先甲而后及丙）。
16. **〔原文〕** "生方怕动库宜开，败地逢冲仔细推。" —— 出处：通神论·地支。用法：寅申巳亥忌冲动（两败俱伤）；辰戌丑未之宜不宜详在杂气（任氏谓墓库逢冲则发为后人之谬——通根辰戌丑未者逢冲则微根拔尽）；子午卯酉专气，用金水则可冲，用木火则不可冲，须活看。
17. **〔原文〕** "旺者冲衰衰者拔，衰神冲旺旺神发。""暗冲暗会尤为喜，彼冲我兮皆冲起。" —— 出处：通神论·地支。用法：得令者冲衰则拔，失时者冲旺无伤；冲之有力则能去之（去凶神利、去吉神不利），无力则反激之；四柱无冲会之神而岁运暗来冲会尤为喜，"喜神是我，忌神为彼"，宁可我去冲彼，不可彼来冲我。
18. **〔原文〕** "支神只以冲为重，刑与穿兮动不动。" —— 出处：通神论·地支。用法：断语总纲——地支逢冲犹天干相克，须视强弱喜忌；**刑（自刑、子卯、寅巳申、丑戌未）、穿（六害）、破皆不足为凭**，总以生克论。
19. **〔原文〕** "阴阳顺逆之说，《洛书》流行之用，其理信有之也，其法不可执一。" —— 出处：通神论·干支总论。用法：力斥阳生阴死、阴生阳死之说——丁遇酉以财论、乙遇午以食神泄气论，俱不以生论；乙遇亥、癸遇申以印论，俱不以死论；阴阳同生同死。
20. **〔原文〕** "天地顺遂而精粹者昌，阴阳乖悖而混乱者亡。""天全一气，不可使地德莫之载。""地全三物，不可使天道莫之容。" —— 出处：通神论·干支总论。用法：**干以载之支为切，支以覆之干为切**——喜甲乙而载以寅卯亥子则生旺，载以申酉则克败；四甲四乙须地支能承（否则或全受克于地支如四乙酉，或反克地支如四辛卯）；支全三物其势旺盛，**旺神在提纲只宜泄不宜制**（提纲即制神之绝地，强制则激而肆逞），旺神在别支则天干制之有力亦可制。
21. **〔原文〕** "阳乘阳位阳气昌，最要行程安顿。""阳乘阴位气盛，还须道路光亨。" —— 出处：通神论·干支总论。用法：申戌子全为西北阳寒，最要行运遇卯巳未东南阴暖；寅辰午全为东南阳暖，最要行运遇酉亥丑西北阴寒；酉亥丑全为西北阴寒，要行东南寅辰午阳暖；卯巳未全为东南阴暖，要行申戌子阳寒。
22. **〔原文〕** "地生天者，天衰怕冲。""天合地者，地旺喜静。" —— 出处：通神论·干支总论。用法：前句——日主生不得令之月、柱中少帮扶而用身印者，冲则根拔生机绝，为祸最重，日主得时当令或年时皆逢禄旺则不怕冲；后句重在下半——地旺者天必衰，四支无冲克有生助则"合似从之意"（合财似从财、合官似从官），**可言合者只有戊子、辛巳、丁亥、壬午四日**（甲午、己亥、癸巳三日支中本气先出，不论）。
23. **〔原文〕** "甲申戊寅，真为杀印相生；庚寅癸丑，也作两神兴旺。" —— 出处：通神论·干支总论。用法：支坐杀印之取用总纲——身强杀浅以财星滋杀，身杀两停以食神制杀，杀强身弱以印绶化杀；杀重身轻非贫即夭，制杀太过虽学无成。任氏补正：**"非止此四日"**，仍须观四柱气势与日主衰旺。
24. **〔原文〕** "上下贵乎情协。""左右贵乎同志。""始其所始，终其所终，富贵福寿，永乎无穷。" —— 出处：通神论·干支总论。用法：情协＝互相卫护、干支不反背（官衰伤旺而财星得局、官旺财多而比劫得局、杀重用印而忌财者财临劫地、身强杀浅而喜财者财坐食乡）；同志＝日主所喜之神贴身透露、得闲神相助不争不忌，所忌之神被闲神制伏不肆不逞；始终＝年月为始、日时为终，看所喜之神能否引于时支有所归。
25. **〔原文〕** "两气合而成象，象不可破也。""五气聚而成形，形不可害也。""独象喜行化地，而化神要昌。""全象喜行财地，而财神要旺。" —— 出处：通神论·形象。用法：两气成象见克破之神则破局（木火成象最怕金水，水火既济尤忌土来止水），相克成象务须均敌；五气成形以食伤泄气、官杀交加用火、印绶重叠用土、财轻劫重用金；独象（曲直炎上稼穑从革润下）须局中食伤昌旺再行化神之地，见金运为破局；全象（伤官生财、官印相生、财官并见）视局中意向定喜财喜官。
26. **〔原文〕** "形全者宜损其有余，形缺者宜补其不足。" —— 出处：通神论·形象。用法："旺则宜泄宜伤，衰则喜帮喜助"，但**泄与伤、帮与助须分用**：日主旺而财官无气则伤之有利泄之有害（泄损官星，伤去比劫补官星）；满局比劫则泄之有利伤之有害（伤之则激）；日主弱而财星重叠则帮之吉助之凶（助则印坏）；日主弱而官杀交加则助之吉帮之凶（不若以印化其强暴）。
27. **〔原文〕** "方是方兮局是局，要得方兮莫混局。""局混方兮有纯疵，行运喜南或喜北。""若然方局一齐来，须是干头无反复。" —— 出处：通神论·方局。用法：三字全为成方（力胜于局），三支合为局；方局相混任氏以为无害（木见亥为生旺、见未为财又为盘根）；方局齐来其气旺盛，要天干顺其气势（日主是木须天干有火泄其精英而不见金水），若天干有火而见水、或无火而见金，谓之**干头反复**，一衿尚不能博。
28. **〔原文〕** "成方干透一元神，生地库地皆非福。""成局干透一官星，左边右边空碌碌。" —— 出处：通神论·方局。用法：成方又透元神（如木方日主是木）旺极不宜再行生地库地，若属从强则生地库地亦能发福，须看气势；会局而干透官星虚脱无气、支无申酉丑者碌碌终身名利无成，须岁运去其官星且柱中先见食伤方可发达。
29. **〔原文〕** "财官印绶发偏正，兼论食伤八格定。""影响遥系既为虚，杂气财官不可拘。" —— 出处：通神论·八格。用法：取格次序——先观月令所得何支，次看天干透出何神，再究司令以定真假，然后取用以分清浊；月逢禄刃无格可取则另寻别支透干者借以为用；飞天禄马（暗冲暗合）、杂气财官（四季月只当取土为格）、禄分四种（背禄、建禄、专禄、归禄）皆不可执。
30. **〔原文〕** "道有体用，不可以一端论也，要在扶之抑之得其宜。" —— 出处：通神论·体用。用法：体者形象气局（无形象气局则以日主为体），用者用神；旺极者抑之反激而有害则宜从其强而扶之，弱极者扶之徒劳无功则宜从其弱而抑之。
31. **〔原文〕** "人有精神，不可以一偏求也，要在损之益之得其中。" —— 出处：通神论·精神。用法：精（生我之神＝印）、神（克我之物＝官杀）、气（本气贯足）；精太足宜益其气，气太旺宜助其神，神太泄宜滋其精；水泛木浮则木无精神，木多火炽则火无精神，火炎则金无精神，金多水弱则水无精神。
32. **〔原文〕** "月令乃提纲之府，譬之宅也，人元为用事之神，宅之定向也，不可以不卜。""生时乃归宿之地，譬之墓也，人元为用事之神，墓之定方也，不可以不辨。" —— 出处：通神论·月令、生时。用法：取格取用皆本于月令人元司令（寅月立春后七日前戊土、八至十四日丙火、十五日后甲木之类），**人元必须司令则能引吉制凶，司令必须出现方能助格辅用**；时之人元与月令人元相附，为日主所喜者加倍兴隆、所忌者必增凶祸，但人元用事之轻重终不及提纲司令。
33. **〔原文〕** "能知衰旺之真机，其于三命之奥，思过半矣。" —— 出处：通神论·衰旺。用法：旺中有衰者存不可损，衰中有旺者存不可益；**旺之极者不可损，衰之极者不可益**（损之反触其怒，益之虚不受补）。
34. **〔任氏〕** "天干得一比肩，不如地支得一余气墓库……得二比肩，不如支中得一长生禄旺。" —— 出处：通神论·衰旺。用法：断日主强弱的硬尺度（比肩如朋友相扶，通根如家室可托，干多不如根重）；日主不论月令休囚，四柱有根便能受财官食神而当伤官七杀；据以立得时不旺、失时不弱之论。
35. **〔任氏〕** "木太旺者而似金，喜火之炼也；木旺极者而似火，喜水之克也。火太旺者而似水，喜土之止也；火旺极者而似土，喜木之克也。……" —— 出处：通神论·衰旺。用法：五行颠倒之真机的三十条变局（太旺者似某、旺极者似某，太衰者似某、衰极者似某，各有所喜）；极端旺衰的取用总表。
36. **〔原文〕** "既识中和之正理，而于五行之妙，有全能焉。" —— 出处：通神论·中和。用法：中和乃至贵；身弱而旺地取富贵、身旺而弱地取富贵者，其气亦纯正，岁运补不足去有余则起发于后。
37. **〔原文〕** "何处起根源?流到何方住?机括此中求，知来亦知去。" —— 出处：通神论·源流。用法：以四柱最旺者为源头，追其流止之地定休咎与六亲（阻节是印主长辈之祸，是比劫主兄弟之累，是财主妻妾之祸，是食伤主子孙之累，是官煞主官刑之祸）；**收局一字定贵贱**——去我浊气作喜神者不贵亦富，去我清气作忌神者不贫亦贱。
38. **〔原文〕** "关内有织女，关外有牛郎，此关若通也，相邀入洞户。" —— 出处：通神论·通关。用法：木土要火、火金要土、土水要金、金木要水；原局无印必须岁运逢印向而通之，或暗会明合通之，或冲开合化、克去间神忌物。
39. **〔原文〕** "官杀混杂来问我，有可有不可。" —— 出处：通神论·官杀。用法：**日主旺相可混也，日主休囚不可混也**；去官不过两端，用食用伤皆可；合杀总为美事，合来合去宜清；杀重身轻非贫即夭，杀微而制过虽学无成。
40. **〔任氏〕** "与其制杀太过，不若官杀混杂之美也。""格格推详，以杀为重。""有杀只论杀，无杀方论用。" —— 出处：通神论·官杀。用法：制杀太过则杀既伤残，再行制煞之运九死一生；官杀混杂只要日主坐旺、印绶不伤、运程安顿，未有不富贵者（杀分六等：财滋弱杀、杀重用印、食神制杀、合官留杀、官杀混杂、制杀太过）。
41. **〔原文〕** "伤官见官果难辨，可见不可见。" —— 出处：通神论·伤官。用法：**大率伤官有财皆可见官，伤官无财皆不可见官**；"伤官见官，为祸百端"专指日主衰弱用比劫帮身者（见官则比劫受克），若局中有印则见官不但无祸而且有福；伤官格只不宜见印，见印破伤为凶。
42. **〔原文〕** "一清到底有精神，管取生平富贵真。澄浊求清清得去，时来寒谷也回春。""满盘浊气令人苦，一局清枯也苦人，半浊半清犹是可，多成多败度晨昏。" —— 出处：通神论·清气、浊气。用法：清而要有精神不为枯弱，喜神宜得地逢生与日主紧贴，忌神宜失势临绝与日主远隔；浊者可待行运扫除浊气而有所起发，枯者难救——**宁使清中浊，不可清中枯**；日主枯者非贫即夭，用神枯者非贫即孤。
43. **〔原文〕** "令上寻其聚得真，假神休要乱真神，真神得用生平贵，用若无为碌碌人。""真假参差难辨论，不明不暗受困顿。提纲不与真神照，暗处寻真也有真。" —— 出处：通神论·真神、假神。用法：真神＝得时秉令之神，须提纲司令又透出天干、不为假神破损；假神安顿得好（不紧贴、被闲神合住、遥隔无力）亦无害；真神失势假神得局则法当以真为假、以假为真，全看日主之爱憎；**"喜宜四生，忌神宜四绝，局内看真神，行运看解神"**。
44. **〔原文〕** "柔刚不一也，善为制者，但引其性情而已矣。""顺逆不齐也，不可逆者，其气势而已矣。" —— 出处：通神论·刚柔、顺逆。用法：**泄者有生生之妙，克者有成就之功，引者有和悦之情，从者有变化之妙**；得时当令不泄则不清，失时休囚不劫则不辟；当令得势之神（二人同心）或日主得时秉令四柱皆拱合（权在一人）只可顺其气势引通，勉强得制必罹凶咎；任氏又云"浊中清，贵之机，清中浊，贱之根。逆来顺去富之基，顺来逆去贫之意"。
45. **〔原文〕** "天道有寒暖，发育万物，人道行之，不可过也。""地道有燥湿，生成品汇，人道得之，不可偏也。" —— 出处：通神论·寒暖、燥湿。用法：**寒虽甚要暖有气，暖虽至要寒有根**；寒甚而暖无气则反以无暖为美，暖至而寒无根则反以无寒为美；木火伤官要湿（喜壬癸与丑辰湿土，忌未戌燥土），金水伤官要燥（可用丙丁，忌丑辰湿土）。
46. **〔原文〕** "吉神太露，起争夺之风；凶物深藏，成养虎之患。""强众而敌寡者，势在去其寡；强寡而敌众者，势在成乎众。" —— 出处：通神论·隐显、众寡。用法：吉神宜深藏地支（天干气专易于劫夺），凶物宜明透天干（地支气杂难于制化）；但吉神通根当令者露亦无害、凶物失时休囚者藏亦无妨；官星无财生助而食伤当令则势在去官（岁运宜扶众抑寡），官星得财星扶则势在成乎众（岁运宜扶寡抑众）。
47. **〔原文〕** "震兑主仁义之真机，势不两立，而有相成者存。""坎离宰天地之中气，成不独成，而有相持者在。" —— 出处：通神论·震兑、坎离。用法：金木取五法——春初木嫩金坚火以攻之、仲春木旺金衰土以成之、夏令木泄金燥水以润之、秋令木凋金锐土以从之、冬令木衰金寒火以暖之；水火取五法——升（天干离衰地支坎旺须地支有木）、降（天干坎衰地支离旺须天干有金）、和（天干皆火地支皆水须木运）、解（天干皆水地支皆火须金运）、制（水火交战须岁运制其强者）。

### 六亲论

48. **〔原文〕** "夫妻因缘宿世来，喜神有意傍天财。""子女根枝一世传，喜神看与杀相连。""父母或降与或替，岁月所关果非细。""兄弟谁废与谁兴，提用财神看重轻。" —— 出处：六亲论·夫妻、子女、父母、兄弟。用法：四亲判断总诀——以财论妻（财星清则中馈贤能，浊则河东狮吼）；以食伤论子女（须先认定食伤再看日主衰旺四柱喜忌）；财官印绶在年月为日主之喜则父母不贵亦富、为忌则不贫亦贱；比肩劫财羊刃看其显伏与财官轻重定兄弟强弱（劫刃太旺财官无气则兄弟反少不如无）。
49. **〔任氏〕** "生我者为父母，偏正印绶是也；我生者为子女，食神伤官是也。我克者为妇妾，偏正财星是也，克我者为官鬼，祖父是也；同我者为兄弟，比肩劫财是也。" —— 出处：六亲论·夫妻。用法：任氏重定六亲正名，取代以财为父、以官为子之旧说；并以用神为子、忌神为女作子息断法。
50. **〔原文〕** "何知其人富?财气通门户。""何知其人贵?官星有理会。""何知其人贫?财贫神反不真。""何知其人贱?官星还不见。" —— 出处：六亲论·何知章。用法：富贵贫贱四断——富：身旺财弱无官必要有食伤、身旺财旺无食伤必须有官有杀、身旺劫旺无财印而有食伤、身弱财重无官印而有比劫；贵：身旺官弱财能生官、官旺身弱官能生印、印旺官衰财能坏印、劫重财轻官能去劫、用官则官藏财亦藏；贫：按任氏九不真逐条比对（原注"中有一味清气，则不贱"）；贱：官轻印重身旺、官重印轻身弱、官印两平而日主休囚为上等官星不见（清贫守正），官旺喜印而财坏印、官杀重无印而食伤强制为下等。
51. **〔原文〕** "何知其人吉?喜神为辅弼。""何知其人凶?忌神辗转攻。""何知其人寿?性定元神厚""何知其人夭?气浊神枯了。" —— 出处：六亲论·何知章。用法：吉凶寿夭四断——吉：先用神而后喜神（用官者身旺可以财为喜神，用印身弱者而后用官为喜神）；凶：以忌神为病、以喜神为药，有病有药则吉、有病无药则凶；寿：仁、静、宽、德、厚五者皆寿征，清而纯粹者必富贵而寿；夭：气浊（作一"弱"字论，虽不寿而有子）、神枯（身弱印绶太重、身旺克泄全无，或金寒水冷而土湿、火炎土燥而木枯，夭而无子）。
52. **〔原文〕** "论夫论子要安样，气静平和妇道章，三奇二德虚好语，咸池驿马半推详。" —— 出处：六亲论·女命章。用法：女命先观夫星之盛衰、次察格局之清浊；三奇二德咸池驿马皆不足凭。
53. **〔任氏〕** "凡女命之夫星，即是用神，女命之子星，即是喜神，不可专论官星为夫、伤食为子。""伤官不宜重，重必轻佻美貌而多淫也；伤官身弱有印，身旺有财者，必聪明美貌而贞洁也。" —— 出处：六亲论·女命章。用法：官星太旺以印为夫、官星太弱以财为夫、满局印绶无官无伤以财为夫——随局取夫；克夫与子息诸条依官星、比劫、印绶、伤官、财星之配置判；贞淫以伤官轻重与财印配置定。
54. **〔原文〕** "论财论杀论精神，四柱和平易养成，气势攸长无削丧，杀关虽有不伤身。""德胜才者，局合君子之风；才胜德者，用显多能之象。""局中显奋发之机者，神舒意畅；象内多沉埋之气者，心郁志灰。" —— 出处：六亲论·小儿、才德、奋郁。用法：小儿易养之条件（财不党杀、主旺精神足、干支和平、根通月令气贯生时、行运不逢前丧）；德胜才＝阳在内阴在外、所用所喜皆阳气，才胜德＝阳在外阴在内、趋势趋利；奋郁以所用得气、所喜得力、所忌失势与否定，局虽阴晦而运途阳明亦能舒畅。
55. **〔原文〕** "两意情通中有媒，虽然遥立意寻追；有情却被人离间，怨起恩中死不灰。""一二闲神用去么，不用何妨莫动它；半局闲神任闲着，要紧之场作自豪。""一出门来只见儿，吾儿成气构门闾：从儿不管身强弱，只要吾儿又得儿。" —— 出处：六亲论·恩怨、闲神、顺局。用法：恩怨——喜神远隔得合神引化而近之如中有媒，喜神被闲神忌神隔绝则怨起恩中；闲神——闲神不伤体用则不须动，至岁运破格损用而喜神不能护用之际得闲神制化凶神或合化为喜用则"为我一家人"；顺局（从儿格）须食伤在提纲、局中有财（儿又生儿），行运不背逢财者未有不富贵，最忌印运、次忌官运。
56. **〔原文〕** "君赖臣生理最微，儿能救母泄天机，母慈灭子关因异，夫健何为又怕妻。""天战犹自可，地战急如火。""合有宜不宜，合多不为奇。" —— 出处：六亲论·反局、战局、合局。用法：四反局——君赖臣生（印太旺，须用土止水，破印就财）、儿能救母（我生者克克我者，须分时候）、母慈灭子（印太旺只宜顺母之性助其子，忌财食伤逆之）、夫健怕妻（财旺有金克身，重在一"健"字）；战局——天干气专易于制化、地支气杂难于制化，天干宜动地支宜静，用神伏藏或被合者反宜冲而动之；合局——喜合而合之最美，忌合而合之比冲愈凶，忌神合而不去不足为喜，喜神合而不来不足为美。
57. **〔原文〕** "君不可抗也。贵乎损上以益下。""臣不可过也，贵乎损下而益上。""知慈母恤孤之道，始有瓜瓞无疆之庆。""知孝子奉亲之方，始克谐成大顺之风。" —— 出处：六亲论·君象、臣象、母象、子象。用法：君象——日主为君、财为臣，君盛臣衰须以火行之、土实之、金卫之，**切忌以金制之**（木盛令金自缺，反触其怒）；臣象——日主为臣、官星为君，臣盛君衰须带火之土运（则臣心顺、君心安），纯用土金以激之非安上全下之意；母象——母众子孤一不可见水、二不可见金；子象——子众母衰一不可见土、二不可见金。任氏自注：此四章虽主木论，火土金水亦如之。
58. **〔原文〕** "五气不戾，性情中和；浊乱偏枯，性情乖逆。""火烈而性燥者，遇金水之激。""水奔而性柔者，当火土之神。""木奔南而软怯。""金见水以流通。""最拗者西水还南。""至刚者东火转北。""顺生之机，遇击神而抗。""逆生之序，见闲神而狂。""阳明遇金，郁而多烦。""阳浊藏火，包而多滞。""羊刃局，战则逞威，弱则怕事；伤官格，清则谦和，浊则刚猛。用神多者，情性不常；时支柘者，虎头蛇尾。"（"柘"为原书讹字，当作"枯"） —— 出处：六亲论·性情。用法：断性情的完整条目——五气配五德（木仁火礼金义水智土信）；火燥宜纯用湿土顺其性，遇金水激之则不知礼；水冲奔不可火冲土激，须金顺其势、木疏其淤；木奔南泄气太过须金水或辰土收火气；金旺遇水得气之正则内方外圆，金衰水旺得气之偏则作事荒唐；西水不可行南、东火不可转北；羊刃以冲、制、泄、克、合分旺弱（旺则心高志傲，战则恃势逞威，弱则多疑怕事，合则矫情立异），伤官以真假分清浊。
59. **〔原文〕** "五行和者，一世无灾。""血气乱者，生平多疾。""忌神入五脏而病凶。""客神游六经而灾小。""木不受水者血病。""土不受火者气伤。""金水伤官，寒则冷嗽，热则痰火；火土印绶，热则风痰，燥则皮痒。论痰多木火，生毒郁火金，金水枯伤而肾经虚，水木相胜而脾胃泄。" —— 出处：六亲论·疾病。用法：疾病断法的全部条文——和者贵在泄其旺神、泻其有余（旺神太过者宜泄，不太过宜克；弱神有根者宜扶，无根者反宜伤之）；忌神入五脏（忌木入土则脾病、忌火入金则肺病、忌土入水则肾病、忌金入木则肝病、忌水入火则心病）为病最凶，客神（阳虚浮于天干）为灾必小；水为血，春冬生旺之木要其衰而受水、夏秋休囚之木要其旺而受水；过燥必气亏、过湿必脾虚；"火多主痰，水多主嗽"。
60. **〔原文〕** "巍巍科第迈迈伦，一个玄机暗里存。""清得尽时黄榜客，虽存浊气亦中式。""秀才不是尘凡子，清气还嫌官不起。""异路功名莫说轻，日干得气遇财星。""台阁勋劳百世传，天然清气发机权。""兵权獬豸弁冠客，刃煞神清气势特。""分藩司牧财官和，清纯格局神气多。""便是诸司并首领，也从清浊分形离。" —— 出处：六亲论·出身、地位。用法：出身与地位八诀——出身看"玄机"（用神轻微喜神暗伏、秀气深藏者初看无好处越看越有精神，显然杀印财官动人心目者必非佳造）；官星不起九种则纵有清气不过一衿终身；异路功名总不外日干有气、财官相通；台阁封疆须清气发乎天然、所用皆真神所喜皆真气；掌兵刑生杀者必刃旺敌杀（刃旺敌杀而无食神印绶而有财官者神气不清，乃武将之命，刃不当权则不能贵显）；方面之官须格局清纯、日元生旺、官旺有印、官衰有财；杂职佐二亦必有清气——**天干浊而地支清者贵，地支浊而天干清者贱**。
61. **〔原文〕** "休囚系乎运，尤系乎岁，战冲视孰降，和好视孰切。""造化起于元，亦止于贞。再肇贞元之会，胚胎嗣续之机。" —— 出处：六亲论·岁运、贞元。用法：大运重地支、太岁重天干；盖头（如喜木运遇庚寅辛卯）减半，截脚（如喜木运遇甲申乙酉）十年皆否，"宁使天干生地支，弗使地支生天干"；战（克）、冲（破）、和（合）、好（同类）四字分断岁运——最凶者天克地冲，日犯岁君日主旺相无咎、休囚必凶。贞元——年为元、月为亨、日为利、时为贞（年月吉者前半世吉，日时吉者后半世吉），大运初十五年为元、次十五年为亨、中十五年为利、后十五年为贞；身后运之吉凶可知子孙之兴替。

## 4. 该书的独门之处

1. **"三元"作为论命第一层框架，并以"顺悖"定吉凶**。以干为天元、支为地元、支中所藏为人元（通神论·天道、人道），把"干弱支生之、支衰干辅之"视为顺、把"干衰支抑之、支弱干克之"视为悖。这一"干支互载"的顺悖判断，是本书区别于一般格局派命书的第一刀。

2. **力辟神煞、奇格、纳音、刑穿破，回归纯粹五行生克**。全书反复痛斥"桃花咸池、金锁铁蛇""壬骑龙背、六阴朝阳、鼠贵格""飞天禄马""杂气财官喜冲""禄分四种""阳刃劫财主克妻""阳生阴死"等，主张**"吉凶神煞之多端，何如生克制化之一理"**。第 2.0 节的判断流程即建立在"尽扫一切名目，只看用神"这一立场上。任氏甚至逐一驳"三奇拱贵"命例（如甲子戊辰庚申壬午一造）。

3. **"通根重于比肩"的量化旺衰法**。明确给出可操作的排序：**天干一比肩 ＜ 地支一余气墓库 ＜ 天干二比肩 ＜ 地支一长生禄旺**；"干多不如根重"。并据此推翻"得时便旺、失令便衰"的"死法"，提出"得时不旺、失时不弱"。

4. **"五行颠倒之真机"三十条**（木太旺似金、木旺极似火……水衰极似火）。这是一套把**极端旺衰重新折算为另一种五行来取用**的独特换算表，是《滴天髓》原文"旺则宜泄宜伤"之外任氏补出的变局，宋明诸书未见同等系统表述。

5. **独创新概念"源头—流住—收局"**（通神论·源流）。以四柱最旺之神为源头，追其流止之地定吉凶，并把源头阻节之神逐项对应到六亲（阻节是印→长辈之祸，是比劫→兄弟之累，是财→妻妾之祸，是食伤→子孙之累，是官煞→官刑之祸），最后以"收局一字"定贵贱——"去我浊气作我喜神者不贵亦富，去我清气作我忌神者不贫亦贱"。这一"逐环节映射六亲"的技法在命书中极为罕见。

6. **明确把"官杀"按成因分为六等并各附命例**（财滋弱杀、杀重用印、食神制杀、合官留杀、官杀混杂、制杀太过），并给出反常识判语：**"与其制杀太过，不若官杀混杂之美"**；"官杀混杂者富贵甚多"，关键在"日主旺相可混、日主休囚不可混"。

7. **自创"从旺、从强、从气、从势"四从**（任氏自注"此四从，诸书所未载，余之立说，试验确实"），与传统的从财、从官杀并列，并各给行运宜忌（从强食伤运有印冲克必凶，从势须行财运和解）。

8. **系统化的"反局"四诀（君赖臣生、儿能救母、母慈灭子、夫健怕妻）**。把印太旺（母慈灭子）、财多克身（夫健怕妻）等"似乎吉而实凶"的结构单列，并给出"顺母之性助其子""重在一健字"等具体应对，与常规"财多身弱宜比劫"之说形成互补层次。

9. **任氏重定六亲配属**：明确反对"以财为父、以官为子"，改定"生我者为父母（印）、我生者为子女（食伤）、我克者为妇妾（财）、克我者为官鬼（祖父）、同我者为兄弟（比劫）"，并以"用神为子、忌神为女"作为子息断法。

10. **断病与断事两套系统互补**（六亲论·疾病章末段）：若八字所见之病与实际不符，则须转而断其六亲吉凶、事体否泰（如肺肾之病不验，则断财多破耗、妻陋子劣），任氏自称"断断必有一验"。这一"以事代病"的换算法是本书在疾病章上的独特处理。

11. **岁运章的"盖头截脚"量化算法**：给出喜行五运时"必要/次则"的具体干支名单，以及"天干生地支则荫厚、地支生天干则气泄""支不载干则十年皆否"的操作细则，把"运"从笼统吉凶细化为可核对的干支组合。

## 5. 局限与后世争议

1. **辟神煞过激，走向另一偏**。任氏对刑、穿、破一概否定（"刑之义无所取""害之义尤为穿凿""破之义尤属不经，削之可也"），后世（尤其盲派与新派）仍广泛使用三刑、六害、羊刃、驿马、空亡等作辅助判断；本书"一律削去"的态度被批评为削足适履。任氏自己也承认："若内之刑既不足为凭，而害之义尤为穿凿"——这是立场而非考证。

2. **女命章的时代局限极其明显**。全章以"贞淫贤愚""克夫欺夫"为纲，且正文夹有大段"严肃闺门""入寺烧香、游玩看戏听词"之类的说教，并把命理与社会训诫混同（如"或由母姑不良，幼失闺训……保无触念动心乎"）。以今日标准看，其淫邪十七则断法属于明显的时代偏见，且以"伤官重必轻佻美貌而多淫"作通则，逻辑上以偏概全。任氏自身亦有警觉（"不可轻断淫邪，以渎神怒"），但仅止于劝诫。

3. **"世德心田居一，山川居二，命格居三"非命理命题**。出身章引入世德、山川、阴骘因果，并把"从世德而来者不论命"写入技法，已越出五行生克的可验证范围。同样，何知章论寿有"仁者寿""为人宽厚和平……未有不富贵福寿者"之语，把道德品格与命局直接挂钩；论富贵贫贱亦有"贪财改帛而恋金谷者竟遭一时之显戮"之类果报论断。这是明清命书的普遍风气，非本书所独有，但与本书"只存用神"的方法论立场自相矛盾。

4. **"身衰印作儿""用神为子、忌神为女"等子息断法证据薄弱**。子息数目的推法（水一火二木三金四土五，当令者倍之、休囚者减半）源自任氏个人命例统计，样本与统计口径均未交代，且"每年得一子连生十六子"一类命例近于轶闻，不可作通则使用。

5. **部分判语内部张力未能消解**。例如：通神论·衰旺既主张"旺则宜泄宜伤，衰则喜帮喜助"，又在体用、从象、顺逆诸章主张"旺极者抑之反激则宜扶之、弱极者扶之徒劳则宜抑之"；任氏虽以"得其中""得其宜"调和，实际操作时**"多旺才算旺极"没有给出可核对的界限**，只能凭经验裁量。又如官杀章"官杀混杂者富贵甚多"与伤官章"伤官见官为祸百端"、制杀太过章"与其制杀太过不若官杀混杂之美"三处并读，初学者极易互扰。

6. **原注与任氏注多处相左，需以任氏为准**。如"天合地者地旺喜静"（原注只列六日，任氏判定只有戊子辛巳丁亥壬午四日可论合）、"甲申戊寅真为杀印相生"（任氏谓"非止此四日"且"即甲申戊寅亦难作据"）、"二三四五用神，的非妙造"（任氏斥为大谬）、"闲神只不去动它"（任氏斥为有误）、"震内兑外"之攻备说（任氏以攻成润从暖五法易之）、精气血之分（原注以金水为精木火为神，任氏改以生我者为精、克我者为神）。**凡遇原注与"任氏曰"相冲突，应以任氏为准，但须知道这是任氏的个人改造而非《滴天髓》原意。**

7. **滴天髓原文歌诀本身过于简略**，须借任氏注方能落地。如"地道有燥湿""隐显""众寡""震兑""坎离"诸章，原文各仅四句，若无任氏所补的燥湿宜忌、隐显门槛、众寡取舍、震兑五法、坎离五法，几不可操作。**第 3 节中标注〔原文〕的条目，单独引用时其判断力有限，必须与第 2 节对应规则同用。**

8. **岁运章的干支优劣表有内在含混**。任氏一面称"喜行金运必要庚申辛酉，次则戌申、己酉、庚辰、辛巳"（原文"戌申"当为"戊申"之讹），一面又斥"截脚"十年皆否——但戊申、庚辰等本身近于"截脚"组合（如戊申为土盖金、庚辰为金坐湿土），"次则"与禁忌之间界限不清。**此表仅可作倾向参考，不宜逐字执行。**
