# 子平真诠 · 技法知识模块

## 1. 传承与体例

《子平真诠》，清乾隆进士沈孝瞻原著，是八字**格局派**最精要的经典。全书四十七篇，前三篇论干支阴阳、生克、生死，四至七篇论合化与刑冲会合，第八至二十四篇论用神（取法、成败救应、变化、纯杂、高低、因成得败、配气候、相神、杂气、墓库、吉凶神破成格、生克先后、星辰、外格、宫分配六亲、妻子），第二十五至三十篇论行运与破斥时说，第三十一至四十七篇分论正官、财、印绶、食神、偏官、伤官、阳刃、建禄月劫、杂格九类格局（各附取运）。

最核心的方法论主张（一句话）：**八字用神专求月令，以日干配月令地支定格局，再以"成格—破格—带忌—救应"四层规则判其成败高低，而全局之成常赖一字之相。**

本书与《滴天髓》一浅一深，前者如循序渐进的课本与阶梯，后者如树顶硕果；本书"以月令用神为经，以诸神为纬"，对用神成败、喜忌生克制化、透与会、有情无情、有力无力的解析尤为透辟。

## 2. 核心技法体系

### 2.0 判断总顺序（先看什么，再看什么）

1. **第一步：定月令用神**。以日干配月令地支，察其生克关系，格局由此而分。
2. **第二步：判善神/不善神**。财官印食为善神→顺用；煞伤劫刃为不善神→逆用。
3. **第三步：看四柱配合是否成格**（八格各有成格条件）。
4. **第四步：看成中有无带忌、败中有无救应**。
5. **第五步：看月令藏干是否因透干、会支而变化，变后是纯是杂**。
6. **第六步：以有情无情、有力无力定格局高低。**
7. **第七步：参气候调候，纠格局之偏**。
8. **第八步：定相神**——全局之格赖此一字而成者即相神；相神不可伤。
9. **第九步：排大运**，以运之干支配八字之喜忌，并察成格、变格、透清。

总口诀：**"支为干之生地，干为支之发用"**，故须逐干逐支、上下统看。

### 2.1 干支阴阳与十神善恶之分

- 十干十二支之设：有阴阳→生五行；五行之中各有阴阳，故有甲乙、寅卯。**甲乙在天，动而不居；寅卯在地，止而不迁。**甲禄于寅，乙禄于卯。
- **官煞何以分**（本书独有之论）：以"气"与"质"判。
  - 阳干为**气**（甲＝木之生气，庚＝秋天肃杀之气，丙＝融和之气，戊＝冲气）；阴干为**质**（乙＝木之形质，辛＝人间五金之质，丁＝薪传之火，己、癸为质）。
  - 规则：**克我者与日干同类（同气或同质）相畏，则为七煞；异类（气相制质、质相制气）不相畏，则为正官。**
  - 例证：庚（气）逢丙（气）→丙能克去庚→**庚以丙为杀**；辛（质）不畏阳和→**辛以丙为官**；辛（质）逢丁（薪传之火，质）→立化→**辛以丁为杀**；庚（气）不畏丁→**庚以丁为官**。木类推：甲（气）逢庚（气）为杀、逢辛（质）为官；乙（质）逢辛（质）为杀、逢庚（气）为官。
- 印绶之中偏正相似，生克之殊可置勿论；**相克之内一官一煞，善恶判然，其理不可不细详。**
- 土为木火金水冲气所结，寄旺于四时。

### 2.2 十二长生与旺衰根气判定

十二宫名义（长生→沐浴→冠带→临官→帝旺→衰→病→死→墓→绝→胎→养）为假借形容之词。**阳主聚，以进为进，故主顺；阴主散，以退为退，故主逆**——此阳顺阴逆之由。"阳之所生，即阴之所死"，彼此互换。

**旺衰活看法（关键规则）：**

- 条件：八字虽以月令为重，而旺相休囚年月日时亦有损益之权 → 推断：**生月不值令而年时值禄旺，不可便作衰看。**
- 条件：干庚辛而支酉丑，无火制 → 得时而不旺（春木虽强，金太重而木亦危）；逢土生而必夭。
- 条件：干甲乙而支寅卯 → **失时不弱**；遇官透而能受，逢水生而太过则不可。
- **总纲：十干不论月令休囚，只要四柱有根，便能受财官食神而当伤官七煞。**
- 根之轻重层级：
  - 长生、禄、旺＝根之重者；墓库、余气＝根之轻者。
  - **得一比肩，不如得支中一墓库**（如甲逢未、丙逢戌）。
  - 例外：**乙逢戌、丁逢丑不作此论**（戌中无藏木，丑中无藏火）。
  - **得二比肩，不如得一余气**（如乙逢辰、丁逢未）。
  - **得三比肩，不如得一长生禄刃**（如甲逢亥子寅卯）。
  - 阴长生不作"长生禄刃"论（如乙逢午、丁逢酉），然亦为有根，比得一余气。
- 日主不必生逢禄旺，月令休囚而年日时中得长生禄旺便不为弱；就使逢库亦为有根。
- **阳长生有力，阴长生不甚有力，然亦不弱。逢库则阳为有根，阴为无用**——因"阳大阴小，阳得兼阴，阴不能兼阳"。
- 破斥：时说"投库而必冲"为俗书之谬；阳干逢库（如壬逢辰、丙坐戌）即水火通根身库，不可求刑冲开之。
- **干多不如根重**（比劫如朋友相扶，通根如室家可住）。

### 2.3 十干合化与合而不合

**化气次序**：甲己化土→乙庚化金→丙辛化水→丁壬化木→戊癸化火（先之以土，相生之序）。

**合之向背（喜忌因合而变）：**

- 四喜神因合而无用 → 逢吉不为吉：甲用辛官而透丙作合（官非其官）；甲用癸印而透戊作合（印非其印）；甲用己财而已与别位之甲作合（财非其财）；甲用丙食与辛作合（非其食）。年己月甲则年上之财被月合去，日主无分；年甲月己则月上之财被年合去。
- 四忌神因合化吉 → 逢凶不为凶：甲逢庚煞与乙作合而煞不攻身；甲逢丁伤与壬作合而丁不为伤官；甲逢壬枭与丁作合而壬不夺食。
- 六亲同理：男以财为妻而被别干合去，则财妻不亲其夫；女以官为夫而被他干合去，则官夫不爱其妻。

**合而不合的四种情形：**

| 情形 | 条件 | 结论 |
|---|---|---|
| 隔于有所间 | 甲己之间有庚间隔 | 制于势，合而不敢合，有若无 |
| 隔位太远 | 甲在年干、己在时上 | 合而不能合，半合，祸福得十之二三 |
| 合而无伤于合 | 甲生寅卯，月时两透辛官，年丙合月辛 | 合一留一，官星反轻，无害 |
| 合而无伤于合 | 甲逢月刃，庚辛并透，丙与辛合 | 合官留煞，煞刃依然成格 |
| 合而不以合论 | 本身之合（五阳逢财、五阴遇官，日干自合） | 是我之官、我之财，不为合去；若他干先合（如庚在年、乙在月），则日干反不能合，是为合去 |
| 争合妒合 | 两辛合丙、两丁合壬 | 终有合意但情不专；若两合一而隔位则全无争妒（高太尉命：庚午、乙酉、甲子、乙亥，两乙合庚而甲日隔之，仍作合煞留官，无减福） |

### 2.4 刑冲会合与解破

- 定义：刑＝三刑（子卯巳申寅之类）；冲＝六冲（子午卯酉之类）；会＝三会（申子辰之类）；合＝六合（子丑之类）。皆以地支宫分言，系对射之意。
- **会合可以解刑冲**：甲生酉月逢卯则冲，支有戌则卯戌合而不冲；有辰则酉辰合而不冲；有亥未则卯亥未会而不冲；有巳丑则酉巳丑会而不冲。丙生子月逢卯则刑，有戌、丑、亥未、申辰皆可解。
- **因解而反得刑冲**：甲生子月，支逢二卯（二卯不刑一子），支又逢戌，戌与卯合本为解刑，合去其一则一合而一刑。
- **刑冲而会合不能解**：子年午月日坐丑，丑子合可解冲，而时逢巳酉则丑与巳酉会，子复冲午。
- **以刑冲解刑冲**：四柱之中刑冲俱不为美，**刑冲用神尤为破格**，不如以另位之刑冲解月令之刑冲。例：丙生子月，卯以刑子，支又逢酉则卯与酉冲，不刑月令之官；甲生酉月，卯日冲之，时逢子立则卯与子刑，月令官星冲之无力，虽别宫刑冲六亲不无刑克，**而月官犹在，其格不破**。

### 2.5 用神取法总则

- **用神专求月令**，以日干配月令地支，生克不同则格局分。
- 善神顺用（财官印食）：
  - 财 → 喜食神以相生，生官以护财；
  - 官 → 喜透财以相生，生印以护官；
  - 印 → 喜官煞以相生，劫财以护印；
  - 食 → 喜身旺以相生，生财以护食。
- 不善神逆用（煞伤劫刃）：
  - 七煞 → 喜食神以制伏，**忌财印以资扶**；
  - 伤官 → 喜佩印以制伏，生财以化伤；
  - 阳刃 → 喜官煞以制伏，**忌官煞之俱无**；
  - 月劫 → 喜透官以制伏，用财而透食以化劫。
- **月令无用神者**（如木生寅卯，日与月同，本身不可为用）→ 看四柱有无财官煞食透干会支，另取用神；然终以月令为主，然后寻用。此即建禄月劫之格，"非用而即用神也"。
- 五大谬误（皆由不知月令而妄论）：
  - 见正官佩印而以为官印双全，与印绶用官者同论；
  - 见财透食神而不以为财逢食生，反以为食神生财；
  - 见偏印透食而不以为泄身之秀，反以为枭神夺食宜用财制；
  - 见煞逢食制而露印，不以为去食护煞，反以为煞印相生；
  - 见煞格逢刃，不以为刃可帮身制煞，反以为七煞制刃。

### 2.6 ★格局成破救应总表（本书最高优先项）

**成格条件（何谓成）**

| 格 | 成格条件 |
|---|---|
| 官格 | 官逢财印，又无刑冲破害 |
| 财格 | 财生官旺；或财逢食生而身强带比；或财格透印而位置妥贴，两不相克 |
| 印格 | 印轻逢煞；或官印双全；或身印两旺而用食伤泄气；或印多逢财而财透根轻 |
| 食格 | 食神生财；或食带煞而无财；弃食就煞而透印 |
| 煞格 | 身强七煞逢制 |
| 伤官格 | 伤官生财；或伤官佩印而伤官旺、印有根；或伤官旺、身主弱而透煞印；或伤官带煞而无财 |
| 阳刃格 | 阳刃透官煞而露财印，不见伤官 |
| 建禄月劫格 | 透官而逢财印；透财而逢食伤；透煞而遇制伏 |

**破格条件（何谓败）**

| 格 | 破格条件 |
|---|---|
| 官格 | 官逢伤克刑冲 |
| 财格 | 财轻比重；财透七煞 |
| 印格 | 印轻逢财；身强印重而透煞 |
| 食神格 | 食神逢枭；生财露煞 |
| 七煞格 | 七煞逢财无制 |
| 伤官格 | 伤官非金水而见官；生财生带煞；佩印而伤轻身旺 |
| 阳刃格 | 阳刃无官煞 |
| 建禄月劫格 | 无财官，透煞印 |

**带忌（成中有败之由）**

正官逢财而又逢伤；透官而又逢合；财旺生官而又逢伤逢合；印透食以泄气而又遇财露；透煞以生印而又透财（去印存煞）；食神带煞印而又逢财；七煞逢食制而又逢印；伤官生财而财又逢合；佩印而印又遭伤；透财而逢煞。

**救应之法（败中有成之由）**

| 病 | 药（救应） |
|---|---|
| 官逢伤 | 透印以解之；杂煞而合煞以清之；刑冲而会合以解之 |
| 财逢劫 | 透食以化之；生官以制之 |
| 财逢煞 | 食神制煞以生财；或存财而合煞 |
| 印逢财 | 劫财以解之；或合财而存印 |
| 食逢枭 | 就煞以成格；或生财以护食 |
| 煞逢食制而印来护煞 | 逢财以去印存食 |
| 伤官生财透煞 | 煞逢合 |
| 阳刃用官煞带伤食 | 重印以护之 |
| 建禄月劫用官遇伤 | 伤被合；用财带煞而煞被合 |

总则：**"成中有败，必是带忌；败中有成，全凭救应。"** 八字妙用全在成败救应，其中权轻权重，甚是活泼。

### 2.7 用神变化

月令所藏不一，故用神有变化（十二支除子午卯酉外皆有藏，不必四库）。理据：寅中甲为本主，丙、戊为长生，**不透甲而透丙，则如知府不临郡而同知得以作主**。

- 从透出而变：丁生亥月本为正官，支全卯未则化为印；己生申月本属伤官，藏庚透壬则化为财。
- 从会合而变：癸生寅月，月令伤官秉令，藏甲透丙、会午会戌成寅午戌三合，伤化为财（加丙透则完全作财论；即不透丙而透戊，亦作财旺生官论，**不作伤官见官论**）；乙生寅月，月劫秉令，会午会戌则劫化为食伤，透戊则为食伤生财，**不作比劫争财论**。

**变之而善**（忌化为喜）：辛生寅月逢丙而化财为官；壬生戌月逢辛而化煞为印；癸生寅月伤化为财；乙生寅月劫化为食伤。

**变之而不善**：丙生寅月本为印绶，甲不透干而会午会戌则化为劫；丙生申月本属偏财，藏庚透壬、会子会辰则化为煞。

**变而不失本格**：
- 辛生寅月透丙化官而又透甲 → 格成正财，正官乃其兼格；
- 乙生申月透壬化印而又透戊 → 财能生官，印逢财而退位，虽通月令**格成伤官**，而戊官忌见；
- 丙生寅月午戌会劫，又或透甲或透壬 → 仍为印而格不破；
- 丙生申月逢壬化煞而又透戊 → 食神能制煞生财，仍为财格，不失富贵。

**"是故八字非用神不立，用神非变化不灵。"**

### 2.8 用神纯杂

- **纯＝互用而两相得者**：辛生寅月甲丙并透（财与官相生）；戊生申月庚壬并透（财与食相生）；癸生未月乙己并透（煞与食相克而相克得其当）。→ 纯者吉。
- **杂＝互用而两不相谋者**：壬生未月乙己并透（官与伤相克）；甲生辰月戊壬并透（印与财相克）。→ 杂者凶。

### 2.9 用神格局高低

总纲：财官印食煞伤劫刃，何格无贵、何格无贱；**其理之大纲，在有情无情、有力无力之间而已。**

- **有情**（相神得用，忌神反为我用）：
  - 正官佩印不如透财，而四柱带伤则反推佩印。例：甲透酉官，透丁合壬，是谓合伤存官，遂成贵格，以其有情。
  - 财忌比劫，而与煞作合，劫反为用。例：甲生辰月透戊成格，遇乙为劫、逢庚为煞，二者相合皆得其用。
- **有力**：
  - 身强煞露而食神又旺。例：乙生酉月，辛金透、丁火刚、秋木盛，三者皆备，极等之贵。
  - 官强财透、身逢禄刃。例：丙生子月，癸水透、庚金露而坐寅午，三者皆均，遂成大贵。
- **有情兼有力**：甲用酉官，壬合丁以清官而壬水根深；乙用酉煞，辛逢丁制而辛之禄即丁之长生、同根月令。
- **有情而非情之至**：甲用酉官，透丁逢癸，癸克不如壬合。
- **有力而非力之全**：乙逢酉煞透丁以制，而煞强丁弱、丁旺煞不昂，或辛丁并旺而乙根不甚深 → 格之高而次者。
- **无情（格之低者）**：
  - 印用七煞本为贵格，而**身强印旺、透煞孤贫**——身旺不劳印生，印旺何劳煞助，偏之又偏。
  - 伤官佩印本秀而贵，而**身主甚旺、伤官甚浅、印又太重**——不贵不秀，欲助身则身强，制伤则伤浅。
- **无力（或夭或贫）**：煞强食旺而身无根；身强比重而财无气。
- **"或一字而有千钧之力，或半字而败全局之美"**，随时观理，难以拟议。

### 2.10 因成得败、因败得成

- **因成得败**：
  - 化伤为财，格之成也；然辛生亥月透丁为用，卯未会财乃以党煞 → 因成得败。
  - 印用七煞，格之成也；然癸生申月秋金重重，略带财以损太过，逢煞则煞印忌财 → 因成得败。
- **因败得成**：
  - 官印逢伤，格之败也；然辛生戊戌月，年丙时壬，壬不能越戊克丙，而反能泄身为秀 → 因败得成。
  - 煞刃逢食，格之败也；然庚生酉月，年丙月丁，时上逢壬，则食神合官留煞，官煞不杂，煞刃局清 → 因败得成。
- 观命者毋眩而无主、执而不化。

### 2.11 用神配气候得失（调候）

| 情形 | 常规 | 调候例外 |

| 印绶遇官（官印双全） | 无人不贵 | 冬木逢水，虽透官星亦难必贵（金寒水冻，冻水不能生木） |
| 身印两旺透食则贵 | 凡印格皆然 | 用之冬木尤为秀气（冬木逢火，既可泄身又可调候） |

| 伤官用财 | 本为贵格 | 用之冬水，即使小富亦多不贵（冻水不能生木）；用之夏木贵而不甚秀（燥土不甚灵秀） |

### 2.12 相神紧要

- **相神定义**：月令既得用神，则别位亦必有辅。"官逢财生则官为用、财为相；财旺生官则财为用、官为相；煞逢食制则煞为用、食为相"是**一定之法**，非通变之妙；要而言之，**凡全局之格赖此一字而成者，均谓之相**。
- 相神之例：甲用酉官透丁逢壬 → 合伤存官全赖壬之相；戊用子财透甲并己 → 合煞存财全赖己之相；乙用酉煞年丁月癸时逢戊 → 合去癸印使丁得制煞全赖戊之相；癸生亥月透丙为财而财逢月劫，卯未会局化水为木转劫生财 → 全赖卯未之相；庚生申月透癸泄气，子辰会局化金为水而成金水相涵 → 全赖子辰之相。
- **"伤用神甚于伤身，伤相甚于伤用。"**
- **"相神无破，贵格已成；相神相伤，立败其格。"**（如甲用酉官透丁逢癸印制伤护官，而又逢戊，癸合戊而不制丁，癸水之相伤矣。）

### 2.13 杂气（四墓）取用

- 四墓为冲气，以其所藏者多用神不一，故谓之杂气（如辰藏戊，又为水库，又为乙余气）。
- 取用原则：**透干会支，取其清者用之，杂而不杂。**
  - 透干：甲生辰月，透戊用偏财、透癸用正印、透乙用月劫。
  - 会支：甲生辰月逢申子会局，用水印。
  - **一透则一用，兼透则兼用，透而又会则透与会并用。**
- **有情（顺而相成）**：甲生辰月透癸为印而又会子会申成局，印绶之格清而不杂；丙生辰月透癸为官又逢乙为印，官印相生而印又能去辰中暗土以清官；甲生丑月辛透为官（或巳酉会金局）而又透己财生官。
- **无情（逆而相背）**：壬生未月透己为官而地支会亥卯成伤官之局；甲生辰月透戊为财又透壬癸为印（透癸则戊癸作合，财印两失；透壬则财印两伤，贪财坏印）；甲生戌月透辛为官又透丁伤官、月支会寅会午成伤官局。
- **有情而卒无情**：甲生辰月逢壬为印而逢丙，火能生土助辰中之戊，印格不清（必壬干透而支又会申会子，则透丙亦无所碍）；甲生辰月透壬为印而支逢戌，戌辰冲则土动，干头之壬难通月令，印格不成 → **富而不贵**。
- **无情而终有情**：癸生辰月透戊为官又会申子成水局，透干与会支相克，然所克者乃劫财（月劫用官何伤）；丙生辰月透戊为食又透壬为煞，两干相克而所克者乃偏官（食神带煞、煞逢食制皆美格，其局愈贵）。

### 2.14 墓库刑冲之说

- 破斥："辰戌丑未最喜刑冲，财官入库不冲不发"——俗书盛称，然**子平先生造命无是说**。杂气透干会支岂不甚美，何劳刑冲？
- **四库之中虽五行俱有，而终以土为主；土冲则灵，金木水火不能取胜以四库之冲而动。**
  - 财官属土 → 冲则库启（甲用戊财而辰戌冲、壬用己官而丑未冲），然**终以戊己干头为清用，干既透则不冲亦得**。
  - 财官为水 → 冲则反累（己生辰月壬透为财，戌冲则劫动；丁生辰月透壬为官，戌冲则伤官）。
- 四墓土自为冲，乃**冲动之冲**，非冲克之冲（子午卯酉二者相仇乃冲克之冲）。
- 结论：**"四墓不忌刑冲，刑冲未必成格。"**
- 破斥时说：月令本非四墓、别有用神，而年月日时一带四墓便求刑冲；日临四库不以为身坐库根而以为身主入库，求冲以解——皆谬。

### 2.15 四吉神能破格 / 四凶神能成格

- **四吉神（财官印食）用之不当亦能破格**：食神带煞而透财为害（财破格）；春木火旺见官则忌（官破格）；煞逢食制而透印无功（印破格）；财旺生官而露食则杂（食破格）。要旨：**"官用食破，印用财破"**；参苓芪术本属良材，用之失宜亦能害人。
- **四凶神（煞伤枭刃）施之得宜亦能成格**：印绶根轻透煞为助（煞成格）；财逢比劫伤官可解（伤成格）；食神带煞灵枭得用（枭成格）；财逢七煞刃可解厄（刃成格）。要旨：**"财不忌伤，官不忌枭，煞不忌刃"**。
- **总纲：吉凶喜忌全在是否合于需要，不因名称而有分别**；弱者以生扶为喜，强者因生扶而反害；衰者以裁抑为忌，太旺者反以裁抑而得益。

### 2.16 生克先后分吉凶

同此生克，先后之间遂分吉凶（"尤谈命之奥"）：

| 格 | 组合 | 吉（先→后） | 凶（先→后） |
|---|---|---|---|
| 正官 | 财伤并透 | 丁（伤）先戊（财）后 → 后以财为解伤，即不能贵，后运必有结局 | 戊先丁后 → 官遇财生而后因伤破，上运稍顺终无结局，子嗣亦难 |
| 印格 | 贪财坏印 | 己（财）先癸（印）后 → 稍顺晚境 | 癸先己在时 → 晚景亦悴 |
| 食神 | 财枭并透 | 庚（枭）先丙（财）后 → 晚运必亨，富而望贵 | 丙先庚在时 → 晚运必淡，富贵两空 |
| 七煞 | 财食并透 | 癸（财）先辛（食）后 → 财以助用而后煞用食制，不失大贵 | 辛先癸在时 → 煞逢食制而财转食党煞，非特不贵，后运萧索，兼难永寿 |

- **隔位之妙（重例）**：丙生甲寅月、年癸时戊 → 官能生印而不怕戊合，戊能泄身为秀而不得越甲以合癸，大贵之格；假使年月戊癸而时甲，或年甲而月癸时戊，则戊无所隔而合全癸，**格大破矣**。
- 又例：丙生辛酉、年癸时己 → 伤因财间，伤之无力，间有小贵；假如癸己并而中无辛隔，格尽破。
- 又例：辛生申月、年壬月戊、时上丙官 → 不愁隔戊之壬，格亦许贵；假使年丙月壬而时戊，或年戊月丙而时壬，则壬能克丙，无望其贵。

### 2.17 星辰无关格局

- **"格局既成，即使满盘孤辰入煞，何损其贵？格局既破，即使满盘天德贵人，何以为功？"**
- 星辰既不能为生克之用，又何以操成败之权。
- 书中禄贵往往指正官，非禄堂、贵人。如"正财得伤贵为奇"——伤贵者伤官，乃生财之具；若指贵人则伤贵为何物？又如"因得禄而避位"，得禄者得官也，运得官乡宜进爵，然财用伤官食神者运透官则格杂，正官运又遇官则重，凡此只可避位。
- 女命"贵众则舞裙歌扇"——贵众者官众也，女以官为夫，正夫岂可叠出；若作贵人（天星）则何碍于众。
- 星辰书之言可参考：**"贵人头上带财官，门充驰马"**——财官如人美貌，贵人如人衣服，貌美者衣服美则现；其实财官成格即非贵人头上亦门充驰马。二德亦然：局清贵又带二德必受荣封，然**终无关于格局之贵贱**。

### 2.18 外格用舍

- 外格者，**因月令无用，权而用之**（如春木冬水、土生四季之类，日与月同难以作用）。
- 可用之外格：类象、属象、冲财、会禄、刑合、遥迎、井栏、朝阳诸格。
- **禁例**：月令自有用神，岂可另寻外格？干头已有财官七煞而弃之以就外格，亦大谬。**"提纲有用提纲重"、"有官莫寻格局"，不易之论。**
- 辨正："月令无用"原指月令本无用神；今人往往以财被劫、官被伤之类（用神已破）皆以为月令无取而弃之以就外格，则谬之又谬。

### 2.19 宫分配六亲与论妻子

**宫位配六亲**：年月日时自上而下，祖父妻子亦自上而下（以地相配，不易之位）。

**用神配六亲**：正印为母（生我）；偏财为父（偏财者母之正夫）；正财为妻（受我克制，夫为妻纲）；官煞为子女（官煞者财所生）；比肩为兄弟。有无得力或吉或凶，则以四柱所存财官伤刃系是何物，然后以六亲配用神，参局中喜忌而配之。

**论妻**：

- **坐下吉凶须以月令用神配喜忌，不可执一**：妻宫坐财，印格逢之反为不美；妻坐官，伤官格逢之岂能顺意；妻坐伤官（凶），财格逢之可生财、煞格逢之可制煞，反主妻能内助；妻坐阳刃（凶），而日主无气全凭日刃帮身，则妻必能相夫。
- **既看妻宫，又看妻星**（干头之财）：
  - 妻透而成局（官格透财、印多逢财、食伤透财为用之类）→ 即坐下无用亦主内助；
  - 妻透而破格（印轻财露、食神伤官、透煞逢财之类）→ 即坐下有用亦防刑克；
  - 妻透成格或妻宫有用而坐下刑冲 → 未免得美妻而难偕老；
  - **妻星两透、偏正杂出 → 一夫多妻，亦防刑克。**

**论子息**：

- 看宫分与星所透喜忌，理与论妻略同；先看时支，再以时干子星配之。
- 长生沐浴歌（断子数）：
  - 长生四子中旬半，沐浴一双保吉祥，
  - 冠带临官三子位，旺中五子自成行，
  - 衰中二子病中一，死中至老没儿郎，
  - 除非养取他之子，入墓之时命夭亡，
  - 受气为绝一个子，胎中头产养姑娘，
  - 养中三子只留一，男子宫中子细详。
- **长生论法用阳而不用阴**：甲乙日只用庚金长生，巳酉丑顺数之局，不用辛金逆数之子申辰。**木为日主，不问甲乙，总以庚为男、辛为女**，不拘官煞（原文自注：男女只论五行长生）。
- 时干有用（财格而时干透食、官格而时干透财之类）→ 即使时逢死绝亦主子贵，但不甚繁；又逢生旺则麟儿绕膝。时干不好、子透破局，即逢生旺难为子息；若又死绝则无所望。

### 2.20 行运法则

**"论运与看命无二法。"** 看命以四柱干支配月令喜忌；取运则以运之干支配八字喜忌。每运行一字，必以此一字配命中干支统观。

**喜运条目**：官用印以制伤而运助印；财生官而身轻而运助身；印带财为忌而运劫财；食带煞成格，身轻而运逢印、煞重而运助食；伤官佩印而行官煞；阳刃用官而运助财乡；月劫用财而运行伤食。

**忌运条目**：正官无印而运行伤；财不透食而运行煞；印绶用官而运合官；食神带煞而运行财；七煞食制而运逢枭；伤官佩印而运行财；阳刃用煞而运逢食；建禄用官而运逢伤。

**辨似**：似喜而实忌——官逢印运而本命有合，印逢官运而本命用煞；似忌而实喜——官逢伤运而命透印，财行煞运而命透食。

**干支有别（细目）**：
- **行干不行支**：丙生子月亥年，逢丙丁则帮身，逢巳午则相冲。
- **行支不行干**：甲生酉月辛金透而官犹弱，逢申酉则官植根，逢庚辛则混煞重官。
- **干同一类而不两行**：丁生亥月年透壬官，逢丙则帮身，逢丁则合官。
- **支同一类而不两行**：戊生卯月丑年，逢申则自坐长生，逢酉则会丑以伤官。
- **冲分缓急**：冲年月则急，冲日时则缓。
- **冲分轻重**：运本美而逢冲则轻，运既忌而又冲则重。
- **逢冲而不冲**：甲用酉官行卯则冲，而本命巳酉相会则冲无力；年支亥未则卯逢年会而不冲月官。
- **一冲而得两冲**：乙用申官，两申并而不冲一寅，运又逢寅则运与本命合成二寅，以冲二申。

**成格变格**：
- **成格**＝本命用神成而未全，从而就之（丁生辰月透壬为官而运逢申子以会之；乙生辰月或申或子会印成局而运逢壬癸以透之）。
- **变格**＝丁生辰月透壬为官而运逢戊，透出辰中伤官；壬生戌月丁己并透、支会寅午作财旺生官而运逢戊土透出戌中七煞；壬生亥月透己为用作建禄用官而运逢卯未会亥成木，化建禄为伤。
- **逢成格而不喜**：壬生午月运透己官而本命有甲乙。
- **逢变格而不忌**：丁生辰月透壬用官，逢戊而命有甲；壬生亥月透己用官，运逢卯未而命有庚辛。
- **成格变格关系甚大，较之喜忌祸福尤重。**

**干支喜忌有别**：干主天、动而有为；支主地、静以待用；且**干主一而支藏多**。故甲用酉官，逢庚辛则官煞杂而申酉不作此例；逢二辛则官犯重而二酉不作此例；透丁则伤官而逢午不作此例（丁动而午静，且丁巳并藏）。然支亦能作祸福：甲用酉官，逢午酉未能伤，而又遇寅遇戌不隔二位，二者合而火动亦能伤；反之甲生申月午不制煞，会寅会戌二者清局而火动亦能。**"然必会有动，是正与干有别也。"**

**支中喜忌逢运透清**：
- **透清**＝如甲用酉官，逢辰未即为财而运透戊，逢午未即为伤而运透丁。
- 命与运二支会局亦作清论（甲用酉官、本命有午而运逢寅戌）。
- 位置轻重：**在年则重，在日次之**；时生于午而运逢寅戌会局则缓而不急。
- 此五年中亦能为其祸福；若月令之物而运中透清，则与命中原有者不甚相悬（即行运成格变格）。
- **"支为干之生地，干为支之发用。"** 命中有一甲字，则统观四支有寅亥卯未否，有一字皆甲木之根；有一亥字，则统观四支有壬甲二字否——有壬则亥为壬禄，用甲则亥为甲长生，壬甲俱全则一以禄为根、一以长生为根，二者并用。

### 2.21 正官格

- 官以克身，虽与七煞有别，终受彼制，故**切忌刑冲破害**（正官者分所当尊）。以刑冲破害为忌，则以生之护之为喜；**存其喜而去其忌则贵**。
- **财印并透者，两不相碍，其贵也大**。例：薛相公命（甲申、壬申、乙巳、戊寅），壬印戊财以乙隔之，水与土不相碍，故为大贵。反例：壬戌、丁未、戊申、乙卯，杂气正官透干会支最为贵格，而壬财丁印二者相合，仍以**孤官无辅**论，所以不上七品。
- 若财印不以两用，则**单用印不若单用财**（印能护官亦能泄官，而财生官）。
- **化官为印而透财，则又为甚秀，大贵之格**（金状元命：乙卯、丁亥、丁未、庚戌，并用财印，无伤官而不杂煞）。
- **"然而遇伤在于佩印，混煞贵乎取清。"** 例：宣参国命（己卯、辛未、壬寅、辛亥），未中己官透干用清，支会木局，两辛解之，是遇伤而佩印；李参政命（庚寅、乙酉、甲子、戊辰），甲用酉官，庚金混杂，乙以合之，合煞留官，是杂煞而取清。
- 官格透伤用印者，**又忌见财**（财能去印，未能生官，而适以护伤）。然亦有逢财反大贵者：范太傅命（丁丑、壬寅、己巳、丙寅），支具巳丑会金伤官，丙丁解之；透壬岂非破格，却不知丙丁并透用一而足，以丁合壬而财去、以丙制伤而官清，**无情而愈有情**。
- 地支刑冲会合可解，已见前篇。

**正官取运**：官用财印，身稍轻则取助身、官稍轻则助官；**官露而不可逢合、不可杂煞、不可重官**；与地支刑冲，不问所就何局皆不利。正官用财，运喜印绶身旺之地，切忌食伤；若身旺而财轻官弱，仍取财官运。正官佩印，运喜财乡，伤食反吉；若官重身轻而佩印，则身旺为宜，不必财运。正官带伤食而用印制，运喜官旺印旺之乡，财运切忌；若印绶叠出，财运亦无害。正官带煞，伤食反为不碍；命中用劫合煞，则财运、伤食、身旺、印绶皆可行，只不宜复露七煞；若命用伤官合煞，则伤食与财俱可行，而不宜逢印。

### 2.22 财格

- 财为我克、使用之物，以能生官所以为美（为财帛、妻妾、才能、驿马）。
- **财喜根深，不宜太露；然透一位以清用，格所最喜，不为之露**；即非月令用神（如寅透乙、卯透甲之类）一亦不为过，太多则露矣。**财旺生官，露亦不忌**（露以防劫，生官则劫退）。例：葛参政命（壬申、壬子、戊午、乙卯）财露唯其生官故不忌。
- 财格贵局与条件：
  - **财旺生官**：身强而不透伤官、不混七煞。
  - **财用食生**：身强而不露官，略带一位比劫益觉有情（杨侍郎命：壬寅、壬寅、庚辰、辛巳）；**透官身弱则格坏**。
  - **财格佩印**：孤财不贵，佩印帮身（曾参政命：乙未、甲申、丙申、庚寅）；**财印宜相并**，如乙未、己卯、庚寅、辛巳，乙与己两不相能，即有好处小富而已。
  - **用食而兼用印**：食与印两不相碍，或有暗官而去食护官（吴榜眼命：庚戌、戊子、戊子、丙辰，庚与丙隔两戊而不相克；平江伯命：壬辰、乙巳、癸巳、辛酉，虽食印相克而欲存巳戊官，是去食护官）；反是则减福。
  - **财用伤官**：财不甚旺而比强，略露一位伤官以化之（汪学士命：甲子、辛未、辛酉、壬辰，甲透未库，逢辛为劫，壬以化劫生财）；**财旺无劫而透伤反为不利**（伤官本非美物，财轻透劫不得已而用之）。
  - **财带七煞**：或合煞存财（毛状元命：乙酉、庚辰、甲午、戊辰），或制煞生财（李御史命：庚辰、戊子、戊寅、甲寅）。
  - **财用煞印**：党煞为忌，印以化之，格成富局；冬土逢之亦贵格（赵侍郎命：乙丑、丁亥、己亥、乙亥，化煞而即以解冻，又不露财以杂其印）；**若财并透，非特不贵，亦不富**。
  - **单透财而亦贵**：壬生午月、癸生巳月，以月令有暗官（林尚书命：丙寅、癸巳、癸未、壬戌）；壬生巳月单透财亦贵，以其透丙藏戊，**弃煞就财**（王太仆命：丙辰、癸巳、壬戌、壬寅）。
  - **劫刃太重，弃财就煞**（一尚书命：丙辰、丙申、丙午、壬辰），此变之又变者。

**财格取运**：财旺生官者，运喜身旺印绶，不利七煞伤官；生官而后透印，伤官之地不甚有害；生官而带食破局，则运喜印绶而逢煞反吉。财用食生，财食重而身轻则喜助身，财食轻而身重则仍行财食；煞运不忌，官印反晦。财格佩印，运喜官乡，身弱逢之最喜印旺。财用食印，财轻则喜财食，身轻则喜比印，官运有碍，煞反不忌。财带伤官，财运则亨，煞运不利，运行官印未见其美。财带七煞，不论合煞制煞，运喜食伤身旺之方。财用煞印，印旺最宜，逢财必忌，伤食之方亦任意。

### 2.23 印绶格

- **印绶喜其生身，正偏同为美格，故财与印不分偏正，同为一格而论之。**
- 分类：
  - **印而透官**：正官不独取其生印，而即可以为用，与用煞者不同；故**身旺印强不愁太过，只要官星清纯**（张参政命：丙寅、戊戌、辛酉、戊子）。
  - **带伤食而贵**：须伤食被制（朱尚书命：丙戌、戊戌、辛未、壬辰，壬为戊制不伤官；临淮侯命：乙亥、己卯、丁酉、壬寅，己为乙制，己不碍官）。
  - **印用伤食**：身强印旺，恐其太过，泄身以为秀气（李状元命：戊戌、乙卯、丙午、乙亥）；**若印浅身轻而用层层伤食，则寒贫之局**。
  - **用偏官（煞）**：偏官本非美物，藉其生印，不得已而用之；**必身重印轻，或身轻印重，有所不足，始为有情**（茅状元命：己巳、癸酉、癸未、庚申，身轻印重；马参政命：壬寅、戊申、壬辰、壬寅，身重印轻）；**若身印并重而用七煞，非孤则贫**。
  - **用煞而兼带伤食**：用煞而有制、生身而有泄，不论身旺印重皆为贵格。
  - **印多而用财**：印重身强，透财以抑太过，权而用之，只要根深无妨财破（汪侍郎命：辛酉、丙申、壬申、辛亥）；**若印轻财重又无劫财以救，则为贪财破印，贫贱之局**。
  - **印重财轻而兼露伤食**：财与食相生，轻而不轻，即可就富，亦不贵。
  - **带食而贵**：庚寅、乙酉、癸亥、丙辰（牛监簿命），乙合庚而不生癸，所以为贵；**合财存食**亦可类推（己未、甲戌、辛未、癸巳）。
  - **印兼透官煞**：或合煞、或有制皆为贵格（辛亥、庚子、甲辰、乙亥，合煞留官；壬子、癸卯、丙子、己亥，官煞有制）。
  - **化印为劫，弃之以就财官**（赵知府命：丙午、庚寅、丙午、癸巳），变之又变者。
  - **印透七煞而劫财以存煞印**亦有贵格（庚戌、戊子、甲戌、乙亥），然此格毕竟难看，宜细详之。

**印绶取运**：印绶用官者，官露印重，财运反吉，伤食之方亦为最利；用官而带伤食，运喜官旺印绶之乡，伤食为害，逢煞不忌。印绶而用伤食，财运反吉，伤食亦利，行官运反见其灾，煞运反能为福。印用七煞，运喜伤食、身旺之方，一见财乡其凶立至。用煞而兼带伤食，运喜身旺印绶之方，伤食亦美，逢官遇财皆不吉。印绶遇财，运喜劫地，官印亦亨，财乡则忌。印格而官煞竞透，运喜食神伤官、印旺身旺；若再透官煞、行财运，立见其灾。印用食伤，印轻者亦不利见财。

### 2.24 食神格

- 食神本属泄气，以其能生正财所以喜之，**食神生财，美格也**。
- 细则：
  - **财要有根，不必偏正叠出**；身强食旺而财透，大贵之格（梁丞相命：丁未、癸卯、癸亥、癸丑；谢阁老命：己未、壬申、戊子、庚申）。
  - **藏食露伤，主人性刚**（沈路分命：丁亥、癸卯、癸卯、甲寅）。
  - **偏正叠出，富贵不巨**（龚知县命：甲午、丁卯、癸丑、丙辰）。
  - **夏木用财，火炎土燥，贵多就武**（黄都督命：己未、己巳、甲寅、丙寅）；不用财而就煞印，最为威权显赫（常国公命：辛卯、辛卯、癸酉、己未）；无印绶而单露偏官，只要无财亦为贵格（胡会元命：戊戌、壬戌、丙子、戊戌）。
  - **金水食神而用煞，贵而且秀**（舒尚书命：丁亥、壬子、辛巳、丁酉）。
  - **食神忌印**，而夏火太炎而木焦，透印不碍（钱参政命：丙午、癸巳、甲子、丙寅）。
  - **食神忌官，金水不忌**（即金水伤官可见官之谓）。
  - **单用食神**，作食神有气，有财运则富，无财运则贫。
  - **印来夺食，透财以解**，亦有富贵，须就全局之势而断。
  - **食神而官煞竞出**，亦可成局，但不甚贵。
  - **食神合煞存财，最为贵格。**
  - **食神透煞本忌见财**，而财先煞后、食以间之，则财不能党煞，亦可就贵（刘提台命：癸酉、辛酉、己卯、乙亥）。

**食神取运**：食神生财，财重食轻则行财食，财食重则喜帮身；官煞之方俱为不美。食用煞印，运喜印旺，切忌财乡；身旺，食伤亦为福运，行官行煞亦为吉。食伤带煞，喜行印绶；身旺，食伤亦为美运，财则最忌；若食太重而煞轻，印运最利，逢财反吉。食神太旺而带印，运最利财，食伤亦吉，印则最忌，官煞皆不吉。食神带印透财以解，运喜财旺，食伤亦吉，印与官煞皆忌。

### 2.25 偏官（七煞）格

- 煞以攻身似非美物，而**大贵之格多存七煞**——控制得宜，煞为我用。
- 分类：
  - **煞用食制者，上也**；煞旺食强而身健，极为贵格（乙亥、乙酉、乙卯、丁丑）。
  - **煞用食制，不要露财透印**（财能转食生煞，印能去食护煞）。**例外**：财先食后（财生煞而食以制之），或印先食后（食太旺而印制），则格成大贵（壬辰、甲辰、丙戌、戊戌，辰中暗煞壬以透之，戊坐四支，食太重而透甲印以损太过）；**若煞强食泄而印露，则破局矣**。
  - **七煞用印**：印能护煞本非所宜，而**印有情便为贵格**（何参政命：丙寅、戊戌、壬戌、辛丑，戊与辛同通月令，是煞印有情）。
  - **煞重身轻，用食则身不能当，不若转而就印**，虽不通根月令，亦为无情而有情，格亦许贵，但不大。
  - **煞而用财**：财以党煞本非所喜，而**食被制不能伏煞，而财以去印存食**便为贵格（周丞相命：戊戌、甲子、丁未、庚戌，戊被制不能伏煞，时透庚财，即以清食者，生不足之煞；生煞即以制煞，两得其用，尤为大贵）。
  - **身重煞轻，煞又化印，用神不清，而借财以清格**，亦为贵格（刘运使命：甲申、乙亥、丙戌、庚寅）。
  - **杂气七煞，干头不透财以清用，亦可取贵。**
  - **煞而杂官者，或去官，或去煞，取清则贵**（岳统制命：癸卯、丁巳、庚寅、庚辰，去官留煞）。**去官何如去煞？**——**月令偏官，煞为用而官非用，各从其重**；若官格杂煞而去官留煞，不能如是之清（沈郎中命：丙子、甲午、辛亥、辛卯，子冲午而克煞，是去煞留官）。
  - **煞无食制而用印当者**（赵员外命：戊辰、甲寅、戊寅、戊午）。
- 书有"制煞不可太过"之说，虽亦有理，然运行财印亦能发福，不可执一；弃命从煞则于外格详之。

**偏官取运**：煞用食制，煞重食轻则助食、煞轻食重则助煞、煞食均而日主根轻则助身；忌正官之混杂，畏印绶之夺食。煞用印绶，不利财乡，伤官为美，印绶身旺俱为福地。七煞用财，其以财而去印存食者不利劫财，伤食皆吉，喜财怕印，透煞亦顺；其以财而助煞不及者，财已足则喜食印与帮身，财未足则喜财旺而露煞。煞带正官，不论去官留煞、去煞留官，身轻则喜助身，食轻则喜助食；莫去取清之物，无伤制煞之神。煞无食制而用刃当煞，煞轻刃重则喜助煞，刃轻煞重则宜制伏，无食可夺，印运何伤；七煞既纯，杂官不利。

### 2.26 伤官格

- 伤官虽非吉神，**实为秀气**，故文人学士多于伤官格内得之；夏木见水、冬金见火，又为秀之尤秀。其格变化最多，须**察气候、量强弱、审喜忌、观纯杂**，微之又微不可执。
- 分类：
  - **伤官用财**：伤不利于官所以为凶，伤官生财则以伤官为生官之具，**转凶为吉，故最利**；只要身强而有根便为贵格（史春芳命：壬午、己酉、戊午、庚申）。
  - **化伤为财，大为秀气**（罗状元命：甲子、乙亥、辛未、戊子，干头之甲通根于亥，又会未成局，化水为木，化之生财尤为有情）；财伤有情与化伤为财者秀气不相上下（秦龙图命：己卯、丁丑、丙寅、庚寅，己与庚同根月令）。
  - **伤官佩印**：印能制伤所以为贵，**反要伤官旺、身稍弱始为秀气**（孛罗平章命：壬申、丙午、甲午、壬申，伤官旺、印根深、身又弱，又夏木逢润，其秀百倍）；**然印旺极深不必多见，偏正叠出反为不秀**；故伤轻身重而印绶多见，贫穷之格。
  - **伤官兼用财印**：财印相克本不并用，只要**干头两清而不相碍**；又必生财者财太旺而带印、佩印者印太重而带财，调停中和遂为贵格（都统制命：丁酉、己酉、戊子、壬子，财太重而带印，丁与壬隔以戊己两不碍，且金水多而觉寒，得火融和；一丞相命：壬戌、己酉、戊午、丁巳，印太重而隔戊己而丁与壬不相碍）；反是则财印不并用而不秀。
  - **伤官用煞印**：伤多身弱，赖煞生印以帮身而制伤（蔡贵妃命：己未、丙子、庚子、丙子）；煞因伤而有制，两得其宜，只要无财便为贵格（夏阁老命：壬寅、丁未、丙寅、壬辰）。
  - **伤官用官**：**他格不用，金水独宜**；然要财印为辅，**不可伤官并透**（戊申、甲子、庚午、丁丑，藏癸露丁，戊甲为辅，官又得禄，所以为丞相之格）；**若孤官无辅，或官伤并透，则发福不大**。
  - **冬金用官而又化伤为财，尤为极秀极贵**（郑丞相命：丙申、己亥、辛未、己亥）。
  - **非金水而见官**：化伤为财，伤非其伤，作**财旺生官**而不作伤官见官（章丞相命：甲子、壬申、己亥、辛未）。
  - **伤官而官煞并透**：只要干头取清，金水得之亦清，不然则空结构而已。

**伤官取运**：伤官用财，财旺身轻则利印比，身强财浅则喜财运，伤官亦宜。伤官佩印，运行官煞为宜，印运亦吉，伤食不碍，财地则凶。伤官兼用财印，其财多而带印者运喜助印，印多而带财者运喜助财。伤官用煞印，印运最利，伤食亦亨，杂官非吉，逢财即危。伤官带煞，喜印忌财，然伤重煞轻，运喜印而财亦吉；惟七煞重则运喜伤食，印绶身旺亦吉，而逢财为凶。伤官用官，运喜财印，不利食伤；若局中官露而财印两旺，则比劫伤官亦未始非吉。

### 2.27 阳刃格

- 定义：**阳刃者，劫我正财之神，乃正财之七煞也；禄前一位，惟五阳有之，故为阳刃。**不曰劫而曰刃，劫之甚也。
- **刃宜伏制，官煞皆宜，财印相随尤为贵显。**
- **与其他格之根本差别**：他格以煞能伤身，故喜制伏、忌财印；**阳刃用之则赖以制刃，不怕伤身，故反喜财印、忌制伏**。
- **阳刃用官，透刃不虑；阳刃露煞，透刃无成**（官能制刃，透而不为害；刃能合煞则有何功——如丙生午月透壬制刃而又露丁，丁与壬合，七煞贪合忘克，如何制刃）。
- 同是官煞制刃而格有高低：**官煞露而根深其贵也大；藏而不露，或露而根浅，其贵也小**（己酉、丙子、壬寅、丙午，官透有力、旺财生之，丞相命；辛酉、甲午、丙申、壬辰，透煞根浅、财印助之，亦丞相命）。
- **官煞制刃带伤食而贵者**，其故有三：
  - **印护**：如穆同知命（甲午、癸酉、庚寅、戊寅），癸水伤寅午之官而戊以合之；
  - **裁损**：如贾平章命（甲寅、庚午、戊申、甲寅），煞两透而根太重，食以制之；
  - **取清**：如丙戌、丁酉、庚申、壬午，官煞竞出而壬合丁官，煞纯而不杂；**况阳刃之格利于留煞**。
- 丙生午月，内藏己土可以克水，**尤宜带财佩印**。
- 戊生午月，干透丙火、支会火局，则化刃为印；或官或煞，透则去刃存印其格愈清。**倘或财煞并透露，则犯去印存煞之忌**，不作生煞制煞之例，富贵两空。
- **阳刃用财，格所不喜**；然财根深而用伤食，以转刃生财，虽不比建禄月劫可以取贵，亦可就富；不然则刃与财相搏，不成局矣。

**阳刃取运**：阳刃用官，则运喜助官；然命中官星根深，则印绶比劫之方反为美运，但不喜伤食合官。阳刃用煞，煞不甚旺则运喜助煞；煞若太重则运喜身旺印绶，伤食亦不为忌。阳刃而官煞并出，不论去官去煞，运喜制伏，身旺亦利，财地官乡反为不吉。

### 2.28 建禄月劫格

- 定义：建禄者月建逢禄堂，禄即是劫。或以禄堂透出即可依以为用者，非也。**建禄与月劫可同一格，不必另分，皆以透干支，别取财官煞食为用。**
- 细则：
  - **禄格用官**：干头透出为奇，**又要财印相随，不可孤官无辅**（金丞相命：庚戌、戊子、癸酉、癸亥，用官而印护；李知府命：丁酉、丙午、丁巳、壬寅，用官而财助）。
  - **官兼带财印**：所谓**身强值三奇**（三奇者财官印也），只要以官隔之，使财印两不相伤，其格便大（王少师命：庚午、戊子、癸卯、丁巳）。
  - **禄劫用财，须带食伤**——月令为劫而以财作用，二者相克，必以伤食化之，始可转劫生财（张都统命：甲子、丙子、癸丑、壬辰）。
  - **化劫为财**（己未、己巳、丁未、辛丑，丑与巳会，即以劫财之火为金局之财）与**化劫为生**（高尚书命：庚子、甲申、庚子、甲申，以劫财之金化为生财之水），尤为秀气。
  - **禄劫用煞，必须制伏**（娄参政命：丁巳、壬子、癸卯、己未，壬合丁财以去其党煞，卯未会局以制伏）。
  - **用煞而又财，本为不美，然能去煞存财又成贵格**（袁内阁命：戊辰、癸亥、壬午、丙午，合煞存财）。
  - **无财官而用伤食，泄其太过，亦为秀气；唯春木秋金用之则贵**（木逢火则明，金生水则灵）。例：张状元命（甲子、丙寅、甲子、丙寅）木火通明；癸卯、庚申、庚子、庚辰，金水相涵。
  - **官煞竞出，必取清方为贵格**（辛丑、庚寅、甲辰、乙亥，合煞留官；辛亥、庚申、甲申、丙寅，制煞留官）。
  - **两官竞出亦须制伏**，所谓**争正官不可无伤**也。
  - **用官而孤官无辅，格局更小，难于取贵**；若透伤食便不破格。亦有官伤并透而贵者（己酉、乙亥、壬戌、庚子，庚合乙而去伤存官）。
  - **用财而不透伤食，便难于发端**；然干头透一位而不杂、地支根多，亦可取富但不贵。
  - 用官煞重而无制伏，运行制伏亦可发财，但不可官煞太重致令身危。

**建禄月劫取运**：禄劫用官，印护者喜财，怕官星之逢合，畏七煞之相乘；伤食不能为害，劫比未即为凶。财生喜印，宜官星之植根，畏伤食之相侮，逢财愈见其功，杂煞岂能无碍。禄劫用财而带伤食，财食重则喜印绶而不忌比肩，财食轻则宜助财而不喜印比；逢煞无伤，遇官非福。禄劫用煞食制，食重煞轻则运宜助煞，食轻煞重则运喜助食。用煞而带财：命中合煞存财，则伤食为宜、财运不忌、透官无虑、身旺亦亨；命中合财存煞而用食制，煞轻则助煞、食轻则助食。禄劫用伤食，财运最宜，煞亦不忌，行印非吉，透官不美；若命中伤食太重，则财运固利而印亦不忌。禄劫而官煞并出，不论合煞留官、存官制煞，运喜伤食，比肩亦宜，印绶未为良图，财官亦非福运。

### 2.29 杂格（外格）

- 定义：杂格者，月令无用，以外格而用之，其格甚多故谓之杂。
- **成立前提：大约要干头无官无煞方成格**；如有官煞则自有官煞为用，无劳外格。若透财尚可取格，然财根深或财透两位，则亦以财为重，不取外格。
- 诸格条件与喜忌：
  - **五行一方秀气**：取甲乙全亥卯未、寅卯辰又生春月之类，本是一派劫财，以五行各得其全体所以成格，**喜印露而体纯**（吴相公命：癸亥、乙卯、乙未、壬午）；运喜印绶比劫之乡，财食亦吉，官煞则忌。
  - **从化取格**：要化出之物得时乘令、四支局全（如丁壬化木，地支全亥卯未、寅卯辰而又生于春月，方为大贵；否则亥未之月亦是木地，次等之贵，如甲戌、丁卯、壬寅、甲辰）；运喜所化之物与所化之印绶，财伤亦可，不利官煞。
  - **倒冲成格**：以四柱列财官而对面以冲之，**要支中字多方冲得动**（如弱主邀强官，主不众则宾不从）；戊午、戊午、戊午、戊午冲子财；甲寅、庚午、丙午、甲午冲子官；**运忌填实**，余俱可行。
  - **朝阳成格**：戊去朝丙，辛日得官，以丙戊同禄于巳，即以引汲之意；**要干头无木火方成其格**（有火则无待于朝，有木财触戊之怒而不为我朝）；戊辰、辛酉、辛酉、戊子；运喜土金水，木运平平，火则忌。
  - **合禄成格**：命无官星，借干支以合之。戊日庚申以庚合乙（因其主而得其偶，己未、戊辰、戊辰、庚申）；癸日庚申以申合巳（因其主而得其朋，己酉、癸未、癸未、庚申）；**运亦忌填实**，不利官煞，不宜以火克金（使彼受制而不能合），余则吉。
  - **弃命保财（从财）**：四柱皆财而身无气，舍而从之，格成大贵；**若透印则身赖印生而不从，有官煞则亦无从财兼从煞之理，其格不成**（庚申、乙酉、丙申、乙丑）；运喜伤食财乡，不宜身旺。
  - **弃命从煞**：四柱皆煞而日主无根，舍而从之，格成大贵；**若有伤食则煞受制而不从，有印则印以化煞而不从**（乙酉、乙酉、乙酉、甲申）；运喜财官，不宜身旺，食伤尤忌。
  - **井栏成格**：庚金生三七月方用此格，以申子辰冲寅午戌，财官印绶合而冲之；**若透丙丁、有巳午，以现有财官而无待于冲，乃非井栏之格**（戊子、庚申、庚申、庚申）；运喜财，不利填实，余亦吉。
  - **刑合成格**：癸日甲寅时，寅刑巳而得财官，格与合禄相似（合禄喜以合之，刑合则硬以致之）；**命有庚申则木被冲克而不能刑；有戊己字则现透官煞而无待于刑，非此格**（乙未、癸卯、癸卯、甲寅）；运忌填实，不利金乡，余则吉。
  - **遥合成格**：巳与丑会本同一局，丑多则会巳而辛丑处官，亦合禄之意（辛丑、辛丑、辛丑、庚寅）；**若命有子字则丑与子合而不遥；有丙丁戊己则辛癸之官煞已透而无待于遥，另有取用，非此格**。至于甲子遥巳，转辗求合，似觉无情，**此格可废**（因罗御史命聊复存之）。
- **一切无理之格既置勿取**：拱禄、拱贵、趋乾、归禄、夹戌、鼠贵、骑龙、日贵、日德、富禄、魁罡、食神时墓、两干不杂、干支一气、五行具足之类。即古人格内亦有成式，总之意为牵就、硬填入格，百无一是，徒误后学。天地双飞虽富贵亦自有格，不全赖此，而亦能增重其格；然有用神不吉即以为凶，不可执。
- **对"伤官伤尽"的质疑**：谓伤尽不宜一见官，必尽力以伤之使之无地容身，现行伤运便能富贵——"不知官有何罪而恶之如此？"**"予用是术以历试，但有贫贱，并无富贵，未轻信也；近亦见有大贵者，不知何故。然要之极贱者多，不得不观其人物以衡之。"**

### 2.30 破斥"时说"（识别伪法）

- **拘泥格局之谬**：戊生甲寅之月时上庚申，不以为明煞有制而以为专食之格；丙生子月时逢巳禄，不以为正官之格归禄帮身而以为日禄归时；辛日透丙时遇戊子，不以为得官逢印而以为朝阳之格；财逢时煞，不以为生煞攻身而以为时上偏官；癸生巳月时遇甲寅，不以为暗官受破而以为刑合成格；癸生冬月酉日亥时透戊坐戌，不以为月劫建禄用官通根而以为拱戌之格；辛日坐丑、寅年亥月卯时，不以为正财之格而以为填实拱贵；乙逢寅月时遇丙子，不以为木火通明而以为格成鼠贵。
- **以讹传讹四端**：论干支则不知阴阳之理而以俗书体象歌诀为确论；论格局则不知专寻月令而以拘泥外格为活变；论生克则不察喜忌而以伤旺扶弱为定法；论行运则不问同中有异而以干支相类为一例。
- 命例辨正一：壬申、癸丑、己丑、甲戌，本杂气财旺生官也，而以为乙亥时作时上偏官论——不知旺财生煞，将救死之不暇，于何取贵。
- 命例辨正二：己未、壬申、戊子、庚申，本食神生财也，而欲弃月令以为戊日庚申合禄之格——本身自有财食岂不甚美，何劳以庚合乙求局外之官。
- 告诫：行术之人必以贵命为指归，或将风闻为实据，或探其生日而以己意加之生时，谬造贵格；其人之八字时多未确，即彼本身亦不自知。

## 3. 关键原文口诀（附适用场景）

1. **"八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。"**（八、论用神）——定格局的第一句话，凡论命起手即引。
2. **"财官印食，此用神之善而顺用之者也；煞伤劫刃，用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格。"**（八、论用神）——判顺用逆用之大纲。
3. **"成中有败，必是带忌；败中有成，全凭救应。"**（九、论用神成败救应）——判断成格后是否有隐病、败格后是否可救的总口诀。
4. **"伤用神甚于伤身，伤相甚于伤用。"**（十五、论相神紧要）——衡量一字轻重的尺子。
5. **"相神无破，贵格已成；相神相伤，立败其格。"**（十五、论相神紧要）——验格成败的直接判据。
6. **"是故十干不论月令休囚，只要四柱有根，便能受财官食神而当伤官七煞。"**（六、论十干得时不旺失时不弱）——反驳"失时便作衰看"。
7. **"长生禄旺，根之重者也；墓库余气，根之轻者也。"**（六）——判根气轻重。
8. **"得一比肩，不如得支中一墓库。"**（六）——干多不如根重的量化口诀。
9. **"干多不如根重，理固然也。"**（六）——身弱身强取用之要。
10. **"盖有所合则有所忌，逢吉不为吉，逢凶不为凶。"**（四、论十干配合性情）——见合先查喜忌是否被合去。
11. **"合官留煞，而煞刃依然成格，皆无伤于合也。"**（五、论十干合而不合）——月刃庚辛并透而丙合辛时引用。
12. **"一夫不娶二妻，一女不配二夫，所以有争合妒合之说。然到底终有合意，但情不专耳。"**（五）——两干争合一干时引用。
13. **"八字支中，刑冲俱非美事，而三合六合，可以解之。"**（七、论刑冲会合解法）——见刑冲先找会合。
14. **"刑冲用神，尤为破格，不如以另位之刑冲，解月令之刑冲矣。"**（七）——月令被冲时的解救思路。
15. **"用神既主月令矣，然月令所藏不一，而用神遂有变化。"**（十、论用神变化）——月令藏干多而透干与会支不同时引用。
16. **"变之而善，其格愈美；变之不善，其格遂坏。"**（十）——判变化吉凶。
17. **"是故八字非用神不立，用神非变化不灵。"**（十）——强调变化之法。
18. **"纯者吉，杂者凶。"**（十一、论用神纯杂）——两神并透看是否两相得。
19. **"然其理之大纲，亦在有情无情、有力无力之间而已。"**（十二、论用神格局高低）——定格局高低的唯一纲。
20. **"或一字而有千钧之力，或半字而败全局之美。"**（十二）——提醒不可轻看一字。
21. **"透干会支，取其清者用之，杂而不杂也。"**（十六、论杂气如何取用）——四库月取用总法。
22. **"是故四墓不忌刑冲，刑冲未必成格。"**（十七、论墓库刑冲之说）——破"财官入库不冲不发"。
23. **"财官入库不冲不发——此说虽俗书盛称之，然子平先生造命，无是说也。"**（十七）——破俗法时引。
24. **"吉凶喜忌，全在是否合于需要，不因名称而有分别也。"**（十八、论四吉神能破格）——吉神破格时引。
25. **"是故财不忌伤，官不忌枭，煞不忌刃。"**（十九、论四凶神能成格）——凶神成格时引。
26. **"格局既成，即使满盘孤辰入煞，何损其贵？格局既破，即使满盘天德贵人，何以为功？"**（二十一、论星辰无关格局）——拒神煞定贵贱。
27. **"提纲有用提纲重"；"有官莫寻格局"**（二十二、论外格用舍）——驳外格滥用。
28. **"论运与看命无二法也。"**（二十五、论行运）——论大运起手式。
29. **"冲年月则急，冲日时则缓也。"**（二十五）——判冲之缓急。
30. **"运本美而逢冲则轻，运既忌而又冲则重也。"**（二十五）——判冲之轻重。
31. **"支为干之生地，干为支之发用。"**（二十八、论支中喜忌逢运透清）——逐干逐支统看之法。
32. **"以刑冲破害为忌，则以生之护之为喜矣。"**（三十一、论正官）——正官格取用总则。
33. **"单用印不若单用财，以印能护官，亦能泄官，而财生官也。"**（三十一）——官格财印不并用时的取舍。
34. **"然而遇伤在于佩印，混煞贵乎取清。"**（三十一）——官格两大救应。
35. **"财喜根深，不宜太露，然透一位以清用，格所最喜，不为之露。"**（三十三、论财）——判财之露与不露。
36. **"印绶喜其生身，正偏同为美格，故财与印不分偏正，同为一格而论之。"**（三十五、论印绶）——印格不分偏正。
37. **"若印轻财重，又无劫财以救，则为贪财破印，贫贱之局也。"**（三十五）——印格见财的成败分界。
38. **"食神生财，美格也。"**（三十七、论食神）——食神格首选。
39. **"藏食露伤，主人性刚。"**（三十七）——论性情。
40. **"食神忌官，金水不忌。"**（三十七）——金水伤官可见官。
41. **"更有食神合煞存财，最为贵格。"**（三十七）——食神格高价组合。
42. **"煞用食制者，上也，煞旺食强而身健，极为贵格。"**（三十九、论偏官）——七煞格首选用法。
43. **"煞用食制，不要露财透印，以财能转食生煞，而印能去食护煞也。"**（三十九）——煞格破格条件。
44. **"有煞而杂官者，或去官，或去煞，取清则贵。"**（三十九）——官煞混杂。
45. **"月令偏官，煞为用而官非用，各从其重。"**（三十九）——决定去官还是去煞。
46. **"伤官虽非吉神，实为秀气，故文人学士，多于伤官格内得之。"**（四十一、论伤官）——论伤官才性。
47. **"伤官生财，则以伤官为生官之具，转凶为吉，故最利。"**（四十一）——伤官格最利之路。
48. **"有伤官用官者，他格不用，金水独宜，然要财印为辅，不可伤官并透。"**（四十一）——伤官见官的例外条件。
49. **"阳刃者，劫我正财之神，乃正财之七煞也。"**（四十三、论阳刃）——阳刃定义。
50. **"他格以煞能伤身，故喜制伏，忌财印；阳刃用之，则赖以制刃，不怕伤身，故反喜财印，忌制伏也。"**（四十三）——阳刃格与它格喜忌相反之关键。
51. **"阳刃用官，透刃不虑；阳刃露煞，透刃无成。"**（四十三）——阳刃格成破判据。
52. **"建禄与月劫，可同一格，不必另分，皆以透干支，别取财官煞食为用。"**（四十五、论建禄月劫）——禄劫格取用。
53. **"禄格用官，干头透出为奇，又要财印相随，不可孤官无辅。"**（四十五）——禄劫用官条件。
54. **"禄劫用财，须带食伤。"**（四十五）——禄劫用财条件。
55. **"所谓争正官不可无伤也。"**（四十五）——两官竞出时的解法。
56. **"杂格者，月令无用，以外格而用之。"**（四十七、论杂格）——外格定义。
57. **"大约要干头无官无煞，方成格。"**（四十七）——外格成立前提。
58. **"其于伤官伤尽……予用是术以历试，但有贫贱，并无富贵，未轻信也。"**（四十七）——驳伤官伤尽。
59. **"冬木逢水，虽透官星，亦难必贵。"**（十四、论用神配气候得失）——冬木调候。
60. **"伤官见官，为祸百端，而金水见之，反为秀气。"**（十四）——调候权用之例。

## 4. 该书的独门之处

1. **"用神专求月令"的彻底格局化体系**。全书以月令为经、诸神为纬，把财官印食煞伤劫刃八格全部收束到"日干配月令地支"这一起点上，与他书重气势、重强弱、重神煞的路数截然不同。第二十五篇以下逐格论"取运"，亦以格为纲而非以十神吉凶为纲。

2. **以"气/质"同类相畏定官煞之别**。阳干为气、阴干为质；克我者与日干同类则为七煞（相畏、能克去），异类则为正官（不相畏）。这是本书独有的理论装置，用以解释"同是克我而一官一煞善恶判然"，而不只是照搬十神定义。

3. **"相神"概念的提出**。用神之外另立"相神"，并给出极强的判据："凡全局之格赖此一字而成者，均谓之相"；**"伤用神甚于伤身，伤相甚于伤用"**、**"相神无破，贵格已成；相神相伤，立败其格"**。后世论命极重视的"用神被伤"之外，本书独重"相神被伤"。

4. **成格—破格—带忌—救应的四层规则化清单**。第九篇以同一八格各列"何谓成""何谓败""何谓带忌""何谓救应"四组条目，是全书写得最规则化、最可编程的一段，也是本书区别于一切命书笔记的核心价值。

5. **"四吉神能破格、四凶神能成格"**。明确宣告吉凶喜忌"不因名称而有分别"，只看是否合于需要；由此立"官用食破，印用财破"与"财不忌伤，官不忌枭，煞不忌刃"两串反常识判据。

6. **彻底否定神煞与"财官入库不冲不发"**。第二十一篇"星辰无关格局"与第十七篇"四墓不忌刑冲，刑冲未必成格"，对当时流行的孤辰、天德、贵人、冲库开库诸说作了系统清算；并指出"土冲则灵"而"财官为水，冲则反累"。

7. **"生克先后分吉凶"与"隔位"论**。同一财伤并透、财枭并透，先后次序不同则吉凶与晚运截然相反；更以"隔位"（如丙生甲寅月年癸时戊，戊不得越甲合癸）判定成格与"格大破"，把字位次序提升为独立的判断维度。

8. **"支中喜忌逢运透清"与"干主一而支藏多"**。喜忌在支者须待运透或会局方能发用，且"在年则重，在日次之"；并立"行干不行支""行支不行干""干同一类而不两行""支同一类而不两行"四组干支差异规则。

9. **对"伤官伤尽"的公开质疑**。作者以自身历试经验否证此说（"但有贫贱，并无富贵"），同时又如实承认"近亦见有大贵者，不知何故"，是全书最坦白的一处存疑。

## 5. 局限与后世争议

1. **"用神专求月令"过于刚性，对变格、外格评价过苛**。本书对外格的基本立场是"月令自有用神，岂可另寻外格"，甚至称拱禄、拱贵、鼠贵、魁罡、两干不杂等"一切无理之格既置勿取"。后世（尤其近现代从格、专旺、化气格研究）认为月令受伤或月令无用时的弃命从财、从煞、从儿等格确有应验，本书虽在第四十七篇收录从财、从煞、从化，却仍将其归入"杂格"边缘地位，判语亦简。（原文对从格仅列成格条件与喜忌，未展开例证，属"原文仅略述，需结合他书"。）

2. **全盘否定神煞，与后世（尤其盲派）分歧极大**。盲派及民间口诀体系仍大量使用神煞、刑冲、纳音、宫位等辅助判据；本书"格局既成，即使满盘孤辰入煞，何损其贵"的立场，被批评为把神煞一概抹去，反失细腻。

3. **"阳大阴小，阳得兼阴，阴不能兼阳"之说**。由此推出"阳长生有力，阴长生不甚有力""逢库则阳为有根而阴为无用"，后世《滴天髓》一路强调"阴阳同生同死"或用阴干月令本气论旺衰者，与此说不合。

4. **子息断法可验性低**。以十二长生歌诀直接断子数（长生四子、沐浴一双、旺中五子……），又规定"长生论法用阳而不用阴""不问甲乙总以庚为男辛为女"，后世基本视为不可据以定数；本书自身亦未给出验证方法。

5. **六亲配属带有宗法时代色彩**。"正印为母、偏财为父"（偏财者母之正夫）、"正财为妻，夫为妻纲"、"妻星两透，偏正杂出，何一夫而多妻"等论断，其中"一夫多妻"的表述属时代局限；后世论六亲多已改以宫位与用神喜忌为主、星为辅。

6. **对"伤官伤尽"的态度自相矛盾**。既斥其无理（"不知官有何罪"），又以"近亦见有大贵者，不知何故""不得不观其人物以衡之"作结，未下确定判断——**原文含混未决，如实记录**。

7. **全书重心在富贵贫贱，对疾病、寿夭、性情着墨甚少**。除"藏食露伤，主人性刚"、"夏木用财，火炎土燥，贵多就武"等零星断语外，几乎不涉疾病与寿元专题；**此类专题原文仅略述，需结合他书**。

8. **原文自身含混处（如实指出）**：第二篇论官煞，以"甲逢秋天为官"起论、继以"乙则反是，庚官而辛杀也"，其"反是"所对应的甲之官煞须靠反推方能确定（推得甲以辛为官、庚为杀，与通行十神一致），文意稍嫌曲折；第三篇"阳之所生，即阴之所死，彼此互换"与第十二宫名义亦属简说，未给排盘细则。

9. **论运各篇多为条目式提示**，屡言"变化在人，不可泥也""其余变化，不能尽述，类而推之可也"，实际使用时须由使用者自行补足运算与命例校验，不具备可直接执行的完整性（**原文多次明言"只可大略言之"**）。
