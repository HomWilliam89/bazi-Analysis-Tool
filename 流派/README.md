# 流派\ — 丙层：各派主张库

> 依据决策台账 D-012 裁定：确立六大主流学派体系。
> 定位：客观收录各派主张、成立条件与古籍出处。**只并陈、不选边、不调和。** 两派相反就两行都列。

## 1. 六大主流学派体系
| 学派分类 | 标准条目文件 | 核心主张与方法论 | 对应母本（见 `流派\原料\` 与 `古籍\`） |
|---|---|---|---|
| **格局派** | `格局.md` | 月令提纲、十神定格、成格破格、清浊纯杂、救应顺逆 | 《子平真诠》《渊海子平》《御定子平秘本三篇》《神峰通考》 |
| **调候派** | `调候.md` | 四时寒暖燥湿、十干性情、生克喜忌配搭 | 《穷通宝鉴》《造化元钥》 |
| **旺衰扶抑派** | `旺衰.md` | 日主强弱、中和为贵、病药通关、极弱从化 | 《滴天髓阐微》《命理约言》《千里命稿》《八字提要》《命理探源》 |
| **盲派与象法** | `盲派象法.md` | 宾主体用、做功方式（制/化/穿/破）、干支字碰字之象 | 《盲派与象法》 |
| **古法三命** | `古法三命.md` | 年为主体、纳音三命、气数衰旺、古法神煞 | 《李虚中命书》《玉照定真经》《五行精纪》《兰台妙选》《鬼谷遗文》《五行大义》 |
| **神煞派** | `神煞.md` | 贵人、羊刃、将星、亡劫等吉凶神煞体系与吉凶互断 | 《星平会海》《三命通会》神煞诸篇 |

## 2. 条目格式（见 `文档\02 设计.md` §2）
| 字段 | 内容要求 |
|---|---|
| 编号 | 形如 `S-###`（按派系与条目序号编号） |
| 主张 | 一句话规则化推断（`条件 → 推断`） |
| 成立条件 | 命盘须满足的精确结构要求 |
| 出处 | 书名·篇名·原文（查不到写「未检得」） |
| 分歧 | 与之相悖或相对立的他派主张条目编号与简述 |

## 3. 原料与母本管理
- `流派\原料\`（D-013）：存放 11 部技法专著，作为主张提取的核心母本。
- `古籍\`：存放 10 部原典正文，作为溯源对校基准。
