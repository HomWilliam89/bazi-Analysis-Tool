# 02 · 设计

> 性质：骨架文档。管"体系怎么组织、词怎么定义、判据怎么排"；代码细节在 `03`。
> 本文件改动按重级处理：先讨论、后动。

## 1. 体系结构
三块，各归各的目录：
- **底座**（`核心\`）：排盘，无争议事实。只算，不判断。
- **丙层**（`流派\`）：各派主张库。只并陈，不选边。
- **乙体系**（`规矩\`）：本工具自己的宪法。只按自己的规则判，不冒充古籍原文。

输出三段，顺序固定：**排盘事实 → 各派并陈 → 本工具看法**。
乙体系未覆盖 ⇒ 第三段写「本体系未覆盖，暂不判断」，**不得**拿丙层某一派冒充本工具看法。

## 2. 丙层条目格式
| 字段 | 内容 |
|---|---|
| 派系 | 格局／调候／盲派／神煞／纳音／古法…（清单待 D-012） |
| 主张 | 一句话（规则化：条件 → 推断） |
| 出处 | 书名·篇名·行号；查不到写「未检得」 |
| 成立条件 | 该主张要求盘上满足什么 |
| 分歧 | 与之相反的他派主张，互链 |

只并陈、不调和；两派相反就两行都列。

## 3. 乙体系
- **宪法**：少数几条根本原则（如"先看什么、再看什么"），是判据的总纲。
- **判据**：每条形如 `条件 → 结论`；结论只许枚举值；附依据（出处或案例编号）。
- **术语**：一词一义，术语表唯一（`规矩\术语.md`）；新词先入表，判据才可用。

判据条目格式（草案，期 4 定稿）：
```md
## P-### 名称
条件：……
结论：<枚举值>
依据：<出处或案例 C-###>
```

## 4. 边界
- 丙层只并陈；乙体系只判自己覆盖的；两者**不许互相冒充**。
- 乙体系未覆盖 ⇒ 明写未覆盖，不硬答、不默认判。
- 分歧、未检得，如实写出。
- 涉健康／生死／诉讼／重大财务：只给倾向，指向专业意见，不作绝对化断言。

## 5. 案例与判据的钉关系
每条判据（P-###）至少一张案例（C-###）钉住期望值；
改判据必须同步更新案例；案例格式见 `案例\README.md`。
