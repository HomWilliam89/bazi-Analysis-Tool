## 6. git 约定
- 一逻辑改动一 commit；文档＋判据＋代码＋案例同 commit；提交前测试全绿。
- message：`[轻|中|重] <判据ID或D-###>: 一句话`；正文四行：改了什么／为什么／影响面／测试。
- 分支 main 单线；每期结束打 tag（如 `v1-skeleton`）。
- 回滚以 commit 为单位；本地 commit 或 amend 后必须同步核准日志记录之 commit hash；严禁未经使用者明确同意执行 git push；`reset --hard`／强推前必须先问使用者。

## 10. 引擎量化参数说明
底座引擎内部包含部分用于计算机连续打分之工程量化参数（如：宫位权重月支 0.35、日支 0.20；干支位置距离衰减贴身 1.00、隔位 0.55、遥隔 0.25；五行力量占比阈值等）：
- **定位**：此类参数属于算法实现的**工程操作化近似数值**，绝不作为乙体系之宪法判据。
- **纪律**：宪法所定者为序（如“月令最大，时支其次；通关桥须两端贴身”）；底层数值之微调不视为易学宪法改动。

## 12. 节气交节分钟边界口径与流年时间轴联动（D-060 落地）
- **节气分钟粒度交节口径**：天文求根器得出精确交节秒数（四舍五入至整秒）。在分钟级别比较（`cmpMoment`）时，若输入生辰之分钟数与节气交节分钟数完全相等（分差为 0），系统依据确定性公理定义为「已进入新节气」（即交节当分钟即按已交节计，归入节气后之月柱/年柱）。
- **流年时间轴基准联动**：Section 3.5 未来十年流年推演起推年份由 `resolveStartYear` 统一仲裁：
  1. 调用指令显式指定 `--start-year` 或 `-y/--year` 时，优先以指定年份为起始推演十年；
  2. 历史名造（生辰或选定时代年份 < 1926 年者），自动联动其出生时代流年；
  3. 现代常规生辰与当代盘，默认推演当下人生阶段未来十年（2026–2035 年）。
- **第六轨「同气比和」防御性保底分支**：依据《体用路线法》病药严格互斥公理，病神（主要矛盾元凶）与用神（做功解救枢纽）在定性上严格对立互斥；在 `resolveDiseaseElement` 中已作严格过滤（`e !== primaryYong`）。五行两两相异必定命中前 5 轨，第 6 轨作为数学完备性保底防御分支保留，业务推演不落入此轨。

## 13. 古典母本全量 2,140+ 条规则推进三大工程防御机制（D-068）
依据使用者最高决策指令，全量吃透 20 部母本 2,140+ 条规则确立为当前核心主线任务，必须坚守三大工程防御闸门：
1. **防脚本臃肿与性能损耗机制**：
   - 手写学理排他谓词（约 700 条）：按流派解耦分拆为 `核心/matcher/` 独立子模块（`geju.mjs`, `tiaohou.mjs`, `shensha.mjs` 等），单文件代码量控制在 800 行以内；主引擎仅负责分发；
   - 民国韦千里《八字提要》（1,440 组）：严禁写成 1,440 个 JS 函数，采用 `核心/data/tiyao.json` 静态数据表 + 单个 30 行查表函数，实现 $O(1)$ 极速检索（耗时 < 0.01ms），零性能损耗、零内存压力。
2. **防 AI 中途偷懒、漏跑与幻觉瞎编机制**：
   - 坚持纯 Node.js 确定性计算引擎，输入四柱由 CPU 执行数学/干支判断，100% 确定性、100% 幂等，杜绝 LLM 盲跑引起的幻觉与省略；
   - 物理磁盘字符看门狗（`citation-check.mjs`）100% 逐字比对原始底本，错漏虚构一字即退出阻断 CI；
   - 测试套件强制断言：条目总数严格等于 N，谓词总数严格等于 N，覆盖率 100%，零死条目。
3. **防输出层漏输出截断与信息隐瞒机制**：
   - 彻底废除 `report-generator.mjs` 中各派 `slice(0, 3)` 粗暴截断，全面升级为“核心强特征详析 + 全量命中主张索引附录全陈”，确保底层命中的每一条在输出端均有明确呈现；
